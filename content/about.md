안녕하세요, **River(Hyerin Kim)** 입니다. 웹 프론트엔드를 중심으로 사용자가 편하게 쓰는 화면을 만들고, 그 화면을 받쳐 주는 백엔드와 컴퓨터 과학의 기초까지 꾸준히 공부하고 있어요.

2022년부터 배운 것을 TIL로 기록해 왔고, 그 기록들을 다시 다듬어 이곳 **지식 창고**에 모았습니다. 블로그에는 만들면서 겪은 일과 생각을 적습니다.

### 관심 있는 것

- **Frontend** — React, React Native, TypeScript, 웹 표준과 브라우저 동작 원리
- **Backend** — NestJS, Django, REST API 설계, 데이터베이스
- **기초 체력** — 자료구조·알고리즘, 운영체제, 네트워크, 컴퓨터 구조
- **일하는 방식** — 테스트 주도 개발, 협업 도구, 문서화
