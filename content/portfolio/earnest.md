Going Merry에서 일하다 2025년부터 모회사 Earnest의 Growth 팀으로 옮겼습니다. 성장 팀의 일은 "작은 변경이 숫자로 돌아오는 일"이었어요. 레이아웃이 조금 덜 흔들리는 것, URL 끝의 슬래시 하나, 온보딩 화면 문구 한 줄이 검색 순위와 대출 체결 수로 이어졌습니다.

## WordPress → Next.js + Storyblok 마이그레이션

> earnest.com을 WordPress에서 Next.js + Storyblok(헤드리스 CMS) 구조로 옮기는 프로젝트

- 기존 WordPress 기반 회사 웹사이트를 **Next.js + Storyblok** 아키텍처로 옮기는 작업에 참여해 핵심 페이지를 구현했습니다.
- **Nginx 404 재라우팅 문제 해결**: 팀이 오래 풀지 못하던 문제였습니다. 새 프론트엔드와 기존 모놀리스 사이의 프로덕션 트래픽 라우팅과 Nginx 설정을 직접 분석하고 고쳐, 이전 과정의 핵심 병목을 없앴습니다. 이전이 끝난 모놀리스 쪽 정적 페이지 템플릿도 정리했습니다.
- **인터랙티브 미국 지도**: 미국 50개 주를 4개 권역으로 묶어 보여 주는 지도 컴포넌트를 만들었습니다.
  - 디자이너가 넘겨 준 SVG를 직접 분석해 주(state)별 path 구조를 다시 정리했습니다.
  - **권역(region) 레이어 구조를 제안**해 hover와 클릭 처리 로직을 단순하게 만들었고, 성능과 유지보수성도 함께 좋아졌습니다.
  - 시안을 그대로 옮기는 데서 그치지 않고 SVG 구조와 컴포넌트 구조까지 함께 설계하는 협업 방식을 이때 익혔습니다.
- **CMS 운영**: Next.js + Storyblok 구조 덕분에 마케팅·콘텐츠 팀이 개발자 없이 캠페인과 콘텐츠 실험을 운영할 수 있게 됐습니다.

## SEO 개선과 검색 트래픽 최적화

> 마이그레이션하면서 SEO 친화적인 구조로 전환

- Lighthouse 기준 **CLS(레이아웃 이동) 문제**를 고쳤습니다.
- **동적 사이트맵**을 구현하고 robots.txt와 canonical URL을 관리했습니다.
- **URL 정규화**를 적용했습니다. 사이트 전체에 trailing slash 리다이렉트를 걸면서 쿼리스트링을 보존하고 블로그 경로는 예외로 처리했으며, 페이지 URL 끝에 붙던 빈 `?`도 없앴습니다.
  - 프로덕션 라우팅 변경은 되돌린 적이 몇 번 있었습니다. 그래서 **staging에 먼저 적용하고 엣지 케이스(쿼리스트링, 블로그 경로)를 점검한 뒤 프로덕션에 반영**하는 절차로 진행했습니다.

그 결과 **6월 평균 검색 순위가 7.5위에서 4.3위로 올랐고, 구글 오가닉 검색 클릭 수는 220% 넘게 늘었습니다.** 프론트엔드 기술의 정밀도가 회사 수익에 직접 영향을 줄 수 있다는 걸 배운 프로젝트예요.

## 학자금 재융자 온보딩 퍼널

> 재융자 신청 퍼널의 이벤트 설계, 본인 인증 개선, 실험 운영

- **이벤트 표준화**: 재융자 온보딩 퍼널의 Segment 이벤트를 구현하고 스키마를 표준화해, 전환·이탈 분석과 A/B 테스트를 할 수 있는 기반을 만들었습니다.
- **Verified 본인 인증**: 사용자가 개인정보를 여러 칸에 직접 입력해야 했던 기존 폼을 **전화번호 1회 입력 + Verified 본인 인증** 방식으로 다시 설계해 신청 완료까지의 이탈을 줄였습니다.
  - 인증된 사용자의 식별(identify) 이벤트가 엉뚱한 시점에 발생하던 버그도 찾아서 고쳤습니다. 플로우를 불러온 뒤 세션을 확인하고, 실패하면 바로 다시 시도하도록 순서를 바꿨어요.
- **금리 확인 결과 화면**: 실험에서 이긴 "금리 티커(Rate Ticker)" 헤더를 정식 기능으로 옮기며 컴포넌트와 테스트를 새로 작성했습니다.
- **실험 정리**: 할인 중첩 표시, 앱 푸터 메시지 등 끝난 실험을 기본 동작으로 통합하면서 **실험 플래그와 트래킹 코드까지 걷어내고 테스트를 추가**했습니다. 할인 배너를 본 사용자의 분석 속성이 빠지는 문제도 복구했습니다.
- 재방문 사용자 라우팅 오류와 결과 화면 UI 버그 등 퍼널 곳곳의 문제를 고쳤습니다.

## A/B 테스트

> Optimizely + Segment 실험 기반 위에서 핵심 화면의 실험을 설계하고 구현

- PM·마케팅·데이터 팀과 함께 **가설 → 실험 설계 → 런칭 → 결과 분석 → 승자 발표** 사이클을 반복하며 재융자 퍼널과 마케팅 성과를 개선했습니다.
- 한 실험에서는 **한 달 만에 대출 체결이 16% 늘었고**, 대출 서명 정도도 함께 증가했습니다.

## 돌아보며

미국 회사에서 원격으로 일하며 가장 크게 바뀐 건 **코드 리뷰를 대하는 태도**였습니다. 디자인, 코드, 자동 리뷰 지적을 하나씩 반영하고, 실험을 끝낼 때는 플래그와 트래킹 코드까지 깨끗이 지우는 습관이 생겼어요. 이 습관은 지금 사내 시스템을 만들 때도 그대로 이어지고 있습니다.
