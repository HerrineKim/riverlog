좋은 글은 정보를 늘어놓는 글이 아니라 **독자를 움직이는 글**이다. 여러 글쓰기 책과 칼럼에서 공통적으로 강조하는 원칙을 구조·설득·문체 세 가지로 묶었다.

## 1. 잘 쓴 글의 구조

1. **도입** — 주제와 관련된 개인 경험, 인물 일화, 역사적 사건으로 시작해 관심을 끈다.
2. **전개** — 책 속 문장, 인터뷰, 객관적 데이터를 인용하며 주장을 쌓는다.
3. **정리** — 분석·시사점·실천법은 번호 목록으로 명확하게 보여 준다.
4. **결론** — 하고 싶은 말을 요약한다.
5. **여운** — 독자에게 생각할 거리를 던진다.

### 문단 만들기

출판 편집자들이 권하는 간단한 공식: **주제 문장 1개 + 뒷받침 문장 3개 = 한 문단**, 이런 문단 3개로 한 편을 구성한다. 이것만 지켜도 읽기 편한 글이 된다. (짧은 말하기·글쓰기에는 「온라인 글쓰기」 노트의 PREP 공식도 유용하다.)

## 2. 설득의 원칙

『뉴욕타임스 편집장의 글을 잘 쓰는 법』(트리시 홀)의 원칙을 요약하면 다음과 같다.

| 원칙 | 요점 |
| --- | --- |
| 먼저 듣는다 | 설득의 첫 단계는 상대가 누구이며 어떻게 느끼는지 아는 것 |
| 한계를 인정한다 | 사람은 신념을 쉽게 바꾸지 않는다. 글로 싸움을 걸면 역효과 |
| 감정에 호소한다 | 사람은 팩트보다 감정과 스토리에 반응한다 |
| 공통점을 찾는다 | 사람은 자신과 비슷한 사람의 의견에 동의한다 |
| 아는 것을 쓴다 | 잘 아는 주제일수록 구체적으로 쓸 수 있다 |
| 구체적으로 쓴다 | 추상적 주장보다 구체적 장면이 설득력 있다 |
| 그래도 팩트는 지킨다 | 사실 확인이 무너지면 글 전체의 신뢰가 무너진다 |
| 전문 용어를 피한다 | 독자가 멈추는 순간 설득도 멈춘다 |
| 고치고 또 고친다 | 퇴고가 곧 글쓰기다 |

## 3. 비즈니스 글쓰기 습관

광고인 데이비드 오길비가 직원들에게 남긴 글쓰기 조언의 요지:

- 말하듯이 자연스럽게 쓴다.
- 단어·문장·문단 모두 **짧게**. 어떤 주제든 2페이지를 넘기지 않는다.
- 전문 용어는 허세일 뿐이다.
- 인용은 꼼꼼히 확인한다.
- 중요한 글은 쓴 당일 보내지 말고, 다음 날 소리 내어 읽고 고친 뒤 보낸다. 가능하면 동료에게 검토를 부탁한다.
- 보내기 전에 **상대에게 원하는 행동**이 분명히 적혀 있는지 확인한다.
- 정말 행동을 원한다면 글 대신 직접 찾아가 말한다.

## 핵심 정리

- 구조: 도입 → 근거 → 목록화된 정리 → 요약 → 여운
- 설득: 듣고, 공감하고, 이야기로 전달하되 사실은 정확하게
- 문체: 짧게, 쉽게, 고쳐 쓰고, 요청을 명확하게
