연말 모임이나 선물용으로 와인을 고를 때, 그리고 칵테일 바에서 무엇을 시킬지 모를 때 참고하려고 모은 목록이다. 마트·와인숍에서 비교적 구하기 쉬운 것 위주이며, 빈티지와 가격은 시기마다 다르니 구매 전에 확인한다.

## 와인 고르는 기준

| 종류 | 특징 | 어울리는 자리 |
| --- | --- | --- |
| 스파클링 | 기포, 산뜻함 | 건배, 식전주, 파티 |
| 레드 | 탄닌감, 묵직함 | 고기 요리, 저녁 식사 |
| 화이트 | 산미, 가벼움 | 해산물, 샐러드, 가벼운 식사 |
| 스위트 | 단맛, 낮은 도수인 경우가 많음 | 와인 입문자, 디저트와 함께 |
| 디저트 | 진한 단맛(포트, 늦수확, 아이스와인) | 식후 소량 |

## 종류별 추천 목록

### 스파클링

- 앙드레 끌루에 (샴페인)
- 샤를 드 까자노브 브뤼 (샴페인)
- 랑슬로 피엔 뀌베 트라디시옹 브뤼
- 산테로 피도 샤르도네 스푸만테
- 도멘 생 미셸 브뤼
- 보히가스 리제르바 까바

### 레드

- 이기갈 지공다스
- 이기갈 꼬뜨 뒤 론 루즈
- 뿌삐유
- 무똥 까데 생떼밀리옹
- 엠 샤푸티에 꼬뜨 뒤 루시용 빌라주
- 바로사 잉크 쉬라즈

### 화이트

- 푸나무 소비뇽 블랑
- 클라우디 베이 소비뇽 블랑
- 이기갈 꼬뜨 뒤 론 블랑
- DRK 호프굿 리슬링
- 레오나드 크로이쉬 아우스레제

### 스위트

- 발비 소프라노 모스카토 다스티
- 트리벤토 레이트 하베스트
- 빌라 엠 로쏘
- 아랄디카 브라케토 다퀴 돌체

### 디저트

- 오스본 토니 포트
- 알람브르 모스카텔 드 세투발
- 파트리치우스 토카이 레이트 하베스트
- 슐로스 폴라즈 리슬링 카비넷
- 시즌스 비달 아이스와인
- 아스코니 머스캣 아이스와인
- 아스코니 카베르네 소비뇽

## 입문용 칵테일

단맛이 있고 도수가 부담스럽지 않아 처음 마시기 좋은 칵테일들이다.

| 칵테일 | 주재료 |
| --- | --- |
| 카시스 오렌지 | 카시스(블랙커런트) 리큐르 + 오렌지 주스 |
| 말리부 오렌지 | 코코넛 럼(말리부) + 오렌지 주스 |
| 스크루드라이버 | 보드카 + 오렌지 주스 |
| 피치 크러시 | 복숭아 리큐르 + 과일 주스 |
| 미도리 사워 | 멜론 리큐르(미도리) + 사워 믹스 |
| 피냐 콜라다 | 럼 + 파인애플 주스 + 코코넛 크림 |
| 깔루아 밀크 | 커피 리큐르(깔루아) + 우유 |
| 베일리스 밀크 | 크림 리큐르(베일리스) + 우유 |
| 블랙 러시안 | 보드카 + 커피 리큐르 (도수 높은 편) |
| 프로즌 다이키리 | 럼 + 라임 + 설탕을 얼음과 함께 간 것 |

주스·우유로 희석한 칵테일은 단맛 때문에 도수가 낮게 느껴진다. 블랙 러시안처럼 주스가 없는 칵테일은 생각보다 독하니 천천히 마신다.
