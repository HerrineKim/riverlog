데이터 저널리즘은 데이터를 수집·분석·시각화해 기사의 근거이자 소재로 삼는 보도 방식이다. 한 탐사보도 매체 데이터팀과의 질의응답을 바탕으로 실무 흐름을 재구성하고, 무료 도구 강좌(Knight Center MOOC "Data Journalism and Visualization with Free Tools")와 2019 데이터 저널리즘 코리아 컨퍼런스에서 얻은 내용을 덧붙였다.

## 현황과 직무

- 국내에서는 일부 방송사·신문사·탐사보도 매체가 데이터팀을 운영하지만 아직 초기 단계다. 매체마다 강점이 다르다. (인터랙티브 콘텐츠 중심, 탐사보도 결합형 등)
- "한국이라서 어렵다"기보다는 **수익이 되느냐, 수익이 안 돼도 투자하느냐**의 문제다. 모든 언론사가 할 필요는 없고 각자 잘하는 것을 하면 된다.
- 직무 구성은 회사마다 다르다.

| 형태 | 구성 |
| --- | --- |
| 통합형 | 시각화·디자인 담당과 분석 담당 모두 '데이터 기자'로 부름 |
| 분업형 | 취재기자, 디자이너, 개발자, 분석가로 직함 구분 |
| 개발 특화형 (미국 일부 비영리 매체) | 시각화·인터랙티브 개발자를 '뉴스 앱 디벨로퍼'로 따로 둠 |

## 1. 주제 설정: 데이터가 먼저? 기사가 먼저?

둘 다 가능하지만 실무에서는 **주제(가설)를 먼저 세우고 이를 확인할 데이터를 찾는** 경우가 압도적으로 많다.

- 예: 특정 국가의 미국 내 로비 활동을 다루기로 하고, 미 법무부의 외국대리인등록법(FARA) 신고 자료를 전수 분석했다.
- 데이터가 가설을 뒷받침하지 못하면 기사를 쓰지 못한다.
- 드물게 데이터 자체가 기사가 되기도 한다. (예: 연구 보고서 부록에 숨어 있던 동 단위 위험도 데이터)
- 고위공직자 재산 공개, 선거 후보자 정보처럼 **정기적으로 공개되는 데이터**는 미리 의제를 잡고 준비한다.
- 연습법: 데이터 기사를 읽고 "어떤 주제에 초점을 맞췄고, 그걸 위해 어떤 자료를 모았는지"를 **역으로 추론**해 본다.

## 2. 수집

- 신뢰할 수 있는 출처가 최우선. 그렇지 않다면 교차 검증이 가능한 곳에서 분석한다.
- 정부 발표 자료와 공공데이터(오픈 데이터)를 꾸준히 살펴본다.
- **전수조사 여부**: 전수를 모아야 이야기가 성립할 때만 한다. 다만 "완벽한 전수"는 사실상 어렵다. 정보공개청구 자료에도 누락이 있을 수 있으므로, "이게 전수다"라고 단정하고 비율을 계산하는 것은 위험하다.

## 3. 정제·분석 도구

| 도구 | 용도 |
| --- | --- |
| 스프레드시트 | 가장 먼저 익힐 도구. 일반 기자들과 공유하기도 쉽다 |
| SQL | 대용량 데이터베이스 |
| Python + Pandas | CSV 등 파일 기반 분석 |

정제가 막힐 때는 작정하고 **수작업**으로 처리하는 편이 오히려 빠를 때도 있다.

## 4. 정확한 분석을 위해

- 회귀분석까지 다루는 기초 통계를 한 번 공부해 두면 좋다.
- 평균 비교, 분산 분석 등에서 차이가 **통계적으로 유의미한지** 따질 줄 알면 수치를 자의적으로 비교하지 않게 된다.
  - 예: "오차 범위 내에서 A가 앞섰다"는 성립하지 않는 문장이다. 오차 범위 안이면 앞섰다고 말할 수 없다.
- 정확성은 지식보다 **습관**이다. 내 작업을 검증할 장치를 미리 마련한다.
  - 예: 수기 기록을 스프레드시트로 옮긴 뒤, 피벗 테이블로 낸 합계를 공식 발표 통계와 대조한다.

## 5. 시각화

- 웹 시각화에는 주로 d3.js, 지도는 Leaflet·Mapbox 같은 JavaScript 라이브러리를 쓴다.
- 도구는 중요하지 않다. 구현 전에 **어떤 시각화로 무엇을 전달할지**부터 정한다.

### 시작은 생각보다 쉽다: 한스 로슬링 차트 따라 만들기

통계·코딩·도구까지 배울 것이 많아 보여 압도되기 쉽지만, 첫 시각화는 코드 없이도 만들 수 있다. 한스 로슬링이 2006년 TED 강연에서 보여 준, 국가별 출산율과 기대 수명이 연도에 따라 움직이는 **애니메이션 버블 차트**를 무료 도구 **Flourish**로 거의 그대로 재현할 수 있다.

1. Gapminder 웹사이트에서 강연에 쓰인 것과 비슷한 데이터셋(국가, 대륙, 연도, 출산율, 기대 수명, 인구)을 내려받는다.
2. Flourish에서 New visualization → **Scatter plot**을 고르고 데이터를 불러온다.
3. 열을 연결한다: X축 = 출산율, Y축 = 기대 수명, Name = 국가, Color = 대륙, Size = 인구, Time = 연도.
4. 버블 크기를 키우면 완성. 재생 버튼을 누르면 시간에 따라 버블이 움직인다.

결과를 보면 오늘날 대부분의 나라가 왼쪽 위(낮은 출산율, 높은 기대 수명)에 모여 있다. 데이터 몇 열과 무료 도구만으로 이런 이야기를 보여 줄 수 있다는 것이 데이터 저널리즘의 출발점이다.

## 단계별 어려움

| 단계 | 어려운 점 |
| --- | --- |
| 구하기 | 아이템마다 상황이 다르고, 이야기가 되는 데이터인지 판단부터 어렵다 |
| 정제 | 형식이 제각각인 데이터 |
| 분석 | 기대한 결과가 안 나오면 다음 단계가 없다 |
| 시각화 | 양이 너무 많거나 독자에게 낯선 정보 |
| 기사 쓰기 | 어떻게 써야 읽히고 공유될지 |

## 실패에서 배운 것

데이터 저널리즘은 블루오션처럼 보이지만, 공개된 중요 데이터에는 모든 언론사와 분석가가 몰리기 때문에 실제로는 레드오션인 경우가 많다. 수집부터 현장 취재·영상 제작까지 시간이 오래 걸리는 사이 다른 곳이 먼저 보도하면 실패한다.

> 남이 공개한 데이터보다 **내가 생산하거나 나만 접근할 수 있는 데이터**로 작업해야 시간에 쫓기지 않고 깊이 있게 보도할 수 있다.

## 현장에서 들은 이야기 (2019 데이터 저널리즘 코리아)

### 뉴스룸의 AI

- 해외 뉴스 기관의 절반가량이 이미 AI를 쓰고 있었다. 수천 건의 문서를 스스로 분류·분석해 어디에 주제가 있는지 알려 주는 등, 기자의 "막노동"을 AI가 돕는 방향이다.
- 텍스트 분석은 BERT 이후 크게 발전했고, OCR도 쓸 만해지고 있다. 기사를 자동으로 쓰는 로봇 저널리즘도 협업 형태로 시도되고 있다.

### 읽히고 공유되는 데이터 기사

아무도 보지 않으면 소용이 없다. 일반 독자는 데이터 기사를 일부러 찾아보지 않는다. 보다 보니 재밌거나 도움이 되니까 볼 뿐이다.

1. **빼라(선택과 집중)**: 텍스트도, 데이터도, 그래프도 덜어낸다. 데이터는 거들 뿐이다.
2. **줄여라(모바일 최적화)**: 로딩 시간을 줄이고, 어렵다면 로딩 화면이라도 넣는다. 텍스트도 더 줄인다.
3. **함께해라(공감과 분노)**: 같이 재밌어하거나, 같이 화내거나, 같이 이야기하고 싶은 주제가 퍼진다. 이름(개명) 데이터, 우리 동네 의회 살림 같은 생활 밀착형 주제가 수십만~백만 단위 조회를 기록했다.

그 밖에

- 모바일 화면을 먼저 디자인한다.
- 고비용 인터랙티브("스노우폴"형 대형 기획)보다 기사 안에서 가볍게 도는 시각물이 현실적이다.
- 뉴스레터·인스타그램 등 자체 채널로 직접 독자를 만나고, 공개 시점에 맞춰 티저를 미리 만든다. 타이밍이 중요하다.
- 같은 주제를 **꾸준히 반복**해 다루면 그 자체로 신뢰와 평가가 쌓인다. 독자는 "중요하다"는 말만으로는 관심을 갖지 않는다.
- 현장 취재는 실마리를 주고, 데이터는 증명을 한다. 압도하는 근거, 몰입되는 스토리, 미래지향적 대안이 함께 있어야 한다.
- 도메인 전문성, 적어도 깊은 관심이 있어야 좋은 질문을 던질 수 있다.

### 공공데이터의 한계와 우회

공개 단위가 거칠어(예: 행정동 단위 미공개) 원하는 분석이 어려울 때는 마이크로데이터 서비스나 생활인구 데이터(통신·교통 데이터를 합친 통계)처럼 다른 경로를 찾는다. 저자 페이지가 있는 학술 DB처럼 **구조가 정리된 사이트**는 수집하기 좋은 출처가 된다.

### 해외 탐사 매체의 펀딩 모델

| 모델 | 내용 |
| --- | --- |
| 크라우드 펀딩 | 긴박한 사안 + 탄탄한 인적 네트워크가 있을 때만 가능 |
| 비영리 재단 | 민주화, 탐사보도, 개발·국제 취재 등 재단 목적에 맞춘 프로젝트 그랜트 |
| 컨설팅 등 수익 사업 | 취재에서 쌓인 노하우를 상품화 |
| 파트너십 | 대형 매체와 기사를 교차 게재. 돈보다 명예·평판에 도움 |

대부분 여러 펀딩 소스를 함께 쓰며, 돈을 받으면서 편집권 독립을 보장받기는 쉽지 않다. 국내에서도 해외에서 접근하기 쉬운 주제(접경 지역, 위성사진·드론 취재, 디아스포라 커뮤니티)로 작은 "가상 해외 지국" 프로젝트를 꾸릴 수 있다는 제안이 있었다.
