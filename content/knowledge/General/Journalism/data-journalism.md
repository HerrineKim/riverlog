데이터 저널리즘은 데이터를 수집·분석·시각화해 기사의 근거이자 소재로 삼는 보도 방식이다. 한 탐사보도 매체 데이터팀과의 질의응답을 바탕으로, 실무 흐름 순서대로 재구성했다.

## 현황과 직무

- 국내에서는 일부 방송사·신문사·탐사보도 매체가 데이터팀을 운영하지만 아직 초기 단계다. 매체마다 강점이 다르다. (인터랙티브 콘텐츠 중심, 탐사보도 결합형 등)
- "한국이라서 어렵다"기보다는 **수익이 되느냐, 수익이 안 돼도 투자하느냐**의 문제다. 모든 언론사가 할 필요는 없고 각자 잘하는 것을 하면 된다.
- 직무 구성은 회사마다 다르다.

| 형태 | 구성 |
| --- | --- |
| 통합형 | 시각화·디자인 담당과 분석 담당 모두 '데이터 기자'로 부름 |
| 분업형 | 취재기자, 디자이너, 개발자, 분석가로 직함 구분 |
| 개발 특화형 (미국 일부 비영리 매체) | 시각화·인터랙티브 개발자를 '뉴스 앱 디벨로퍼'로 따로 둠 |

## 1. 주제 설정: 데이터가 먼저? 기사가 먼저?

둘 다 가능하지만 실무에서는 **주제(가설)를 먼저 세우고 이를 확인할 데이터를 찾는** 경우가 압도적으로 많다.

- 예: 특정 국가의 미국 내 로비 활동을 다루기로 하고, 미 법무부의 외국대리인등록법(FARA) 신고 자료를 전수 분석했다.
- 데이터가 가설을 뒷받침하지 못하면 기사를 쓰지 못한다.
- 드물게 데이터 자체가 기사가 되기도 한다. (예: 연구 보고서 부록에 숨어 있던 동 단위 위험도 데이터)
- 고위공직자 재산 공개, 선거 후보자 정보처럼 **정기적으로 공개되는 데이터**는 미리 의제를 잡고 준비한다.
- 연습법: 데이터 기사를 읽고 "어떤 주제에 초점을 맞췄고, 그걸 위해 어떤 자료를 모았는지"를 **역으로 추론**해 본다.

## 2. 수집

- 신뢰할 수 있는 출처가 최우선. 그렇지 않다면 교차 검증이 가능한 곳에서 분석한다.
- 정부 발표 자료와 공공데이터(오픈 데이터)를 꾸준히 살펴본다.
- **전수조사 여부**: 전수를 모아야 이야기가 성립할 때만 한다. 다만 "완벽한 전수"는 사실상 어렵다. 정보공개청구 자료에도 누락이 있을 수 있으므로, "이게 전수다"라고 단정하고 비율을 계산하는 것은 위험하다.

## 3. 정제·분석 도구

| 도구 | 용도 |
| --- | --- |
| 스프레드시트 | 가장 먼저 익힐 도구. 일반 기자들과 공유하기도 쉽다 |
| SQL | 대용량 데이터베이스 |
| Python + Pandas | CSV 등 파일 기반 분석 |

정제가 막힐 때는 작정하고 **수작업**으로 처리하는 편이 오히려 빠를 때도 있다.

## 4. 정확한 분석을 위해

- 회귀분석까지 다루는 기초 통계를 한 번 공부해 두면 좋다.
- 평균 비교, 분산 분석 등에서 차이가 **통계적으로 유의미한지** 따질 줄 알면 수치를 자의적으로 비교하지 않게 된다.
  - 예: "오차 범위 내에서 A가 앞섰다"는 성립하지 않는 문장이다. 오차 범위 안이면 앞섰다고 말할 수 없다.
- 정확성은 지식보다 **습관**이다. 내 작업을 검증할 장치를 미리 마련한다.
  - 예: 수기 기록을 스프레드시트로 옮긴 뒤, 피벗 테이블로 낸 합계를 공식 발표 통계와 대조한다.

## 5. 시각화

- 웹 시각화에는 주로 d3.js, 지도는 Leaflet·Mapbox 같은 JavaScript 라이브러리를 쓴다.
- 도구는 중요하지 않다. 구현 전에 **어떤 시각화로 무엇을 전달할지**부터 정한다.

## 단계별 어려움

| 단계 | 어려운 점 |
| --- | --- |
| 구하기 | 아이템마다 상황이 다르고, 이야기가 되는 데이터인지 판단부터 어렵다 |
| 정제 | 형식이 제각각인 데이터 |
| 분석 | 기대한 결과가 안 나오면 다음 단계가 없다 |
| 시각화 | 양이 너무 많거나 독자에게 낯선 정보 |
| 기사 쓰기 | 어떻게 써야 읽히고 공유될지 |

## 실패에서 배운 것

데이터 저널리즘은 블루오션처럼 보이지만, 공개된 중요 데이터에는 모든 언론사와 분석가가 몰리기 때문에 실제로는 레드오션인 경우가 많다. 수집부터 현장 취재·영상 제작까지 시간이 오래 걸리는 사이 다른 곳이 먼저 보도하면 실패한다.

> 남이 공개한 데이터보다 **내가 생산하거나 나만 접근할 수 있는 데이터**로 작업해야 시간에 쫓기지 않고 깊이 있게 보도할 수 있다.
