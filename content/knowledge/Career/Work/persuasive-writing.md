좋은 글은 정보를 늘어놓는 글이 아니라 **독자가 다음 행동을 하게 하는 글**이다. 구조, 설득, 문장은 따로 놀지 않는다. 뼈대가 없으면 근거가 흩어지고, 상대를 모르면 문장을 다듬어도 설득이 안 되며, 문장이 따라 주지 않으면 구조만 남는다.

> 우리말 문장 부분은 블로거팁닷컴의 「[유시민이 말하는 글을 잘 쓰는 방법](https://bloggertip.com/4175)」(2013.09)을 바탕으로 재구성했다. 원 자료는 글쓰기 강의다. 구조·설득·업무 글 습관은 여러 글쓰기 지침에서 겹치는 부분을 한자리에 묶었다.

## 잘 쓴 글의 구조

한 편은 다섯 칸으로 읽힌다.

| 칸 | 역할 |
| --- | --- |
| 도입 | 주제와 닿는 장면, 질문, 숫자로 왜 이 글인지 연다 |
| 전개 | 인용, 데이터, 사례로 주장을 쌓는다. 근거는 강한 것 하나면 된다 |
| 정리 | 분석·시사점·실천은 번호 목록으로 꺼낸다 |
| 결론 | 하고 싶은 말을 한 줄로 다시 적는다 |
| 여운 | 독자가 가져갈 질문이나 다음 행동을 남긴다 |

문단은 **주제 문장 하나 + 뒷받침 두세 문장**이다. 이런 문단 서너 개면 한 편이 선다.

짧은 글과 말은 결론을 앞에 둔다. 핵심 한 줄, 이유, 사례 하나, 핵심을 다시 한 줄. 이 틀은 자기소개서와 면접 답변에서 [[cover-letter-writing|PREP]], 면접 말에서는 [[interview-attitude|결론부터 말하기]]로 이미 쓴다. 설득이 약한 주장을 근거 여러 개로 메우면 글만 길어진다.

## 설득

설득은 문장을 세게 쓰는 일이 아니다. 상대가 어디에 서 있는지를 먼저 아는 일이다.

| 원칙 | 요점 |
| --- | --- |
| 먼저 듣는다 | 누가 읽고, 무엇을 이미 믿으며, 무엇을 하면 손해를 보는지 |
| 한계를 인정한다 | 글 한 편으로 신념이 바뀌지 않을 때가 있다 |
| 싸움을 걸지 않는다 | 언쟁은 상대의 기존 믿음을 더 단단하게 만든다 |
| 공통점에서 시작한다 | 사람은 자기와 비슷하다고 느끼는 쪽에 귀를 연다 |
| 감정 다음에 팩트 | 장면과 이야기가 먼저 남고, 숫자는 그 장면을 받친다 |
| 구체적으로 쓴다 | 「중요하다」 대신 누가, 언제, 무엇을 했는지 |
| 아는 것만 쓴다 | 잘 아는 주제일수록 장면이 구체적이다 |
| 사실은 지킨다 | 사실 확인이 무너지면 글 전체의 신뢰가 무너진다 |
| 전문 용어를 푼다 | 독자가 멈추는 순간 설득도 멈춘다 |
| 고치고 또 고친다 | 퇴고가 곧 글쓰기다 |

화면 안의 짧은 문구는 같은 원칙을 더 좁혀 쓴다. 목표에 맞는지, 훑어보기 좋은지, 이유가 먼저 보이는지는 [[ux-writing|UX 라이팅]]이 맡는다.

## 업무 글

메일, 메모, 제안은 문학이 아니라 **상대가 무엇을 하면 되는지**가 드러나야 한다.

1. 말하듯 쓰고, 소리 내어 읽어 걸린 곳을 고친다.
2. 단어, 문장, 문단을 짧게 유지한다.
3. 전문 용어는 빼거나 처음 한 번 푼다.
4. 긴 글은 두 쪽을 넘기기 전에 목적을 다시 자른다.
5. 인용과 숫자는 원문과 대조한다.
6. 보낸 날 바로 보내지 않는다. 다음 날 아침 다시 읽는다.
7. 중요한 글은 동료에게 한 번 고치게 한다.
8. 끝내기 전에, 수신인이 **무엇을 하기를 원하는지** 한 줄로 적혀 있는지 본다.
9. 글로 행동이 안 나오는 부탁은 직접 말한다.

메일 한 통의 받는 사람, 제목, 첨부 점검은 [[business-email|비즈니스 이메일]]에 있다.

## 사실과 판단

글은 생각에서 말로, 말에서 글로 간다. 말하듯 쓴 문장이 자연스럽다. 이중 피동(「발전되어지다」), 남발한 「~적」, 무생물 주어의 피동은 우리말 리듬을 깬다.

| 원칙 | 내용 |
| --- | --- |
| 사실과 판단을 가른다 | 일어난 일과 그에 대한 평가를 한 문장에 섞지 않는다 |
| 판단에는 근거를 붙인다 | 취향은 반박할 수 없고, 근거 없는 판단도 마찬가지다 |
| 내 판단임을 밝힌다 | 개인 의견을 일반 사실처럼 쓰지 않는다 |
| 동어반복을 피한다 | 근거 자리에 주장을 다른 말로 되풀이하면 논증이 아니다 |

## 문장력을 기르는 습관

원칙을 알아도 문장이 따라 주지 않으면 글이 서지 않는다. 문장력은 재능보다 반복에 가깝다.

| 습관 | 하는 일 |
| --- | --- |
| 표현을 모은다 | 읽다가 걸린 낱말과 문장을 표시해 두고, 직접 써 본다 |
| 메모한다 | 장면, 대화, 숫자를 짧게 남겨 글감으로 쓴다 |
| 사전을 찾는다 | 뜻이 겹치는 낱말의 결을 구분한다. 「모습」과 「몰골」은 같은 대상이 아니다 |
| 분석하며 읽는다 | 잘 쓴 글에서 주제, 소재, 구성, 표현 중 무엇을 베낄지 고른다 |
| 쓰고 고친다 | 시간을 두고, 소리 내어, 가능하면 다른 사람에게 읽힌다 |

소프트웨어 문서처럼 목적이 정해진 글은 종류를 섞지 않는 편이 먼저다([[software-documentation|문서의 네 가지 유형]]).

## 정리

- 구조는 도입, 근거, 목록으로 정리한 요지, 한 줄 결론이다.
- 설득은 상대를 안 뒤 장면과 사실로 한다. 용어에서 멈추게 하지 않는다.
- 업무 글은 짧고, 하루 묵히고, 원하는 행동이 한 줄로 보이게 쓴다.
- 사실과 판단을 가르고, 판단에는 근거를 붙인다.
- 문장력은 모으고, 메모하고, 사전을 찾고, 고치는 습관이다.
