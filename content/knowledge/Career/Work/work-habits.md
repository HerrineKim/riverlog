첫 직장에서는 일 자체보다 **일하는 방식**에서 차이가 크게 난다. 직장 생활의 습관을 "커리어와 자기 관리", "업무량", "업무 전화"로 나눠 상황별로 정리한다.

## 커리어와 자기 관리

| 상황 | 습관 |
| --- | --- |
| 퇴사할 때 | **경력증명서를 챙긴다.** 이직할 때마다 요구받는다 |
| 평소 | **내가 한 일을 어딘가에 기록한다.** 나만 보는 기록이어도 이력서와 회고의 재료가 된다 |
| 3개월마다 | 이력서를 업데이트한다. 6개월이면 바뀐 것을 잊는다 |
| 첫 회사 연봉 협상 | 이후 협상의 기준점이 되므로 생각보다 중요하다 |
| 자기계발 | 업무와 관련된 것과 관련 없는 것 두 갈래로 한다. 문서 작성 능력은 어느 직군에서든 필요하므로 좋은 글을 많이 읽는다 |
| 팀장·사수와 부딪힐 때 | 적이 아니다. 솔직하게 이야기하는 편이 대부분 낫다 |
| 혼났을 때 | 변명 없이 "OO해서 죄송합니다. 앞으로는 이렇게 하겠습니다"로 짧게 인정하고 개선 방법을 말한다. 사정 설명은 감정이 가라앉은 뒤 따로 한다 |

## 업무량이 많을 때

| 상황 | 습관 |
| --- | --- |
| 같은 형식의 이메일을 자주 보낸다 | 서명·템플릿으로 저장해 두고 주어·목적어·숫자만 바꾼다 |
| 할 일이 쌓인다 | 스프레드시트로 리스트업하고 **마감일·중요도**로 정렬해 항상 켜 둔다 |
| 중요한 문서·이메일을 낸다 | 제출 직전 상태에서 출력해 펜으로 확인한다. 첨부 파일은 **직접 열어** 확인하고, 실수가 안 보이면 **거꾸로** 읽는다. 문법·맞춤법 검사기도 돌린다 |
| 꼭 해야 하는 전화가 있다 | 인사·소개·용건을 미리 적고 소리 내 읽어 본 뒤 건다 |
| 중요한 대화를 했다 | 동의를 구해 녹음하고, 다시 들으며 나에게 보내는 이메일로 요약한다 |
| 일이 막힌다 | 기존 자료를 모두 읽고 **정말 모르는 부분만** 추려서 선배에게 묻는다 |

## 업무 전화

전화는 기록이 남지 않고 즉답을 요구받기 쉬워서 업무 소통 중 실수가 가장 잦은 채널이다. 핵심은 **차분하게 받고, 적고, 확인하고, 문서로 남기는 것**이다.

| 단계 | 습관 |
| --- | --- |
| 받기 전 | 첫 멘트(소속·이름)를 속으로 한 번 읊고 받는다. 녹음이 필요하면 상대에게 알리고 동의를 구한다 |
| 통화 중 | 목소리는 낮고 차분하게. 내용은 무조건 메모한다 |
| 다른 사람을 찾는 전화 | **용건·이름·연락처**를 받아 둔다. 자리에 없으면 "잠시 자리를 비우셨습니다" 정도로만 말하고 사적인 사유는 설명하지 않는다 |
| 모르는 질문 | 추측해서 답하지 않는다. "확인 후 말씀드리겠습니다", "확인해서 메일로 정리해 드리겠습니다"로 넘긴다 |
| 끊기 전 | 상대가 원하는 것을 **구두로 다시 확인**한다 |
| 끊은 뒤 | 통화로 합의한 내용은 문서로 정리해 이메일로 보내 확인받는다. 말은 사라지고 문서는 남는다 |

## 핵심 정리

- 경력증명서·이력서·업무 기록은 미리미리.
- 할 일은 마감·중요도로 시각화하고, 반복 업무는 템플릿화.
- 중요한 결과물은 출력·재확인·거꾸로 읽기로 검수.
- 질문은 스스로 찾아본 뒤 좁혀서.
- 통화로 정한 것은 이메일로 다시 확인받는다.
