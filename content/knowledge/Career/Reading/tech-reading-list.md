언젠가 읽고 싶은 개발 서적을 분야별로 모아 둔 목록이다. ✅는 읽은 책. 같은 분야에서는 입문서 → 심화서 순으로 대략 정렬했다.

## CS 기초

### 네트워크

- 모두의 네트워크 → TCP/IP 쉽게, 더 쉽게 → HTTP 완벽 가이드 → TCP/IP 완벽 가이드
- Computer Networks: A Top-down Approach

### 운영체제

- 쉽게 배우는 운영체제 → 운영체제 아주 쉬운 세 가지 이야기(OSTEP)
- Operating System Concepts(공룡책), Modern Operating Systems

### 컴퓨터 시스템·데이터베이스

- 찰스 페졸드의 CODE, 밑바닥부터 만드는 컴퓨팅 시스템
- Computer Systems: A Programmer's Perspective, Computer Architecture
- Database Management Systems, 데이터 중심 애플리케이션 설계
- 면접을 위한 CS 전공지식 노트

### 자료구조

- 윤성우의 열혈 자료구조, 자료구조 입문(알고리즘과 그림으로 이해하고 C로 구현하는)
- 이것이 자료구조+알고리즘이다 with C 언어, C로 쓴 자료구조론

### 프로그래밍 언어론

- 코딩을 지탱하는 기술, 브루스 테이트의 세븐 랭귀지, 임백준의 폴리글랏 프로그래밍
- 컴퓨터 프로그램의 구조와 해석(SICP), 자바스크립트로 보는 SICP
- Programming Language Pragmatics, 프로그래밍 언어론 원리와 실제
- 밑바닥부터 만드는 인터프리터 in Go, Compilers: Principles, Techniques, and Tools
- 서울대 프로그래밍 언어 공개 강의(4190.310)

## 알고리즘

- **교양**: 누워서 읽는 알고리즘, 미래를 바꾼 아홉 가지 알고리즘, 알고리즘 인생을 계산하다, 마스터 알고리즘, 알고리즘이 보이는 그림책
- **이론·문제 해결**: 알고리즘 문제 해결 전략, 프로그래밍 콘테스트 챌린징, TOP CODER 알고리즘 트레이닝, 문제로 풀어보는 알고리즘
- **코딩 테스트**: 이것이 취업을 위한 코딩테스트다 with 파이썬, 파이썬 알고리즘 인터뷰, Do it! 알고리즘 코딩 테스트(자바), 한 권으로 끝내는 코딩테스트, 코딩 인터뷰 완전 분석
- **언어별**: 자바스크립트 자료구조와 알고리즘, 자바로 배우는 핵심 자료구조와 알고리즘, 고전 컴퓨터 알고리즘 인 파이썬, C로 구현한 알고리즘

## 설계·코드 품질

### 클린 코드·리팩터링·테스트

- 읽기 좋은 코드가 좋은 코드다, 클린 코드, 리팩토링 ✅, 켄트 벡의 구현 패턴
- 테스트 주도 개발, 클린 코드를 위한 테스트 주도 개발, 탐험적 테스팅
- 레거시 코드 활용 전략, 코드 컴플리트 2

### 객체지향·디자인 패턴

- 객체지향의 사실과 오해 → 오브젝트

- A Philosophy of Software Design, 객체에서 함수로

### 아키텍처

- 클린 아키텍처, 클린 소프트웨어
- 가상 면접 사례로 배우는 대규모 시스템 설계 기초
- 파이썬으로 살펴보는 아키텍처 패턴
- 마이크로서비스 아키텍처 구축, 마이크로서비스 구축과 운영
- 플랫폼 엔지니어링, Release의 모든 것

- 프론트엔드 개발자를 위한 자바스크립트 프로그래밍, 자바스크립트 핵심 가이드, 함수형 자바스크립트
