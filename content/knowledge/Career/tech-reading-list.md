개발 서적을 분야별로 묶은 목록이다. 분야마다 첫 줄에 어디서 시작하면 좋은지 적고, 같은 줄 안에서는 입문서 → 심화서 순으로 둔다.

## CS 기초

| 분야 | 입문 경로 | 책 |
| --- | --- | --- |
| 네트워크 | 그림 위주의 입문서로 계층 구조를 잡고 HTTP → TCP/IP 순으로 깊어진다 | 모두의 네트워크 → TCP/IP 쉽게, 더 쉽게 → HTTP 완벽 가이드 → TCP/IP 완벽 가이드, Computer Networks: A Top-down Approach |
| 운영체제 | 쉬운 개론서 다음 OSTEP으로 가상화·동시성·영속성을 익힌다 | 쉽게 배우는 운영체제 → 운영체제 아주 쉬운 세 가지 이야기(OSTEP), Operating System Concepts(공룡책), Modern Operating Systems |
| 컴퓨터 시스템 | 전기 신호부터 쌓아 올리는 책으로 시작한다 | 찰스 페졸드의 CODE, 밑바닥부터 만드는 컴퓨팅 시스템, Computer Systems: A Programmer's Perspective, Computer Architecture |
| 데이터베이스 | 원리서 다음 분산 시스템 관점으로 넓힌다 | Database Management Systems, 데이터 중심 애플리케이션 설계, 면접을 위한 CS 전공지식 노트 |
| 자료구조 | C로 직접 구현하는 입문서가 기본이다 | 윤성우의 열혈 자료구조, 자료구조 입문, 이것이 자료구조+알고리즘이다 with C 언어, C로 쓴 자료구조론 |
| 프로그래밍 언어론 | 여러 언어를 비교하는 교양서 다음 SICP와 인터프리터 구현으로 간다 | 코딩을 지탱하는 기술, 세븐 랭귀지, 폴리글랏 프로그래밍, SICP(자바스크립트판 포함), Programming Language Pragmatics, 프로그래밍 언어론 원리와 실제, 밑바닥부터 만드는 인터프리터 in Go, Compilers: Principles, Techniques, and Tools, 서울대 프로그래밍 언어 공개 강의(4190.310) |

## 알고리즘

교양서로 흥미를 붙이고, 코딩 테스트 대비서로 유형을 익힌 뒤 문제 해결 전략서로 깊어진다.

| 갈래 | 책 |
| --- | --- |
| 교양 | 누워서 읽는 알고리즘, 미래를 바꾼 아홉 가지 알고리즘, 알고리즘 인생을 계산하다, 마스터 알고리즘, 알고리즘이 보이는 그림책 |
| 코딩 테스트 | 이것이 취업을 위한 코딩테스트다 with 파이썬, 파이썬 알고리즘 인터뷰, Do it! 알고리즘 코딩 테스트(자바), 한 권으로 끝내는 코딩테스트, 코딩 인터뷰 완전 분석 |
| 이론·문제 해결 | 알고리즘 문제 해결 전략, 프로그래밍 콘테스트 챌린징, TOP CODER 알고리즘 트레이닝, 문제로 풀어보는 알고리즘 |
| 언어별 | 자바스크립트 자료구조와 알고리즘, 자바로 배우는 핵심 자료구조와 알고리즘, 고전 컴퓨터 알고리즘 인 파이썬, C로 구현한 알고리즘 |

## 프론트엔드·UX

언어 기본서로 자바스크립트를 단단히 하고, 사용성 고전으로 사용자 관점을 더한다.

| 갈래 | 책 |
| --- | --- |
| 자바스크립트·타입스크립트 | 프론트엔드 개발자를 위한 자바스크립트 프로그래밍, 자바스크립트 핵심 가이드, 함수형 자바스크립트, 우아한 타입스크립트 with 리액트 |
| UX·디자인 | 사용자를 생각하게 하지 마!, 대체 뭐가 문제야, 사용자를 읽는 법, 버려지는 디자인 통과되는 디자인, Creative Selection, 디자인 오브 디자인, 당당한 디자인 결정을 위한 9가지 방법, 데이터 시각화 교과서 |

## 언어·도구

쓰는 언어의 관용구를 다루는 책을 먼저 고른다. 프로그래머를 위한 파이썬, Two Scoops of Django, Node.js 디자인 패턴 바이블, Effective C#, Kubernetes in Action, 다양한 언어로 배우는 정규표현식, 유닉스의 탄생, 리눅스 그냥 재미로.
