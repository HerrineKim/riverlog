> SNS에서 돌던 이미지 「ChatGPT Cheat Sheet」를 요약·재구성한 노트입니다. 원문 번역이 아니라 프롬프트 작성법 위주로 다시 묶었고, 도구·플러그인 목록은 작성 시점 기준이라 지금은 바뀌었을 수 있습니다.

## 핵심: 역할을 주고, 지시를 구체적으로

치트시트가 말하는 「매직 프롬프트(Magic Prompt)」는 **AI에게 특정 전문가 역할을 맡기는 것**이다. 역할이 정해지면 답의 관점·어휘·깊이가 그 전문가 수준에 맞춰진다. 여기에 **분명한 지시**가 더해져야 정확하고 쓸모 있는 답이 나온다.

역할을 주는 말투는 여러 가지다. 효과는 비슷하다.

```text
Act as a Professional Marketing Consultant...
You are a Professional Marketing Consultant...
You will be my Professional Marketing Consultant...
```

## 프롬프트 만드는 7단계

| 단계 | 할 일 | 효과 |
| --- | --- | --- |
| 1. 맥락(Context) | 맡길 역할을 정한다 | 답의 기준점이 생긴다 |
| 2. 요구(Requirements) | 원하는 것이 추천인지, 해결책인지, 답인지 밝힌다 | 대화 초점이 좁혀진다 |
| 3. 과제(Task) | 수행할 작업을 구체적으로 적는다 | 결과물이 분명해진다 |
| 4. 세부 사항(Details) | 고려할 조건·배경을 덧붙인다 | 빠뜨리는 관점이 줄어든다 |
| 5. 제약(Restrictions) | 따라야 할 한계와 피할 것을 적는다 | 엉뚱한 답을 막는다 |
| 6. 형식(Format) | 결과물의 구조를 지정한다 | 바로 쓸 수 있는 모양으로 나온다 |
| 7. 예시(Examples) | 원하는 답의 샘플을 보여 준다 | 품질과 적합도가 올라간다 |

## 프롬프트 어휘

프롬프트에 넣을 요소를 키워드로 기억하는 표다.

| 키워드 | 뜻 |
| --- | --- |
| Act as | 역할·캐릭터 (예: 전문 SEO 카피라이터) |
| Tone | 말투 (친근하게, 전문적으로, 재미있게) |
| Clarity | 원하는 것을 분명히 |
| Specify | 필요한 것만, 군더더기 없이 |
| Details | 빠짐없이, 하지만 정리해서 |
| Examples | 원하는 결과를 예시로 |
| Format | 결과 형식을 보여 주기 |
| Avoid | 피할 것을 항상 명시 |
| Reality | 기대치를 현실적으로 (AI는 마음을 읽지 못한다) |
| Size | 분량·단어 수 지정 |
| Score | 스스로 점수를 매기게 하고 10/10짜리를 요구 |

## 고를 수 있는 값

| 항목 | 예 |
| --- | --- |
| 역할 | 제품 디자이너, 역사학자, 번역가, 카피라이터, UX 리서처, 데이터 사이언티스트, 법률 자문, 영양사, 커리어 코치, SEO 전문가 등 |
| 어조(Tone) | 친근한, 흥미진진한, 혁신적인, 진취적인, 안정적인, 일관된 |
| 문체(Writing style) | 전문적, 정보 전달형, 교육용, 사실 기반, 비교형, 이점 중심, 해결책 중심, 스토리텔링, 유머, 감성, 명령형, 캐주얼, 대화체 |
| 출력 형식(Format) | 표, 목록, 요약, 일반 텍스트, JSON, HTML, CSV, XML, Markdown, 글머리표, 스프레드시트, 긴 글 |

역할에는 「숙련된」「공감하는」「전략적인」 같은 수식어를 붙이는 경우가 많다. 전문성의 결을 한 번 더 지정하는 효과다.

## 제약 템플릿

`{TYPE}` 자리에 값을 넣어 프롬프트 끝에 붙여 쓴다.

```text
Language: {TYPE}로 답한다.
Tone: {TYPE} 어조를 유지한다.
Sentence length: 간결한 문장을 선호한다.
Style: {TYPE} 문체를 쓴다.
Sources: 신뢰할 수 있는 웹사이트의 정보에 근거한다.
Names: 구체적인 이름은 {Var: Name} 같은 변수로 바꾼다.
Output format: 일반 텍스트로 답한다.
```

## 추가 팁

1. **목표를 먼저 정의한다.** 무엇을 얻고 싶은지 모르면 프롬프트도 흐려진다.
2. **역할 부여는 거의 항상 이득이다.**
3. **제약과 피할 것을 항상 적는다.**
4. **세부 사항은 많을수록 좋지만, 정리해서 준다.**
5. **예시는 답의 모양을 알려 주는 가장 빠른 방법이다.**
6. **여러 챗봇을 팀처럼 쓴다.** 각자 역할을 주고, 한 모델의 결과를 다음 모델에 넘긴다.
7. **답을 평가하고 피드백한다.** 한 번에 끝내지 말고 고쳐 가며 다듬는다.

## 정리

- 프롬프트는 **역할 + 과제 + 맥락 + 제약 + 형식 + 예시**의 조합이다.
- 역할은 관점을, 제약과 형식은 결과물의 모양을 정한다.
- 어조·문체·형식은 목록에서 골라 끼우면 매번 고민하지 않아도 된다.
- 원본의 도구·플러그인 목록(Midjourney, Copy AI, Replit AI, ChatGPT 플러그인 등)은 빠르게 바뀌는 정보라 노트에서 뺐다. ChatGPT 플러그인은 이후 GPTs로 대체됐다.
- 결국 **AI는 마음을 읽지 못한다**. 원하는 것을 말로 꺼내 놓는 만큼 답이 좋아진다.
