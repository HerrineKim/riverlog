> SNS에서 돌던 「HOW TO VIBE CODE BEAUTIFUL UI」 팁 7가지를 정리한 노트입니다. 원문 번역이 아니라 요약·재구성했습니다.

## 핵심 전제: AI는 모방은 잘하고 상상은 못 한다

"모던하고 깔끔하게 만들어 줘" 같은 말은 AI가 추측할 여지만 남긴다. 그러면 결과는 늘 비슷한 기본값으로 돌아간다. 보여 줄 수 있는 건 글로 설명하지 말고 **이미지로 보여 준다**.

## 7가지 팁

### 1. 프롬프트보다 스케치 먼저

[Excalidraw](https://excalidraw.com) 같은 도구로 박스, 버튼, 이미지 자리 정도만 대충 그린 와이어프레임을 만든다. 이걸 내보내서 붙이고 **"이 구조를 그대로 따라 해"** 라고 지시한다. 레이아웃을 AI가 상상하게 두지 않는 것이 요점이다.

### 2. 마음에 드는 화면을 스크린샷으로

Dribbble, Mobbin, 혹은 깔끔하다고 느낀 아무 사이트에서 **원하는 부분만** 잘라 캡처한다. 내비게이션 바, 가격 카드, 히어로 섹션처럼 범위를 좁힐수록 좋다. 붙여 넣고 **"이 스타일을 따라 해"** 라고 하면 결과가 크게 달라진다.

### 3. 색은 무드보드로 전달

"따뜻하고 모던한 느낌"이라고 말하면 AI는 매번 비슷한 파란색을 내놓는다. 대신 이미지 생성 도구(원문은 Nano Banana류 도구를 언급)로 무드보드를 만들어 넣고 **"색 팔레트는 이걸 참고해"** 라고 한다. 운에 맡길 때보다 훨씬 개성 있는 결과가 나온다.

### 4. 만들기 전에 디자인 시스템부터

코드를 쓰기 전에 **브랜드 색, 타이포그래피, 간격 규칙**을 정해 AI에게 공유한다. 바이브 코딩한 앱이 어색해 보이는 가장 흔한 이유는 페이지 간 일관성이 전혀 없다는 것이다.

### 5. 디자인 스킬과 안티패턴 규칙 쓰기

Claude용 오픈소스 스킬 **UI/UX Pro Max**는 UI 코드를 쓰기 전에 먼저 추론 단계를 거치게 한다. 업종에 맞는 디자인 시스템을 만들어 주고, 뻔한 AI식 그라데이션 같은 패턴을 금지하는 규칙이 들어 있다. 한마디로 "다른 AI 앱처럼 보이지 마"를 강제하는 장치다.

### 6. 소통의 기본 수단을 스크린샷으로

시각 맥락을 많이 줄수록 AI가 추측할 부분이 줄어든다. "깔끔하게 해 줘"라고 쓰는 대신 **깔끔한 게 어떤 건지 직접 보여 준다**. 결과물을 고칠 때도 마찬가지로 현재 화면을 캡처해서 어디가 문제인지 짚는다.

### 7. 폰트와 아이콘이 생각보다 중요하다

AI는 거의 항상 **Inter + Lucide** 조합을 기본으로 쓴다. 보는 순간 AI가 만든 티가 난다. Google Fonts에서 개성 있는 서체를 고르고, 아이콘은 Phosphor 같은 다른 라이브러리로 바꾼다. 작은 변화지만 템플릿 같은 인상이 바로 사라진다.

## 정리

| 하지 말 것 | 대신 할 것 |
| --- | --- |
| "랜딩 페이지 만들어 줘" | 와이어프레임 + "이 구조 그대로" |
| "깔끔하게" | 레퍼런스 스크린샷 + "이 스타일로" |
| "따뜻하고 모던한 색" | 무드보드 이미지 + "이 팔레트 참고" |
| 페이지마다 즉흥 스타일 | 색·서체·간격 규칙을 먼저 정의 |
| Inter + Lucide 기본값 | 고른 서체 + 다른 아이콘 세트 |

문제는 AI가 아니라 **"랜딩 페이지 만들어 줘" 한 줄 치고 잘되길 바라는 방식**이다.
