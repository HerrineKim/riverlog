> 팔만코딩경(42Seoul 커뮤니티 위키)의 「자연어 처리 소개」를 바탕으로 재구성한 노트다.

## 자연어 처리란

자연어(natural language)는 사람이 일상에서 쓰는 언어다. 자연어 처리(Natural Language Processing, NLP)는 이 언어를 컴퓨터가 이해하고 만들어 내도록 가공하는 기술이다. 번역기, 음성 비서, 챗봇, 검색 추천, 그리고 ChatGPT·Claude 같은 대규모 언어 모델(LLM)이 모두 NLP의 산물이다.

| 응용 | 쓰이는 기술 |
| --- | --- |
| 챗봇 | 토큰화, 감성 분석, 개체명 인식(NER), 오타 정규화, 구문 분석 |
| 음성 비서 | 음성 특징 추출, 음성 인식, 언어 모델, 의도 분류 |
| 번역기 | 인코더-디코더, 어텐션, 트랜스포머 |
| 검색·추천 | 키워드 추출, 문서 유사도, 임베딩 검색 |

## 전체 흐름

NLP 모델을 만드는 과정은 머신 러닝 일반의 흐름과 같다. 딥러닝도 머신 러닝의 부분집합이기 때문이다.

```text
데이터셋 준비 → 전처리 → 모델 학습 → 평가 → 예측(서비스)
  (말뭉치)      (토큰화·      (언어 모델)   (과적합       (감성 분류,
               인코딩·패딩)                점검)         번역, 생성 …)
```

## 1. 데이터셋 준비

학습 재료가 되는 대량의 텍스트를 데이터셋 또는 **말뭉치(corpus)** 라 한다. 양만큼 중요한 것이 **과제에 맞는 말뭉치를 고르는 일**이다. 맞춤법 교정 모델이면 교정 말뭉치를, 대화 모델이면 일상 대화 말뭉치를 쓴다. 한국어는 국립국어원 「모두의 말뭉치」, AI Hub 공개 데이터, 커뮤니티가 정리한 한국어 데이터셋 목록 등에서 구할 수 있다. 공공 말뭉치는 이용 신청과 승인이 필요한 경우가 많다.

## 2. 전처리

날것의 텍스트로 학습하면 성능이 떨어진다. 전처리는 텍스트를 모델이 먹기 좋은 숫자 배열로 바꾸는 과정이다.

| 단계 | 하는 일 | 예 |
| --- | --- | --- |
| 토큰화(tokenization) | 문장을 의미 단위(토큰)로 자른다 | `Don't` → `Do` / `n't` |
| 정제(cleaning) | 목적에 맞지 않는 노이즈 제거: 특수 문자, 희귀 단어, 관사 | 대소문자 통일, 빈도 낮은 단어 삭제 |
| 정규화(normalization) | 형태가 다른 같은 단어를 하나로 | 어간 추출, 표제어 추출 |
| 불용어 제거 | 의미 기여가 적은 단어 제거 | the, a, 은/는 |
| 인코딩(encoding) | 토큰을 숫자로 | 단어 사전 → 정수 ID |
| 패딩(padding) | 길이가 다른 문장을 같은 길이로 맞춘다 | 빈자리를 0으로 채우는 제로 패딩 |

### 토큰화와 한국어

영어는 띄어쓰기와 구두점으로 대부분 잘린다. 한국어는 조사·어미가 붙는 교착어라 **형태소 분석**이 필요하다.

```text
"화분에 예쁜 꽃이 피었다."
→ 화분(명사) / 에(조사) / 예쁘(어간) / ㄴ(어미) / 꽃(명사) / 이(조사) / 피(어간) / 었(어미) / 다(어미)
```

트랜스포머 계열 모델은 형태소 대신 **서브워드(subword) 토큰화**(BPE, WordPiece, SentencePiece)를 쓴다. 자주 나오는 글자 조각을 사전에 넣어, 처음 보는 단어도 조각의 조합으로 표현한다.

### 어간 추출과 표제어 추출

| 방식 | 방법 | 예 |
| --- | --- | --- |
| 어간 추출(stemming) | 규칙으로 어미를 잘라 낸다. 품사를 모른다 | formalize → formal |
| 표제어 추출(lemmatization) | 품사와 사전을 써서 기본형을 찾는다 | is, are → be / having → have |

## 3. 텍스트를 숫자로 표현하기

| 표현 | 방법 | 한계 |
| --- | --- | --- |
| 정수 인코딩 | 빈도순 단어 사전을 만들고 단어마다 번호를 붙인다 | 번호 크기에 의미가 없다 |
| 원-핫 인코딩 | 사전 크기의 벡터에서 해당 번호 자리만 1 | 차원이 사전 크기만큼 크고, 단어 간 유사도를 담지 못한다 |
| BoW·TF-IDF | 문서를 단어 빈도 벡터로. TF-IDF는 흔한 단어의 가중치를 낮춘다 | 어순과 문맥을 버린다 |
| 단어 임베딩(Word2Vec, GloVe) | 주변 단어로 학습한 밀집 벡터. **벡터가 가까우면 뜻도 가깝다** | 단어마다 벡터가 하나라 동음이의어를 구분하지 못한다 |
| 문맥 임베딩(BERT, LLM) | 같은 단어도 문장에 따라 다른 벡터 | 모델이 크고 계산 비용이 든다 |

TF-IDF는 문서 d에서 단어 t의 중요도를 이렇게 매긴다.

```text
TF-IDF(d, t) = tf(d, t) × log( N / df(t) )
  tf(d, t): 문서 d에서 t가 나온 횟수
  df(t):    t가 나온 문서 수,  N: 전체 문서 수
```

벡터끼리의 비슷함은 코사인 유사도, 유클리드 거리, 자카드 유사도로 재고, 문자열 자체의 비슷함은 편집 거리(레벤슈타인 거리)로 잰다. 자세한 계산은 [[text-similarity|문자열·문서 유사도]]에 있다.

## 4. 언어 모델

언어 모델(language model)은 **단어 나열이 나올 확률을 계산하는 모델**이다. "나는 밥을 먹는다"가 "나는 밥을 먹힌다"보다 확률이 높다고 판단하고, 다음 단어를 예측한다.

| 세대 | 모델 | 핵심 |
| --- | --- | --- |
| 통계 기반 | n-gram | 앞의 n−1개 단어만 보고 다음 단어 확률을 센다. 긴 문맥을 못 보고, 처음 보는 조합은 확률 0이 되는 희소성 문제가 있다 |
| 순환 신경망 | RNN, LSTM, GRU | 문장을 시간 순서대로 읽으며 상태를 넘긴다. 길면 앞 정보가 흐려진다 |
| 어텐션 | seq2seq + 어텐션 | 출력할 때 입력의 필요한 부분에 집중한다 |
| 트랜스포머 | BERT(인코더), GPT(디코더) | 셀프 어텐션으로 모든 단어 쌍의 관계를 병렬로 계산한다 |
| 대규모 언어 모델 | GPT·Claude·Gemini 계열 | 거대한 트랜스포머를 방대한 텍스트로 사전 학습한 뒤, 지시 따르기·사람 선호에 맞게 추가 학습한다 |

## 5. 평가와 예측

학습 데이터에서는 잘 맞는데 처음 보는 테스트 데이터에서 성능이 크게 떨어지면 **과적합**이다. 그래서 학습에 쓰지 않은 데이터로 따로 평가한다. 분류 과제는 정밀도·재현율·F1로, 생성 과제는 퍼플렉서티(perplexity)나 BLEU·사람 평가로 잰다. 평가를 통과한 모델에 새 입력을 넣어 감성 분류·번역 같은 과제 결과를 얻는 것이 예측 단계다.

## 정리

- NLP 모델은 데이터셋 → 전처리 → 학습 → 평가 → 예측 순서로 만든다.
- 전처리는 토큰화·정제·정규화·인코딩·패딩이고, 한국어는 형태소 분석이나 서브워드 토큰화가 필요하다.
- 텍스트 표현은 원-핫·TF-IDF 같은 희소 벡터에서 임베딩·문맥 임베딩 같은 밀집 벡터로 발전했다.
- 언어 모델은 n-gram → RNN → 트랜스포머 → LLM으로 이어지며 긴 문맥을 다루는 능력이 커졌다.
- **좋은 NLP 모델의 출발점은 과제에 맞는 말뭉치와 깨끗한 전처리다.**
