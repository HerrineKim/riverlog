차트 이름부터 고르면 데이터에 안 맞는 그림이 나오기 쉽다. **"이 데이터에서 무엇을 보고 싶은가"** 를 먼저 정하면 후보가 두세 개로 줄어든다. 채널과 지각의 원리는 [[visual-encoding|시각화 인코딩]]에, 고른 차트를 다듬는 규칙은 [[chart-design-principles|그래프 디자인 원칙]]에 있다.

## 수량: 항목별 크기 비교

### 막대 도표

범주마다 하나의 수치(브랜드별 판매량, 도시별 인구)를 비교할 때 쓴다.

- 레이블이 길면 **가로 막대**로 돌린다. 레이블을 기울이면 공간은 아끼지만 읽기 어렵다.
- **순서를 의미 있게 정한다.** 범주에 자연스러운 순서(연령대)가 없으면 값 크기순으로 정렬한다. 알파벳순은 찾기는 쉽지만 요점이 안 보인다.
- 두 범주를 함께 보여 주는 **묶은 막대**는 한쪽 기준 비교는 쉽지만 다른 쪽 비교가 어렵다. 어느 비교가 중요한지 정하거나, 범주별로 작은 막대 차트를 나란히 놓는다(면분할).
- **누적 막대**는 쌓은 합계가 의미 있을 때만 쓴다(객실 등급별 남녀 탑승객 → 등급별 총인원). 막대 안에 값을 직접 적으면 y축을 생략할 수도 있다.

### 점 도표와 히트맵

막대는 0에서 시작해야 길이가 값에 비례한다(잉크 비례 원칙). 값들이 60~80처럼 좁은 범위에 몰려 있으면 막대로는 차이가 안 보인다. **점 도표(dot plot)** 는 길이가 아니라 위치로 값을 나타내므로 축을 데이터 범위로 좁혀도 왜곡이 없다.

항목 수와 시점 수가 모두 많으면(국가 × 연도별 인터넷 보급률) 막대나 점으로는 감당이 안 된다. **히트맵**은 값을 색으로 바꿔 전체 추세를 한 장에 보여 준다. 정확한 값 비교는 포기하는 대신이다. 행의 정렬 기준(최근 값 순, 특정 임계값을 처음 넘은 연도 순)에 따라 드러나는 이야기가 달라진다.

## 분포: 값이 어떻게 퍼져 있나

### 하나의 분포

| 차트 | 장점 | 주의 |
| --- | --- | --- |
| 히스토그램 | 직관적이다 | **구간 폭**에 따라 모양이 달라진다. 너무 좁으면 들쭉날쭉, 너무 넓으면 특징이 뭉개진다. 몇 가지 폭으로 그려 본다 |
| 밀도 도표(KDE) | 매끄러운 곡선, 곡선 아래 넓이가 1 | 추정치라 대역폭에 따라 모양이 바뀌고, 나이가 음수인 구간처럼 데이터가 없는 곳까지 곡선이 뻗을 수 있다 |
| 경험적 누적 분포(ECDF) | 모든 점을 그대로 쓰면서 분포를 보여 준다. 구간 폭 같은 선택이 없다 | 처음 보는 사람에게는 읽는 법이 낯설다. y축을 비율(0~1)로 두면 "하위 50%가 몇 점 이하"를 바로 읽는다 |

히스토그램과 밀도 도표는 원데이터라기보다 **데이터에 대한 해석**이라는 점을 기억한다.

### 여러 분포 비교

| 차트 | 언제 |
| --- | --- |
| 겹친 히스토그램 | 두 집단까지. 누적해서 쌓으면 막대의 시작점이 헷갈리고, 반투명으로 겹치면 세 번째 범주처럼 보이는 색이 생긴다 |
| 겹친 밀도 도표 | 두세 집단. 시작·끝이 분명하다. 전체 분포를 회색 배경으로 깔고 집단별로 나눠 그리면 더 잘 읽힌다 |
| 연령 피라미드 | 두 집단(남녀)의 히스토그램을 좌우로 맞댄다. 세 집단 이상은 못 그린다 |
| 평균 + 오차 막대 | 간단하지만 분포 모양(쌍봉, 치우침)을 숨긴다 |
| 박스 도표 | 중앙값, 사분위(Q1~Q3, 가운데 50%), 수염, 이상치를 간결하게. 집단이 많을 때 좋다 |
| 바이올린 도표 | 박스보다 분포 모양을 잘 보여 준다. 데이터가 충분해야 매끄럽다 |
| 스트립 차트 + 지터 | 점을 다 찍고 좌우로 살짝 흩뿌려 겹침을 푼다. 데이터가 적을 때 정직하다 |
| 시나 도표 | 바이올린 모양 안에 지터한 점을 찍는다. 분포 모양과 개별 점을 함께 |
| 융기선(ridgeline) 도표 | 여러 밀도 곡선을 산등성이처럼 위아래로 겹친다. 시간에 따른 분포 변화(연도별 영화 상영 시간)를 볼 때 |

```python
import seaborn as sns

sns.histplot(df, x="age", bins=20)                     # 구간 수를 바꿔 가며 확인
sns.ecdfplot(df, x="score", stat="proportion")
sns.violinplot(df, x="group", y="value", inner="quart")
sns.stripplot(df, x="group", y="value", jitter=0.2, alpha=0.5)
```

## 비율: 전체 중 얼마인가

### 한 범주의 비율

| 할 수 있는 것 | 파이 | 누적 막대 | 병렬 막대 |
| --- | --- | --- | --- |
| 전체 대비 비율이 분명하다 | ○ | ○ | |
| 조각끼리 상대 비교가 쉽다 | | | ○ |
| 1/2, 1/4 같은 단순 분수가 잘 보인다 | ○ | | |
| 조각이 아주 적어도 보기 좋다 | ○ | | ○ |
| 조각이 많아도 된다 | | | ○ |
| 시간에 따른 비율 변화를 보여 준다 | | ○ | ○ |

- 파이 여러 개로 연도별 점유율을 비교하면 추이가 거의 안 보인다. 각도는 길이보다 비교하기 어렵다.
- 누적 막대에서 바닥과 꼭대기에 붙은 조각은 변화가 잘 보이지만 가운데 조각은 기준선이 움직여 비교가 어렵다. 조각이 두 개(남녀 성비)면 이 문제가 없다.
- 연속 변수(나이)에 따른 비율 변화는 **누적 밀도**로 그릴 수 있다. 다만 일부 범주가 급격히 변하면 나머지가 읽히지 않으므로, 그럴 때는 범주마다 "이 범주 대 나머지"를 따로 그린다.

### 내포 비율: 범주 안의 범주

정당별 성비, 건설 자재별 건설 시기처럼 한 범주 아래 또 범주가 있는 데이터다.

- 두 범주를 한 파이에 넣으면 같은 대상을 두 번 세어 합이 100%를 넘는 실수가 생긴다.
- **모자이크 도표**: 가로 폭과 세로 높이로 두 범주의 비율을 함께 나타낸다. 가로 범주에 따른 차이를 강조하기 좋다.
- **트리맵**: 사각형을 계층적으로 쪼갠다. 상위 범주가 서로 무관한 묶음(미국의 주 → 카운티)일 때 공간 효율이 좋다. 사각형 모양이 제각각이라 크기 비교가 어려우니 숫자나 백분율을 함께 적는다.
- **내포 파이(도넛 두 겹)**: 안쪽·바깥쪽 원에 범주를 하나씩 둔다. 조각이 작아 레이블이 안 들어가고 공간 효율이 낮다.
- **평행 집합(parallel sets)**: 범주 축을 나란히 세우고 띠로 잇는다. 범주가 셋 이상일 때 강하다. 색칠 기준과 축 순서를 바꾸면 띠의 교차가 줄어 훨씬 읽기 쉬워진다.

## 관계: 두 변수는 같이 움직이나

| 차트 | 쓰임 |
| --- | --- |
| 산점도 | 점 하나가 관측 하나. 점의 퍼진 모양으로 관계를 본다. 색으로 범주를 더하면 집단 비교도 된다 |
| 버블 차트 | 점 크기로 세 번째 변수를 더한다. 위치와 크기를 동시에 읽어야 해서 혼란스럽고 크기 범위에 한계가 있다 |
| 산점도 행렬 | 모든 변수 쌍의 산점도를 격자로. EDA 첫 단계에 좋다 |
| 상관 행렬(correlogram) | 상관계수(-1~1)를 색이나 원 크기로. 변수가 많을 때 간결하지만, 상관계수만으로는 관계의 모양을 모른다(앤스컴 콰르텟) |

**쌍 데이터(paired data)** 는 같은 대상을 조건만 달리해 두 번 잰 데이터다(왼팔·오른팔, 2000년·2020년 배출량).

- 대상이 많으면 x=전, y=후로 산점도를 그리고 **y=x 대각선**을 긋는다. 선 위는 증가, 아래는 감소다.
- 대상이 적으면 **경사 차트(slopegraph)**: 두 시점을 세로축 두 개에 놓고 대상마다 선으로 잇는다. 기울기가 변화의 방향과 크기다. 시점이 셋 이상이면 오른쪽으로 축을 늘린다.

```python
sns.pairplot(df, hue="species")
sns.heatmap(df.corr(numeric_only=True), cmap="RdBu_r", vmin=-1, vmax=1, annot=True)
```

## 시계열: 시간에 따라 어떻게 변하나

- 시간 순서대로 점만 찍으면 시간의 흐름이 잘 안 느껴진다. **선으로 이으면** 흐름이 드러난다. 선은 데이터가 아니라 추세를 따라가게 돕는 안내선이다.
- 점이 많으면 점을 빼고 선만 남긴다. 계열이 하나면 선 아래를 칠해 흐름을 강조할 수 있다.
- 계열이 여럿이면 범례 대신 **선 끝에 이름을 직접** 붙인다. 범례를 오가며 맞추는 부담이 사라진다.
- 시간이 아니어도 순서가 있는 x(비료 투입량에 따른 수확량, 용량-반응 곡선)라면 선 그래프를 쓴다.

### 추세 보여 주기

| 방법 | 원리 | 특징 |
| --- | --- | --- |
| 이동 평균 | 일정 구간의 평균을 한 칸씩 밀며 계산 | 단순하다. 창 크기만큼 앞쪽 데이터가 비고, 창이 크면 반응이 늦다 |
| LOESS | 구간마다 낮은 차수의 다항식을 국소적으로 적합 | 이동 평균보다 매끄럽고, 시계열이 아닌 산점도에도 쓴다 |
| 스플라인 | 제어점 사이 구간을 곡선으로 적합 | 종류와 매듭 수에 따라 결과가 달라진다 |
| 정해진 함수 적합 | 직선(y = a + bx), 지수(y = a·e^(bx)) 등 형식을 정하고 계수를 찾는다 | 성장 법칙을 알고 있을 때. 지수 성장은 로그 축에서 직선이 된다 |
| 추세 제거(detrending) | 장기 추세를 빼고 남은 편차만 그린다 | 물가 상승 같은 큰 흐름에 가려진 지역별 차이가 드러난다 |

```python
import numpy as np

ts["ma_30"] = ts["close"].rolling(30).mean()           # 30일 이동 평균
slope, intercept = np.polyfit(x, y, 1)                  # 선형 추세
```

## 정리

- 차트는 질문으로 고른다. 크기, 분포, 비율, 관계, 시간 변화 중 무엇을 보려는지 먼저 정한다.
- 막대는 0에서 시작해야 하므로 범위가 좁은 값은 점 도표로, 항목이 많으면 히트맵으로 넘어간다.
- 분포 차트는 구간 폭과 대역폭이 모양을 바꾼다. ECDF나 점 찍기로 원데이터를 함께 확인한다.
- 비율은 조각이 적고 단순할 때 파이, 비교와 시간 변화가 중요하면 막대. 범주가 겹치면 모자이크·트리맵·평행 집합.
- 시계열은 선으로 잇고, 직접 레이블을 붙이고, 노이즈가 많으면 평활 곡선을 겹친다.
