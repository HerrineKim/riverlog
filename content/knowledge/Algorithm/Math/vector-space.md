## 벡터공간이란

벡터공간(vector space)은 화살표나 좌표 묶음이 아니라 두 연산이 정해진 규칙을 지키는 집합이다. 체(field) F 위의 벡터공간 V는 공집합이 아닌 집합으로, 다음 두 연산이 정의되어 있다.

| 연산 | 정의 |
| --- | --- |
| 벡터 덧셈 | V의 두 원소 x, y에 V의 원소 x + y 하나를 대응 |
| 스칼라 곱 | F의 원소 a와 V의 원소 x에 V의 원소 ax 하나를 대응 |

**체(field)** 는 덧셈·뺄셈·곱셈·(0이 아닌 수로) 나눗셈이 자유로운 수 체계다. 실수 ℝ, 복소수 ℂ, 유리수 ℚ가 체이고, 정수 ℤ는 나눗셈이 닫혀 있지 않아 체가 아니다. 체의 원소를 **스칼라**라 부른다. 벡터공간 안에는 벡터만 있으므로, 스칼라 곱의 다른 피연산자를 가져올 곳으로 체를 함께 정의한다. 이렇게 정한 공간을 "F-벡터공간 V"라고 쓴다.

## 공리 8가지

모든 x, y, z ∈ V와 a, b ∈ F에 대해

| 번호 | 성질 | 식 |
| --- | --- | --- |
| VS1 | 덧셈의 교환법칙 | x + y = y + x |
| VS2 | 덧셈의 결합법칙 | (x + y) + z = x + (y + z) |
| VS3 | 덧셈의 항등원 | 모든 x에 대해 x + 0 = x인 **하나의** 0 ∈ V가 있다 |
| VS4 | 덧셈의 역원 | **각** x마다 x + y = 0인 y ∈ V가 있다 |
| VS5 | 스칼라 곱의 항등원 | 1x = x |
| VS6 | 스칼라 곱의 결합법칙 | (ab)x = a(bx) |
| VS7 | 벡터에 대한 분배법칙 | a(x + y) = ax + ay |
| VS8 | 스칼라에 대한 분배법칙 | (a + b)x = ax + bx |

VS3과 VS4의 차이에 주의한다. VS3은 **모든 벡터에 공통인 영벡터 하나**가 존재한다는 뜻이고, VS4는 **벡터마다 자기 역원**이 존재한다는 뜻이다.

"S가 벡터공간임을 보여라"는 두 연산이 S 안에서 닫혀 있고 8가지 공리를 모두 만족함을 확인하라는 뜻이다. "벡터공간이 아님을 보여라"는 성립하지 않는 공리 하나만 찾으면 된다.

## 공리에서 바로 나오는 성질

| 정리 | 내용 | 근거 |
| --- | --- | --- |
| 소거법칙 | x + z = y + z이면 x = y | 양변에 z의 역원을 더하고 VS2, VS4, VS3 |
| 영벡터의 유일성 | VS3의 0은 하나뿐이다 | 0과 0′ 모두 항등원이면 x + 0 = x + 0′ → 소거법칙 |
| 역원의 유일성 | 각 x의 역원은 하나뿐이다 → −x로 쓴다 | x + y = x + y′ = 0 → 소거법칙 |
| 스칼라 0 | 0x = **0** (좌변 0은 스칼라, 우변은 영벡터) | 0x = (0 + 0)x = 0x + 0x에 소거법칙 |
| 부호 | (−a)x = −(ax) = a(−x) | 역원의 유일성 |
| 영벡터 곱 | a**0** = **0** | a**0** = a(**0** + **0**) = a**0** + a**0** |

당연해 보이는 성질도 공리만으로 증명해야 한다. 그래야 실수 좌표가 아닌 다항식·함수·행렬로 이루어진 공간에서도 똑같이 쓸 수 있다.

## 부분공간

V의 부분집합 W가 V와 같은 연산으로 그 자체로 벡터공간이 되면 W를 V의 부분공간(subspace)이라 한다. 모든 V에서 V 자신과 {**0**}은 부분공간이다. 공집합은 영벡터가 없어(VS3 위반) 부분공간이 아니다.

8가지 공리를 다시 확인할 필요는 없다. 연산이 V에서 물려받은 것이라 교환·결합·분배법칙은 저절로 성립하기 때문이다. 세 가지만 확인하면 된다.

```text
W가 V의 부분공간  ⇔  ① 0 ∈ W
                     ② x, y ∈ W 이면 x + y ∈ W   (덧셈에 닫힘)
                     ③ x ∈ W, a ∈ F 이면 ax ∈ W  (스칼라 곱에 닫힘)
```

①은 W가 비어 있지 않음을 보장하고, W의 영벡터가 V의 영벡터와 같다는 뜻이다. 역원은 ③에서 a = −1로 두면 따라 나온다.

## 교집합, 합공간, 직합

- **교집합**: 부분공간들의 교집합은 언제나 부분공간이다. 영벡터를 모두 포함하고, 각 부분공간에서 닫혀 있으면 교집합에서도 닫혀 있다.
- **합집합은 일반적으로 부분공간이 아니다.** ℝ²에서 x축과 y축의 합집합(+ 모양)은 (1, 0) + (0, 1) = (1, 1)을 담지 못한다. 한쪽이 다른 쪽에 포함될 때만 예외다.
- **합공간**: 두 부분공간을 모두 담는 가장 작은 부분공간은 합 `W₁ + W₂ = {x + y | x ∈ W₁, y ∈ W₂}`다. 위의 세 조건을 만족해 부분공간이 된다.
- **직합(direct sum)**: `V = W₁ + W₂`이고 `W₁ ∩ W₂ = {0}`이면 `V = W₁ ⊕ W₂`로 쓴다. 이는 V의 모든 벡터를 x + y (x ∈ W₁, y ∈ W₂)로 쓰는 방법이 유일하다는 것과 동치다.

```text
두 부분공간을 담는 부분공간 U 중
  가장 큰 공통 부분:  W₁ ∩ W₂   (둘 다에 포함되는 최대 부분공간)
  가장 작은 포함체:   W₁ + W₂   (둘 다를 포함하는 최소 부분공간)
```

## 일차결합과 생성공간

- **일차결합(linear combination)**: 유한개의 벡터 u₁, …, uₙ과 스칼라 a₁, …, aₙ으로 만든 `a₁u₁ + … + aₙuₙ`.
- **생성공간(span)**: 집합 S의 벡터로 만들 수 있는 모든 일차결합의 집합 span(S). 편의상 span(∅) = {**0**}으로 정한다.
- span(S)는 S를 포함하는 가장 작은 부분공간이다. 일차결합끼리 더하거나 상수배해도 일차결합이므로 부분공간이고, S를 포함하는 부분공간은 덧셈·스칼라 곱에 닫혀 있어 S의 모든 일차결합을 반드시 담기 때문이다.
- span(S) = V이면 S가 V를 **생성(generate)** 한다고 하고, S를 생성집합이라 부른다. 예: ℝ³에서 {(1,0,0), (0,1,0)}의 생성공간은 xy 평면이다.

같은 공간을 생성하는 집합은 여러 개다. 불필요한 벡터를 덜어낸 가장 작은 생성집합이 **기저(basis)** 이고, 그 원소 수가 **차원(dimension)** 이다. 이는 일차독립·종속 개념으로 이어진다.

## 정리

- 벡터공간은 덧셈과 스칼라 곱이 8가지 공리를 지키는 집합이다. 스칼라는 체에서 온다.
- 영벡터와 역원의 유일성, 0x = **0** 같은 성질은 소거법칙에서 나온다.
- 부분공간 판정은 영벡터 포함 + 덧셈·스칼라 곱에 닫힘, 세 가지면 충분하다.
- 교집합과 합공간은 부분공간이지만 합집합은 아니다. 교집합이 {**0**}인 합은 직합이다.
- span(S)는 S를 포함하는 최소 부분공간이다.
