> Shahjalal Shohag의 「[A List of Useful Equations in Competitive Programming](https://shahjalalshohag.com/blog/equation-list)」(2022.03)을 바탕으로 재구성한 노트다. 순열에 대한 바닥 합의 최솟값은 IMO 2021 숏리스트 A3(같은 저자)의 결과를 보강했다.

이 노트는 식을 찾아보는 참조표다. 조합·정수론을 처음 보는 설명은 여기 두지 않는다. 이항 계수의 정의, 파스칼 점화식, 중복 조합은 [[permutation-combination|순열과 조합]], gcd·φ·μ·페르마의 소정리·윌슨 정리는 [[number-theory-basics|정수론 기초]], 비트 관용구는 [[bit-manipulation|비트 연산 기법]]에 있다.

아래 `C(n, k)`는 이항 계수, `n ≥ k ≥ 0`이 아니면 0이다. 합의 빈 범위는 0이다.

## 이항 계수

| 식 | 이름·뜻 |
| --- | --- |
| `C(n, k) = C(n, n−k)` | 대칭. 정의는 [[permutation-combination\|순열과 조합]] |
| `k·C(n, k) = n·C(n−1, k−1)` | 흡수. `C(n, k) = n/k · C(n−1, k−1)` |
| `Σ_i C(n, i) = 2^n` | 부분집합의 수 |
| `Σ_i C(n, 2i) = Σ_i C(n, 2i+1) = 2^(n−1)` | n ≥ 1일 때 짝수 개·홀수 개 부분집합이 같다 |
| `Σ_{i=0..k} (−1)^i C(n, i) = (−1)^k C(n−1, k)` | 부분 교대합 |
| `Σ_{i=0..k} C(n+i, i) = C(n+k+1, k)` | 하키 스틱의 한 형태 |
| `Σ_{i=r..n} C(i, r) = C(n+1, r+1)` | 하키 스틱. n > r인 자연수 |
| `Σ_i i·C(n, i) = n·2^(n−1)` | 원소 하나를 고정하고 나머지를 자유로이 |
| `Σ_i i²·C(n, i) = n(n+1)·2^(n−2)` | |
| `Σ_k C(m, k) C(n, r−k) = C(m+n, r)` | 방데르몽드 |
| `Σ_i C(k, i)² = C(2k, k)` | 방데르몽드에서 m = n = r = k |
| `Σ_{k=q..n} C(n, k) C(k, q) = 2^(n−q) · C(n, q)` | |
| `Σ_i k^i C(n, i) = (k+1)^n` | 이항 정리에 a = k, b = 1 |
| `Σ_{i=0..n} C(2n, i) = 2^(2n−1) + C(2n, n) / 2` | 가운데 항만 한 번 세고 양쪽은 같다 |
| `Σ_i C(n, i) C(n−1, i−1) = C(2n−1, n−1)` | |
| `Σ_{i 홀수} C(n, i) a^(n−i) b^i = ((a+b)^n − (a−b)^n) / 2` | 짝수 거듭제곱은 빠진다 |

n의 이진 표현에 1이 x개 있으면, 파스칼 삼각형 n번째 줄의 홀수 항은 `2^x`개다. 따라서 `2^n − 1`번째 줄은 전부 홀수다. 소수 p에 대해 p번째 줄의 양 끝 1을 뺀 항은 모두 p의 배수다. 역으로, n ≥ 2가 소수인 것은 `C(n, 1), …, C(n, n−1)`이 모두 n으로 나누어떨어지는 것과 같다.

**쿠머(Kummer):** 소수 p가 `C(n, m)`을 나누는 지수는, m과 n−m을 p진법으로 더할 때 받아올림이 일어나는 횟수다. 그래서 2가 `C(2n, n)`을 나누는 지수는 n의 이진 표현에서 1의 개수다.

**뤼카(Lucas):** p가 소수이고 m, n을 p진법 `m = Σ m_i p^i`, `n = Σ n_i p^i`(0 ≤ 자리 < p)로 쓰면 `C(m, n) ≡ Π C(m_i, n_i) (mod p)`. 어느 자리에서 n_i > m_i이면 0이다. n < p일 때 팩토리얼 역원으로 `C(n, k) mod p`를 구하는 법은 [[number-theory-basics|정수론 기초]]에 있다.

`Σ_i C(n, i) · i^k`는 i를 그대로 돌면 O(n)이다. 제2종 스털링 수 `S(k, j)`로 쓰면 `Σ_{j=0..k} S(k, j) · n(n−1)…(n−j+1) · 2^(n−j)`라서, S를 O(k²)에 채우면 지수가 아니라 k에 의존한다.

이항 반전: `P(n) = Σ_{k=0..n} C(n, k) Q(k)`이면 `Q(n) = Σ_{k=0..n} (−1)^(n−k) C(n, k) P(k)`. 앞에 (−1)^k가 붙은 형태는 자기 자신이 역변환이다. 수열 x_0, x_1, …의 이웃끼리 합을 n번 반복하면, n번째 줄의 첫 칸은 `Σ_k C(n, k) x_k`다.

음이 아닌 정수해의 개수 `x_1 + … + x_k = n`은 `C(n+k−1, n)`이다. 1 이상 b 이하에서 n개를 고르되 고른 수를 정렬했을 때 이웃 차이가 k 이상이면 `C(b − (n−1)(k−1), n)`이다. 서로 다른 n명을 크기 k인 이름 없는 조 `n/k`개로 나누는 수는 `n! / ((k!)^(n/k) · (n/k)!)`이다(n이 k의 배수일 때).

## 카탈란 수와 이웃한 수열

**카탈란 수** `C_n = C(2n, n) / (n+1)`, `C_0 = 1`, `C_n = Σ_{i=0..n−1} C_i C_(n−1−i)`.

| 세는 대상 | 조건 |
| --- | --- |
| 올바른 괄호 | 여는 괄호 n개, 닫는 괄호 n개 |
| 곱셈 결합 | 인수 n+1개의 괄호 치는 방법 |
| 볼록 (n+2)각형의 삼각분할 | 꼭짓점은 고정, 대각선은 안에서만 |
| 원 위의 2n개 점을 n개의 현으로 | 현끼리 교차하지 않음 |
| 격자 (0,0) → (n,n) | 대각선 y = x 위로 올라가지 않는 최단 경로 |
| 꽉 찬 이진 트리 | 잎이 n+1개, 정점 번호는 없음. 모든 정점의 자식은 0개 또는 2개 |
| 길이 3 패턴을 피하는 순열 | `{1,…,n}`의 순열 중 123처럼 길이 3인 패턴 하나를 피하는 것. 길이 3 패턴 여섯 가지 모두 개수가 같다 |

앞에 여는 괄호가 k개 이미 있는, 총 n+k쌍의 올바른 괄호 문자열 수는 `(k+1)/(n+k+1) · C(2n+k, n)`이다.

**나라야나 수** `N(n, k) = C(n, k) C(n, k−1) / n`. 괄호 n쌍이 올바르고, 부분문자열 `()`가 k번 나오는 문자열의 수다. `N(4, 2) = 6`.

**완전순열(derangement)** 은 모든 원소가 제자리가 아닌 순열이다. `d(0) = 1`, `d(1) = 0`, `d(n) = (n−1) (d(n−1) + d(n−2))`.

**대합(involution)** 은 두 번 적용하면 항등인 순열, 즉 사이클 길이가 1 또는 2뿐이다. `a_0 = a_1 = 1`, `a_n = a_(n−1) + (n−1) a_(n−2)`.

사이클 길이가 전부 k 이하인 순열의 수 `T(n, k)`는 n ≤ k이면 `n!`이고, n > k이면 `n·T(n−1, k) − P(n−1, k)·T(n−k−1, k)`이다. `P(n, k) = n(n−1)…(n−k+1)`, `T(0, k) = 1`, 음수 크기는 0이다. k = 2이면 대합과 같다.

### 스털링 수와 벨 수

| | 제1종(부호 없는 것) | 제2종 |
| --- | --- | --- |
| 뜻 | n개를 k개의 사이클(길이 1 포함)로 나누는 순열 수 | n개를 비어 있지 않은 k개 집합으로 분할하는 수 |
| 점화식 | `s(n, k) = (n−1) s(n−1, k) + s(n−1, k−1)` | `S(n, k) = k·S(n−1, k) + S(n−1, k−1)` |
| 초기값 | `s(0,0) = 1`, n이나 k만 0이면 0 | 같다 |
| 바로 나오는 값 | `Σ_k s(n, k) = n!` | `S(n, 2) = 2^(n−1) − 1`. `S(n, k)·k!`은 n개를 k색으로 칠하되 모든 색을 쓰는 방법 |

상승 팩토리얼 `x(x+1)…(x+n−1) = Σ_k s(n, k) x^k`. 제1종에서 `s(n, n−k)`는 `0 ≤ i_1 < … < i_k < n`인 곱 `i_1…i_k`의 합이다.

각 집합의 크기가 r 이상인 분할의 수(r-연관 제2종) `S_r`는 `S_r(n+1, k) = k·S_r(n, k) + C(n, r−1) S_r(n−r+1, k−1)`. 한 집합 안 원소의 차가 모두 d 이상인 분할 수 `S^d(n, k)`는 `n ≥ k ≥ d`일 때 보통의 `S(n−d+1, k−d+1)`과 같다.

**벨 수** `B_n = Σ_k S(n, k)`는 n개 집합의 분할 전체다. `B_0 = 1`, `B_(n+1) = Σ_{k=0..n} C(n, k) B_k`.

## 피보나치

`F_0 = 0`, `F_1 = 1`, `F_n = F_(n−1) + F_(n−2)`.

| 식 | |
| --- | --- |
| `F_n = Σ_{k=0..⌊(n−1)/2⌋} C(n−k−1, k)` | 이항 계수 합 |
| `F_n = (φ^n − ψ^n) / √5`, `φ = (1+√5)/2`, `ψ = (1−√5)/2` | 비네 공식 |
| `Σ_{i=1..n} F_i = F_(n+2) − 1` | |
| `Σ_{i=0..n−1} F_(2i+1) = F_(2n)`, `Σ_{i=1..n} F_(2i) = F_(2n+1) − 1` | |
| `Σ_{i=1..n} F_i² = F_n F_(n+1)` | |
| `F_(m+n) = F_(m+1) F_n + F_m F_(n−1)` | 덧셈 공식. `F_(2n) = F_n (F_(n+1) + F_(n−1))` |
| `gcd(F_m, F_n) = F_gcd(m, n)` | |
| `F_k`가 `F_n`을 나눔 | k가 n의 약수일 때. 특히 세 번째마다 짝수 |
| 이웃한 세 항 | `gcd(F_n, F_(n+1)) = gcd(F_n, F_(n+2)) = gcd(F_(n+1), F_(n+2)) = 1` |

n이 피보나치 수인 것은 `5n² + 4` 또는 `5n² − 4` 중 적어도 하나가 제곱수인 것과 같다. `F_n mod m`은 주기적이고, 그 주기(피사노 주기)는 6m 이하이다.

## 바닥 함수, 대푯값, 다항식

양의 정수 m, n과 실수 x에 대해 `⌊⌊x/m⌋ / n⌋ = ⌊x/(mn)⌋`, 올림도 같다.

양의 정수 a, b, c에서 `a·b ≤ c`는 `a ≤ ⌊c/b⌋`와 같다. `a·b > c`는 `a > ⌊c/b⌋`와 같다. `a·b < c`는 `a < ⌊c/b⌋`가 **아니다**. `a = 2, b = 3, c = 7`이면 6 < 7이지만 `⌊7/3⌋ = 2`라서 a가 그보다 작지 않다. 맞는 조건은 `a ≤ ⌊(c−1)/b⌋`이다. `a·b ≥ c`이면 `a ≥ ⌊c/b⌋`이지만, 필요충분조건은 `a ≥ ⌈c/b⌉`이다.

세 수 a, b, c에 대해 `|a−b| + |b−c| + |c−a| = 2 (max − min)`. `min(a+b, c) = a + min(b, c−a)`는 실수 전체에서 성립한다.

수들의 L1 거리 합 `|a_1−x| + … + |a_n−x|`를 최소로 하는 x는 중앙값이다. n이 짝수면 가운데 두 값 사이의 어느 값이든 된다. 제곱 합을 최소로 하는 x는 평균이다.

음이 아닌 수 a_i에 대해, 모든 부분집합의 원소 곱의 합은 `Π (1 + a_i)`이다.

`Σ_{i=1..n} i·i! = (n+1)! − 1`. `Σ_{i=1..n} i a^i = a (1 − (n+1) a^n + n a^(n+1)) / (a−1)²` (a ≠ 1).

**비에타:** `p(x) = a_n x^n + … + a_0`(a_n ≠ 0)의 근을 r_1, …, r_n이라 하면, 서로 다른 k개의 근을 곱한 합은 `(−1)^k a_(n−k) / a_n`이다. k = 1이면 합이 `−a_(n−1)/a_n`, k = n이면 곱이 `(−1)^n a_0/a_n`.

**라그랑주 항등식:** `(Σ a_k²)(Σ b_k²) − (Σ a_k b_k)² = Σ_{i<j} (a_i b_j − a_j b_i)²`.

### 순열에서 바닥의 합

양의 정수 n과 `{1,…,n}`의 순열 a에 대해 `Σ_{k=1..n} ⌊a_k / k⌋`의 최솟값은 `⌊log2 n⌋ + 1`이다. `2^k ≤ n < 2^(k+1)`이면 답은 k+1이다.

한 가지 구성은 구간 `[2^j, min(2^(j+1)−1, n)]`마다 맨 앞 자리에 그 구간의 최댓값을 두고, 나머지는 한 칸씩 앞으로 당기는 것이다. 맨 앞만 바닥이 1이고 나머지는 0이라 구간마다 합이 1이다. 구간이 k+1개다.

이 최솟값은 IMO 2021 숏리스트 A3다. 문제와 풀이는 [공식 숏리스트](https://www.imo-official.org/assets/documents/problems/2021/IMO2021SL.pdf)에 있다.

## 약수, gcd, 합동

정의와 기본 관계(`gcd·lcm = |ab|`, `φ(n) = n Π (1−1/p)`, `Σ_{d|n} φ(d) = n`, 뫼비우스 반전)는 [[number-theory-basics|정수론 기초]]에 있다. 여기에는 그 다음으로 자주 꺼내는 식만 둔다.

| 식 | 조건·뜻 |
| --- | --- |
| `gcd(n^a − 1, n^b − 1) = n^gcd(a,b) − 1` | n ≥ 0, a, b는 음이 아닌 정수, 둘 다 0은 아님 |
| `gcd(a, b) = Σ_{k|a, k|b} φ(k)` | |
| `Σ_{k=1..n} [gcd(k, n) = d] = φ(n/d)` | d가 n의 약수. `[ ]`는 참이면 1 |
| `Σ_{k=1..n} gcd(k, n) = Σ_{d|n} d · φ(n/d)` | |
| `Σ_{k=1..n} x^gcd(k,n) = Σ_{d|n} x^d φ(n/d)` | |
| `Σ_{i=1..n} Σ_{j=1..n} [gcd(i,j) = 1] = Σ_{d=1..n} μ(d) ⌊n/d⌋²` | |
| `Σ_{i=1..n} Σ_{j=1..n} gcd(i,j) = Σ_{d=1..n} φ(d) ⌊n/d⌋²` | |
| `Σ_{k=1..n} lcm(k, n) = n/2 · (Σ_{d|n} φ(d)·d + 1)` | |
| `Σ_{i=1..n} Σ_{j=1..n} lcm(i,j) = Σ_{t=1..n} ((1+⌊n/t⌋)⌊n/t⌋ / 2)² · Σ_{d|t} μ(d) · t · d` | |

구간 `[L, R]`의 gcd는 차분으로 바꿀 수 있다. `gcd(A_L, A_(L+1), …, A_R) = gcd(A_L, A_(L+1)−A_L, …, A_R−A_(R−1))`.

격자점 `(x1, y1)`, `(x2, y2)`를 잇는 선분 위의 격자점 수(양 끝 포함)는 `gcd(|x1−x2|, |y1−y2|) + 1`이다.

`d = Π p_i^(e_i)`가 `x^k`를 나누는 x ≤ n의 개수는 `⌊n / Π p_i^⌈e_i/k⌉⌋`이다.

서로소인 양의 정수 a, b로 n을 만드는 음이 아닌 정수해 `(x, y)`의 개수(`ax + by = n`)는 `n/(ab) − {b′ n / a} − {a′ n / b} + 1`이다. `{ }`는 소수부, `a a′ ≡ 1 (mod b)`, `b b′ ≡ 1 (mod a)`.

n ≥ 1의 약수 곱은 `n^(d(n)/2)`이다. `Σ_{k≤x} d(k) = Σ_{k=1..⌊x⌋} ⌊x/k⌋`이고, `u = ⌊√x⌋`이면 `2 Σ_{k=1..u} ⌊x/k⌋ − u²`로 O(√x)에 계산한다. `Σ_{k=1..n} σ(k) = Σ_{k=1..n} k ⌊n/k⌋`.

**조르당 토션트** `J_k(n)`은 1 이상 n 이하인 k개의 정수가 n과 함께 서로소(k+1개의 gcd가 1)인 튜플의 수다. `J_1 = φ`, `J_k(n) = n^k Π_{p|n} (1 − p^(−k))`, `Σ_{d|n} J_k(d) = n^k`.

윌슨 정리와, 서로소인 수를 모두 곱했을 때 −1이 되는 법을 가리는 가우스의 일반화는 [[number-theory-basics|정수론 기초]]에 있다.

n > 1이면 1 이상 n 이하이면서 n과 서로소인 수의 합은 `n φ(n) / 2`이고, 그 평균은 `n/2`이다. `φ(2m)`은 m이 짝수면 `2φ(m)`, 홀수면 `φ(m)`. `φ(lcm(m,n)) φ(gcd(m,n)) = φ(m) φ(n)`. n ≥ 3이면 φ(n)은 짝수이고, 서로 다른 홀소인수가 r개면 `2^r`이 φ(n)을 나눈다. m ≥ 2이면 `φ(φ(m)) ≤ m/2`. `rad(n)`을 n의 서로 다른 소인수 곱이라 하면 `φ(n)/n = φ(rad(n))/rad(n)`.

곱셈적 함수 f에 대해 `Σ_{d|n} μ(d) f(d) = Π_{p|n} (1 − f(p))`. 특히 `Σ_{d|n} μ(d) φ(d) = Π_{p|n} (2 − p)`. `F(n) = Π_{d|n} f(d)`이면 `f(n) = Π_{d|n} F(n/d)^(μ(d))`.

`Σ_{n=1..N} μ(n)²`은 N 이하의 제곱인수가 없는 수의 개수이고 `Σ_{k=1..⌊√N⌋} μ(k) ⌊N/k²⌋`이다.

## 이차 잉여와 르장드르 기호

홀소수 p에 대해 르장드르 기호 `(a/p)`는 a가 p의 배수가 아니면서 제곱과 합동이면 1, 제곱과 합동인 수가 없으면 −1, p가 a를 나누면 0이다. **오일러 판정법** `(a/p) ≡ a^((p−1)/2) (mod p)`이고 값은 {−1, 0, 1}에 있다. 이차 잉여의 정의는 [[number-theory-basics|정수론 기초]]의 표에 있다.

- a ≡ b (mod p)이면 `(a/p) = (b/p)`.
- `(ab/p) = (a/p)(b/p)`.
- n = k²이면 홀소수 p ≠ k에 대해 `(n/p) = 1`이고, k가 홀소수면 `(n/k) = 0`.
- `(n/5)`를 n = 1, 2, 3, …에 대해 쓰면 `1, −1, −1, 1, 0`이 반복된다.
- p가 소수면 `F_(p − (p/5)) ≡ 0 (mod p)`, `F_p ≡ (p/5) (mod p)`.

## 피타고라스 수와 제곱의 합

`a² + b² = c²`인 양의 정수 쌍. m > n > 0, `a = m² − n²`, `b = 2mn`, `c = m² + n²`는 피타고라스 수다. m, n이 서로소이고 둘 다 홀수가 아닐 때 원시(gcd가 1)다. 둘 다 홀수면 a, b, c가 모두 짝수이고, 2로 나누면 원시가 된다. 모든 쌍은 `k ≥ 1`을 곱한 이 꼴로, m > n, 서로소, 둘 다 홀수는 아님이라는 조건 아래 한 번씩 나온다.

빗변이 n인 쌍 `{a, b, n}`의 개수는 `(Π (2α+1) − 1) / 2`이다. 곱은 n의 소인수 중 `4k+1` 꼴인 것의 지수 α에 대한 것이다. 그런 소인수가 없으면 0이다. 예: n = 65 = 5·13이면 (3·3 − 1) / 2 = 4.

`r_k(n)`은 `n = a_1² + … + a_k²`인 정수해의 개수다. 순서와 부호를 다르게 센다.

| | 식 |
| --- | --- |
| `r_2(n)` | `4 (d_1(n) − d_3(n))`. d_1, d_3은 n의 약수 중 mod 4로 1, 3인 것의 개수. `4k+3` 꼴 소인수의 지수가 하나라도 홀수면 0 |
| `r_4(n)` | 4로 나누어떨어지지 않는 약수의 합의 8배 |
| `r_8(n)` | `16 Σ_{d|n} (−1)^(n+d) d³` |

## 분할수와 오각수

분할수 `p(n)`은 n을 순서 없이 양의 정수 합으로 쓰는 방법의 수. `p(0) = 1`. 오각수 정리의 점화식은

```text
p(n) = Σ_{k≥1} (−1)^(k−1) ( p(n − k(3k−1)/2) + p(n − k(3k+1)/2) )
```

인자가 음수인 항은 0이다. k(3k−1)/2 (k = 1, −1, 2, −2, …)가 일반화 오각수 1, 2, 5, 7, 12, …이다. 0이 아닌 항은 O(√n)개라서 `p(0)…p(n)`을 O(n√n)에 채운다.

생성함수로는 `Π_{m≥1} (1 − x^m) = Σ_{k∈ℤ} (−1)^k x^(k(3k−1)/2)`.

## 한 수의 제곱과 세제곱

69 = 3 × 23이라 두 소수의 곱(반소수)이다. `69² = 4761`, `69³ = 328509`이고, 두 결과를 이어 쓰면 0부터 9가 정확히 한 번씩 나온다.

## 정리

- 이항 계수의 합은 하키 스틱, 방데르몽드, 쿠머, 뤼카로 대부분 덮인다. `i^k`가 붙은 합은 제2종 스털링으로 k에 대한 식으로 바꾼다.
- 카탈란 수는 `C(2n, n)/(n+1)`이고, 괄호·경로·삼각분할이 같은 수다.
- 피보나치의 gcd는 인덱스의 gcd다. 주기는 6m 이하이다.
- 양의 정수의 곱과 비교는 바닥으로 내리되, `<`만 부등호 방향이 그대로이지 않다.
- 약수 합과 gcd 합은 `⌊n/d⌋`로 바꾸면 √n 또는 약수 열거에 들어간다.
- `{1,…,n}`의 순열에서 `Σ ⌊a_k/k⌋`의 최솟값은 `⌊log2 n⌋ + 1`이다.
