## 루프 복잡도를 세는 요령

빅오 표기의 정의와 단순화 규칙은 [[big-o|빅오 표기법과 시간 복잡도]]에 있다. 이 노트는 그다음 단계, 즉 **반복문이 한눈에 O(n)이나 O(n²)로 보이지 않을 때 실행 횟수를 어떻게 세는지**를 다룬다.

자주 나오는 실수는 두 가지다.

- **이미 모든 반복에 대해 합쳐 둔 횟수에, 바깥 루프 횟수를 다시 곱한다.** `n + (n-1) + ... + 1`은 이미 바깥 루프를 반영한 O(n²)이다. 여기에 n을 한 번 더 곱하면 O(n³)로 과대 계산된다.
- **반복 변수가 1씩 늘지 않거나 종료 조건이 `i < n`이 아닌데도, 반복 횟수를 n으로 적는다.** 변수가 일정 비율로 커지면 로그, 제곱이 상한을 넘으면 제곱근이다.

아래 코드는 원문의 C 스타일 예제를 옮겼다. 원문에 `2n`처럼 적힌 곱셈은 `2 * n` 형태로 고쳤다.

## 앞의 상수는 버려도 차수는 남는다

```c
int x = 0;
for (int i = 4 * n; i >= 1; i--)
    x = x + 2 * i;
```

루프는 4n번 돌고, 한 번의 일은 O(1)이다. 상수 4는 버리므로 **O(n)** 이다.

## 반복 변수가 일정 비율로 커지면 O(log n)

```c
int z = 0;
int x = 0;
for (int i = 1; i <= n; i = i * 3) {
    z = z + 5;
    z++;
    x = 2 * x;
}
```

i는 1, 3, 9, 27, …처럼 3의 거듭제곱을 따른다. k번째 반복에서 i = 3^k이고, 루프는 3^k > n일 때 끝나므로 k > log₃ n이다. 한 번의 일은 O(1)이므로 전체는 **O(log n)** 이다. n/3번이 아니다.

[[big-o|빅오 표기법과 시간 복잡도]]에서처럼 2배씩 커져도 마찬가지다. 밑이 달라도 로그의 밑은 상수 배라서 모두 O(log n)이다.

## 제곱 조건은 O(√n)

```c
int y = 0;
for (int j = 1; j * j <= n; j++)
    y++;
```

j는 1씩 늘지만, 루프는 j² ≤ n인 동안만 돈다. j가 √n을 넘는 순간 끝나므로 반복은 **O(√n)** 번이다. 제곱 조건을 로그로 착각하기 쉽다. 로그가 되려면 남은 범위가 일정 비율로 줄어야 한다.

같은 모양이 중첩되면 곱한다.

```c
int t = 0;
for (int i = 1; i <= n; i++)
    for (int j = 0; j * j < 4 * n; j++)
        for (int k = 1; k * k <= 9 * n; k++)
            t++;
```

바깥은 n번, `j * j < 4 * n`은 j < 2√n이므로 O(√n)번, `k * k <= 9 * n`은 k ≤ 3√n이므로 O(√n)번이다. 전체는 n · √n · √n = **O(n²)** 이다.

## 중첩을 합쳤으면 바깥 횟수를 다시 곱하지 않는다

```c
int b = 0;
for (int i = n; i > 0; i--)
    for (int j = 0; j < i; j++)
        b = b + 5;
```

안쪽 루프의 반복 횟수를 바깥 i에 대해 더하면 n + (n-1) + ... + 1 = n(n+1)/2 = O(n²)이다. 이 합은 **이미 바깥 루프의 모든 반복을 포함한 값**이다. 여기에 바깥 횟수 n을 다시 곱하면 같은 일을 두 번 센다. 정확한 복잡도는 **O(n²)** 이다.

안쪽 상한이 `i * n`이어도 같은 원리다.

```c
int b = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j < i * n; j++)
        b = b + 5;
```

안쪽은 0 + n + 2n + ... + n(n-1) = n(0 + 1 + ... + n-1) = n · n(n-1)/2 번 돈다. 전체는 **O(n³)** 이다. 바깥 n번과 안쪽을 n²로 보고 다시 곱해 O(n⁴)로 적는 것이 전형적인 과대 계산이다.

## 이어지는 두 반복문은 더하고, 둘째의 횟수는 첫째가 남긴 변수다

나란히 놓인 두 루프의 비용은 곱하지 않고 더한다. 다만 둘째 루프의 반복 횟수는 첫째가 끝난 뒤의 변수 값에 달려 있을 수 있다.

```c
int y = 1;
int j = 0;
for (j = 1; j <= 2 * n; j = j + 2)
    y = y + i;

int s = 0;
for (i = 1; i <= j; i++)
    s++;
```

첫째 루프는 2씩 증가하며 약 n번 돈다. 끝난 뒤 j는 2n을 처음으로 넘는 값, 곧 Θ(n)이다. 둘째 루프도 Θ(n)번 돌므로 전체는 **O(n)** 이다.

첫째가 값을 제곱 차로 쌓으면 둘째가 지배한다.

```c
int i = 0, j = 0, y = 0, s = 0;
for (j = 0; j < n + 1; j++)
    y = y + j;
for (i = 1; i <= y; i++)
    s++;
```

첫째는 O(n)이고, 끝날 때 y = 0 + 1 + ... + n = n(n+1)/2 = Θ(n²)이다. 둘째는 y번, 곧 Θ(n²)번 돈다. 전체는 **Θ(n²)** 이다. 첫째의 O(n)에 둘째의 횟수를 n²으로만 보고 다시 곱하면 O(n³)이 되어 버린다.

같은 삼각수 상한이라도, 루프 변수가 1, 2, 3, …을 누적하면 반복 횟수는 n이다.

```c
int i = 1, z = 0;
while (z < n * (n + 1) / 2) {
    z += i;
    i++;
}
```

z는 1 + 2 + ... + t가 n(n+1)/2에 닿을 때까지 커진다. t = n일 때 딱 닿으므로 루프는 **O(n)** 번 돈다.

## 안쪽 일이 기하급수로 늘면 합은 마지막 항 차수다

```c
int x = 0;
for (int i = 1; i <= n; i = i * 3) {
    if (i % 2 != 0)
        for (int j = 0; j < i; j++)
            x++;
}
```

바깥은 i가 1, 3, 9, …로 커지므로 O(log n)번이다. 3의 거듭제곱은 모두 홀수라서 `i % 2 != 0`은 항상 참이다. 안쪽은 그때의 i번 돌므로 총일은 1 + 3 + 9 + ... + 3^{log₃ n}이다. 공비 3인 기하급수의 합은 (3^{k+1} - 1)/2이고, 3^k = n이면 (3n - 1)/2 = **O(n)** 이다. 바깥 횟수 O(log n)과 안쪽을 모두 n으로 보고 곱하면 O(n log n)으로 과대 계산된다. 기하급수는 마지막 항이 합을 지배한다.

## 절반으로 줄이는 루프는 로그번, 안쪽 일이 함께 줄어들면 첫 항 차수다

바깥 변수를 절반씩 줄이면 바깥 반복은 O(log n)번이다. 전체 비용은 안쪽 일이 매 반복 같은지, 바깥 변수와 함께 줄어드는지에 따라 달라진다.

안쪽 일이 매번 같다.

```c
int a = 0;
int k = n * n;
while (k > 1) {
    for (int j = 0; j < n * n; j++) {
        a++;
    }
    k = k / 2;
}
```

k는 n²에서 시작해 절반씩 줄므로 바깥은 log(n²) = 2 log n = O(log n)번이다. 안쪽은 매번 n²번이다. 전체는 **O(n² log n)** 이다. 바깥을 n²번으로 세면 O(n⁴)가 된다.

안쪽 상한이 줄어드는 k에 묶이면 이야기가 다르다.

```c
int a = 0;
int k = n * n * n;
while (k > 1) {
    for (int j = 0; j < k; j++) {
        a--;
    }
    k = k / 2;
}
```

바깥은 역시 O(log n)번이고, 첫 반복의 안쪽은 n³번이다. 그러나 안쪽 횟수는 n³ + n³/2 + n³/4 + n³/8 + ... = n³(1 + 1/2 + 1/4 + ...) ≤ 2n³이다. 전체는 **O(n³)** 이다. O(log n)과 첫 항 n³을 곱한 O(n³ log n)보다 작다. 공비가 1/2인 무한 기하급수는 상수 2로 묶인다.

## 조건문이 안쪽 루프를 제한하면 참이 되는 항만 센다

중첩 루프를 무조건 곱하면 안 되는 또 다른 경우는, 가장 안쪽 루프가 조건이 참일 때만 실행될 때다.

```c
for (int i = 0; i <= n; i++)
    for (int j = 1; j <= i * i; j++)
        if (j % i == 0)
            for (int k = 0; k < j; k++)
                sum++;
```

i = 0이면 안쪽 `j` 루프는 돌지 않는다(`j`의 상한이 0). i ≥ 1일 때 j는 1부터 i²까지 돌지만, `j % i == 0`인 j만 k 루프를 실행한다. 그런 j는 i, 2i, …, i·i로 i개다. j = m·i (m = 1, …, i)일 때 k 루프는 j = m·i번 돌므로, i 하나당 일은

i · (1 + 2 + ... + i) = i · i(i+1)/2 = O(i³)

이다. i를 1부터 n까지 더하면 O(n⁴)이다. 조건문을 무시하고 바깥 n, j 루프 n², k 루프를 j의 최댓값 n²로 곱하면 과대 계산된다. **곱하기 전에 조건이 참이 되는 항을 먼저 센다.**

## 한눈에 보기

| 루프 모양 | 복잡도 | 세는 요령 |
| --- | --- | --- |
| `i`가 4n에서 1까지 1씩 감소 | O(n) | 앞의 상수는 버린다 |
| `i *= 3`처럼 일정 비율로 증가 | O(log n) | 거듭제곱 횟수는 로그 |
| `j * j <= n` | O(√n) | 선형 증가 + 제곱 종료 조건 |
| 바깥 n번, 안쪽 i번 (삼각합) | O(n²) | 합에 바깥을 다시 곱하지 않는다 |
| 바깥 n번, 안쪽 `i * n`번 | O(n³) | 0 + n + ... + n(n-1) = O(n³) |
| 나란한 두 루프, 둘째 상한이 Θ(n) | O(n) | 나란한 루프는 더한다 |
| 첫째가 삼각수를 쌓고 둘째가 그 값만큼 반복 | Θ(n²) | 둘째의 횟수는 쌓인 변수 값 |
| `z`가 삼각수 상한에 닿을 때까지 1, 2, 3, …을 누적 | O(n) | 누적 횟수는 n |
| 바깥 `i *= 3`, 안쪽 i번 (항상 실행) | O(n) | 1+3+…+n 기하급수는 마지막 항 |
| 바깥 n번 × `j * j < 4n` × `k * k <= 9n` | O(n²) | √n · √n = n |
| k = n²를 절반씩, 안쪽은 매번 n² | O(n² log n) | 바깥은 log(n²)번 |
| k = n³를 절반씩, 안쪽은 그때의 k | O(n³) | n³(1+1/2+…) ≤ 2n³ |
| j가 i²까지, `j % i == 0`일 때만 k가 j번 | O(n⁴) | 조건이 참인 항만 더한다 |

## 정리

- 반복 횟수는 종료 조건과 증가량을 보고 센다. 1씩 증가하며 n에 닿으면 n, 일정 비율로 커지거나 절반으로 줄면 log n, 제곱이 상한이면 √n이다.
- 중첩 루프는 안쪽 횟수를 바깥 변수에 대해 **합친 뒤** 끝낸다. 그 합에 바깥 횟수를 다시 곱하지 않는다.
- 나란한 루프는 비용을 더한다. 둘째의 반복 횟수는 첫째가 남긴 변수 값을 따른다.
- 기하급수 합은 공비가 1보다 크면 마지막 항, 1보다 작으면 첫 항이 차수를 정한다.
- 안쪽 루프가 조건문 안에 있으면, 조건이 참이 되는 항만 더한다.
