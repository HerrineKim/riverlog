분할 정복(Divide and Conquer)은 그대로는 풀기 어려운 문제를 **같은 형태의 더 작은 문제로 쪼개** 해결하는 방법이다. 대표적인 예로 병합 정렬, 퀵 정렬, 이분 탐색, 거듭제곱 빠르게 계산하기, 고속 푸리에 변환(FFT) 등이 있다.

## 세 단계

1. **Divide(분할)**: 원래 문제를 비슷한 유형의 더 작은 하위 문제로 나눈다.
2. **Conquer(정복)**: 하위 문제를 재귀적으로 푼다. 더 나눌 수 없을 만큼 작아지면(종료 조건) 직접 푼다.
3. **Combine(결합)**: 하위 문제의 답을 합쳐 원래 문제의 답을 만든다.

분할을 잘 설계하면 정복은 자연스럽게 쉬워진다. 그래서 **어떻게 나눌지**가 가장 중요하다.

## 특징

- 나뉜 문제는 원래 문제와 성격이 같고 **입력 크기만 작다**.
- 나뉜 문제들은 **서로 독립적**이다. 같은 하위 문제가 반복해서 등장하지 않는다. (반복해서 등장한다면 동적 계획법을 쓴다.)
- 보통 하위 문제를 두 개 이상 만들기 때문에 재귀 호출이 여러 갈래로 뻗는다.

| 장점 | 단점 |
| --- | --- |
| 재귀(Top-down)로 구현해 코드가 직관적이다. | 재귀 호출 오버헤드가 생긴다. |
| 하위 문제가 독립적이라 병렬로 처리하기 좋다. | 재귀가 깊으면 스택 메모리를 많이 쓰고, 스택 오버플로우가 날 수 있다. |

## 대표 예시

### 병합 정렬과 퀵 정렬

- **병합 정렬**: 결합에서 작업한다. 균등하게 둘로 나누고, 정렬된 두 리스트를 합칠 때 비교가 일어난다. 항상 O(n log n).
- **퀵 정렬**: 분할에서 작업한다. 피벗 기준으로 나눌 때 비교가 일어나고, 결합은 이어 붙이기뿐이다. 평균 O(n log n), 최악 O(n²).

자세한 동작과 비교는 [[merge-quick-sort|병합 정렬과 퀵 정렬]]에 있다.

### 이진 탐색

정렬된 배열을 반으로 나눈 뒤 **한쪽만** 계속 탐색한다. 하위 문제가 하나뿐인 분할 정복(감소 정복)으로 볼 수 있다. O(log n).

### 거듭제곱 빠르게 계산하기

xⁿ = (x^(n/2))² 임을 이용하면 곱셈을 O(log n)번만 하면 된다.

```python
def power(x, n):
    if n == 0:
        return 1
    half = power(x, n // 2)
    if n % 2 == 0:
        return half * half
    return half * half * x

print(power(2, 10))  # 1024
```

## 핵심 정리

- 분할 → 정복 → 결합, 하위 문제는 서로 독립적
- 하위 문제가 겹치면 동적 계획법, 겹치지 않으면 분할 정복
- 병합 정렬, 퀵 정렬, 이진 탐색, 빠른 거듭제곱이 대표 예시
