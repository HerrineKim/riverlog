> 질병관리청의 [항생제 내성 인식주간 자료](https://www.kdca.go.kr/bbs/kdca/42/313484/artclView.do)와 [인플루엔자 국가예방접종 안내](https://nip.kdca.go.kr/irhp/infm/goVcntInfo.do?menuCd=134&menuLv=1), 건강보험심사평가원의 비급여 진료비용 공개, 식품의약품안전처의 GLP-1 계열 비만치료제 안전사용 안내, [국립연명의료관리기관](https://www.lst.go.kr/addt/medicalintent.do) 안내, 보건복지부의 수술실 CCTV 시행 발표를 종합한 노트다. 제도와 일반 권고를 정리한 것이며 개인의 진단이나 처방을 대신하지 않는다.

| 독감 예방접종 | 국가예방접종은 가을에 시작해 다음 해 4월 30일까지 이어진다 |

| 수술실 CCTV | 설치는 의무지만 촬영은 환자나 보호자가 요청해야 한다 |

## 감기와 항생제

항생제는 **세균 감염**을 치료하는 약이다. 감기와 독감은 바이러스 감염이므로 항생제가 낫는 데 도움이 되지 않는다. 필요 없이 쓴 항생제는 내성균을 만들어, 정작 항생제가 필요할 때 약이 듣지 않게 한다.

질병관리청의 2026년 인식도 조사(일반인 1,000명)에서 드러난 오해가 곧 지켜야 할 수칙이다.

| 조사 결과 | 올바른 사용 |
| --- | --- |
| 71.4%가 항생제가 감기 치료에 도움이 된다고 잘못 알고 있다 | 감기에 항생제를 요구하지 않는다 |
| 66.2%가 증상이 나아지자 처방받은 항생제를 임의로 끊은 적이 있다 | 처방받은 용법·용량·기간을 지킨다 |
| 항생제의 용도를 세균 감염 치료로 정확히 아는 사람은 26.4%다 | 의사가 처방한 경우에만 쓴다 |

남은 항생제를 두었다가 비슷한 증상에 임의로 먹거나, 다른 사람의 항생제를 나눠 먹지 않는다.

## 독감 예방접종

인플루엔자(독감) 국가예방접종은 해마다 가을에 시작해 **다음 해 4월 30일까지** 이어진다. 유행하는 바이러스가 해마다 달라 백신도 해마다 새로 만들므로, 지난 절기에 맞았더라도 매년 1회 접종한다.

2026~2027절기(2026년 9월 21일~2027년 4월 30일) 기준은 다음과 같다.

| 항목 | 내용 |
| --- | --- |
| 무료 접종 대상 | 생후 6개월~14세 어린이, 임신부(임신 주수 무관), 65세 이상 |
| 백신 | 세계보건기구(WHO) 권장 균주를 담은 불활성화 3가 백신 |
| 횟수 | 1회. 생후 6개월 이상 9세 미만 가운데 처음 맞거나 이전에 1회만 맞은 어린이는 2회 |
| 장소 | 주소지와 관계없이 전국 위탁의료기관과 보건소 |

- 접종 지원 기간이 4월 말까지인 만큼, 유행이 시작된 뒤에 맞는 것도 의미가 있다.
- 접종 가능한 기관은 [예방접종도우미](https://nip.kdca.go.kr)에서 찾는다.

## 심뇌혈관질환 예방관리 9대 생활수칙

질병관리청이 정한 수칙이다.

1. 담배를 피우지 않는다.
2. 술은 가급적 마시지 않는다.
3. 적당량의 음식을 규칙적으로 먹는다. 골고루, 짜지 않게 먹고 통곡물·채소·콩·생선을 충분히 포함한다.
4. 규칙적으로 매일 30분 이상 운동하고 오래 앉아 있는 시간을 줄인다.
5. 적정한 체중과 허리둘레를 유지한다.
6. 스트레스를 잘 관리하며 즐거운 마음으로 생활한다.
7. 정기적으로 혈압, 혈당, 콜레스테롤 수치를 측정한다.
8. 고혈압·당뇨병·이상지질혈증 환자는 생활 습관을 개선하고 필요하면 꾸준히 약물 치료를 받는다.
9. 뇌졸중·심근경색증의 응급 증상을 미리 알고 응급 상황에서는 즉시 119를 부른다.

과거 수칙의 「술은 하루 한두 잔 이하」는 개정되어 지금은 **가급적 마시지 않는다**다. 9번 수칙의 응급 증상은 [[emergency-first-response|응급 상황 초기 대응]]에 정리했다.

## 비급여 진료비 비교

비급여는 건강보험이 적용되지 않아 **의료기관이 가격을 스스로 정하는** 항목이다. 그래서 같은 진료도 기관에 따라 값이 크게 다르다. 예를 들어 2026년 공개 자료에서 사지 관절 부위 증식치료는 한 의원이 5만 원, 다른 의원이 20만 1,000원이었다.

| 항목 | 내용 |
| --- | --- |
| 공개 주체 | 건강보험심사평가원 |
| 공개 범위 | 2026년 기준 753개 항목. 해마다 단계적으로 늘어난다 |
| 확인하는 곳 | [심평원 누리집](https://www.hira.or.kr), 모바일 앱 「건강e음」 |
| 조회 방식 | 「병·의원으로 조회」, 「항목으로 조회」 가운데 고른다. 치료 재료 항목도 조회할 수 있다 |

- 공개 금액은 항목 하나의 가격이다. 실제 총진료비는 함께 하는 다른 진료나 치료 재료에 따라 달라진다.
- 기관이 바꾼 금액이 실시간으로 반영되지 않을 수 있으므로, 진료 전에 해당 기관에 금액을 다시 확인한다.

## GLP-1 계열 비만치료제

GLP-1 계열 비만치료제는 **의사의 처방이 필요한 전문의약품**이다. 허가된 처방 대상은 초기 체질량지수(BMI)가 30kg/m² 이상인 비만 환자, 또는 체중 관련 동반 질환이 하나 이상 있으면서 BMI가 27kg/m² 이상 30kg/m² 미만인 과체중 환자다. 식품의약품안전처가 2026년 9월에 개정해 배포한 안전사용 안내서의 요점은 다음과 같다.

| 구분 | 내용 |
| --- | --- |
| 청소년 | BMI 30kg/m² 이상이면서 체중이 60kg을 넘는 청소년에게만 일부 제품을 처방할 수 있다. 낮은 용량부터 신중하게 시작한다 |
| 당뇨병약 병용 | 저혈당 위험이 커질 수 있어 의료진과 상의한다 |
| 임신·수유 | 임신 중, 수유 중이거나 임신을 계획하면 투여를 중단하고 전문가와 상의한다 |
| 보관 | 빛을 피해 냉장 보관한다 |
| 이상 반응 | 부작용이 생기면 빨리 의료진과 상담한다 |
| 구입 경로 | 온라인 해외 직구와 개인 간 판매를 하지 않는다. 제품의 안전성을 담보할 수 없다 |

허가된 대상과 용법의 범위 안에서 쓰는 약이므로 처방 없이 구해 쓰지 않는다.

## 사전연명의료의향서

사전연명의료의향서는 **자신이 나중에 임종과정에 있는 환자가 되었을 때를 대비해** 연명의료와 호스피스에 관한 의향을 미리 적어 두는 문서다.

| 항목 | 내용 |
| --- | --- |
| 작성 자격 | 만 19세 이상이면 누구나 |
| 작성 장소 | 보건복지부가 지정한 사전연명의료의향서 등록기관. 신분증을 가지고 방문해 설명을 들은 뒤 작성한다 |
| 효력 | 등록기관을 통해 작성·등록되어 연명의료 정보처리시스템에 보관되어야 법적 효력이 있다 |
| 등록 현황 | 2026년 11월 23일 기준 누적 약 363만 명 |

### 작성과 이행은 별개의 단계다

의향서를 등록했다고 해서 자동으로 연명의료가 중단되지는 않는다. 실제 유보·중단은 의료기관에서 두 가지가 모두 충족될 때 이뤄진다.

1. **임종과정 판단**: 담당의사와 해당 분야 전문의 1명이, 회생 가능성이 없고 치료해도 회복되지 않으며 급속히 악화해 사망이 임박한 상태라고 판단한다.
2. **환자 의사 확인**: 아래 방법 가운데 하나로 환자의 뜻을 확인한다.

| 확인 방법 | 요건 |
| --- | --- |
| 사전연명의료의향서 | 담당의사가 그 내용을 환자에게 확인한다. 환자가 의사를 표현할 수 없는 상태면 담당의사와 전문의 1명이 함께 문서가 적법하게 작성됐는지 확인한다 |
| 연명의료계획서 | 담당의사가 작성한 연명의료계획서로 환자의 뜻을 확인한다 |
| 환자가족 2명 이상의 진술 | 두 문서가 모두 없고 환자가 의사를 표현할 수 없을 때. 평소 환자의 뜻을 가족 2명 이상이 똑같이 진술하고, 담당의사와 전문의가 확인한다 |
| 환자가족 전원 합의 | 위 방법이 모두 불가능할 때. 가족 전원이 합의하고 담당의사와 전문의가 확인한다 |

의향서가 있으면 환자가 말할 수 없는 상태에서도 가족의 기억이나 합의에 기대지 않고 본인의 뜻이 확인된다. 다만 의료진이 의향서를 조회해 확인하는 절차가 있어야 하므로, **작성한 사실과 원하는 내용을 가족에게 알려 두면** 필요한 때에 의료진에게 전달되기 쉽다.

## 수술실 CCTV

2023년 9월 25일부터 전신마취나 수면마취(진정)처럼 **환자가 의식이 없는 상태에서 수술하는 의료기관**은 수술실 안에 CCTV를 설치해야 한다(「의료법」 제38조의2).

| 항목 | 내용 |
| --- | --- |
| 촬영 조건 | **환자 또는 보호자가 요청할 때만** 촬영한다. 요청은 촬영 요청서로 한다 |
| 의료기관의 의무 | 촬영이 가능하다는 것을 안내하고 요청서를 제공한다 |
| 거부할 수 있는 경우 | 응급 수술, 환자 생명을 구하기 위해 적극적 조치가 필요한 위험도 높은 수술, 전공의 수련 목적을 현저히 저해할 우려가 있는 경우, 수술 직전처럼 예정대로 수술하기 어려운 시점에 요청한 경우, 천재지변·통신 장애 같은 불가항력 |
| 거부 절차 | 수술 전에 환자나 보호자에게 사유를 설명하고 기록을 3년간 보관한다 |
| 녹음 | 금지. 환자와 수술에 참여한 의료인 전원이 동의하면 가능하다 |
| 보관 | **촬영일부터 30일 이상.** 열람·제공 요청이 들어온 영상은 결정이 날 때까지 지울 수 없다 |
| 열람·제공 | 수사·재판을 위한 관계 기관의 요청, 한국의료분쟁조정중재원의 조정·중재 업무 요청, 환자와 수술 참여 의료인 전원의 동의 가운데 하나에 해당할 때만 가능하다 |

요청하지 않으면 영상 자체가 없다. 영상을 남기려면 **수술 전에, 여유를 두고** 촬영을 요청하고, 사후에 영상이 필요해지면 보관 기간 30일 안에 절차를 시작한다.

## 정리

- 감기에 항생제를 요구하지 않고, 처방받은 항생제는 끝까지 정해진 대로 먹는다.
- 독감 접종은 매년 한 번이고, 국가예방접종은 4월 말까지 이어진다.
- 비급여 진료는 받기 전에 심평원 공개 자료로 가격을 비교하고 기관에 다시 확인한다.
- 비만치료제는 처방받아 허가 범위 안에서 쓰고, 직구나 개인 간 거래로 구하지 않는다.
- 사전연명의료의향서는 등록기관에서 작성하고 가족에게 알려 둔다.
- 수술실 CCTV 촬영은 수술 전에 요청해야 하고, 영상 보관은 30일이 기본이다.
