> 가트맨 연구소의 「[The Four Horsemen](https://www.gottman.com/blog/the-four-horsemen-recognizing-criticism-contempt-defensiveness-and-stonewalling/)」과 [해독제 안내](https://www.gottman.com/blog/the-four-horsemen-the-antidotes/), Lewicki·Polin·Lount의 사과 연구(2016), UC 버클리 Greater Good Science Center의 [용서 정의](https://greatergood.berkeley.edu/topic/forgiveness/definition), 스티븐 코비의 『성공하는 사람들의 7가지 습관』(1989)을 종합한 노트다.

## 갈등을 키우는 네 가지 말

심리학자 존 가트맨(John Gottman)은 관계를 무너뜨리는 대화 패턴 넷을 「네 기수(Four Horsemen)」라고 부른다. 부부 연구에서 나온 틀이지만 동료·가족·친구 사이의 다툼에도 그대로 보인다.

| 패턴 | 모습 | 해독제 |
| --- | --- | --- |
| 비난(criticism) | 특정 행동이 아니라 사람의 성격을 공격한다. 「너는 원래 그래」 | **부드럽게 시작하기**: 「너」가 아니라 「나」를 주어로 내 감정과 필요를 말한다 |
| 경멸(contempt) | 비꼬기, 조롱, 욕, 눈 굴리기, 코웃음. 내가 도덕적으로 위에 있다는 태도에서 나온다 | **고마움과 존중의 문화**: 평소에 고마움과 인정을 자주 표현해 둔다 |
| 방어(defensiveness) | 변명, 피해자 되기, 되받아 탓하기 | **책임 인정**: 갈등의 일부라도 내 몫을 받아들인다 |
| 담쌓기(stonewalling) | 대화를 닫고 반응을 끊는다. 감정이 몸의 한계를 넘는 「범람(flooding)」 상태에서 나온다 | **스스로 가라앉히기**: 쉬자고 말하고 20분 이상 쉰 뒤 돌아온다 |

- **불만(complaint)과 비난은 다르다.** 불만은 특정 행동과 그것이 내게 준 영향을 말하고, 비난은 사람에게 꼬리표를 붙인다.
- **경멸은 넷 가운데 가장 해롭다.** 가트맨 연구소는 경멸을 이혼을 예측하는 가장 강한 단일 요인으로 꼽는다. 같은 내용이라도 높아진 목소리, 비꼬는 어조, 눈 굴리기가 붙으면 듣는 사람은 내용이 아니라 경멸을 듣는다.
- 관계가 안정적인 쪽은 갈등 중에도 긍정적 상호작용과 부정적 상호작용의 비율이 5 대 1쯤 된다.

## 단정을 요청으로 바꾸기

비난하지 않는 말의 핵심은 **상대의 잘못을 단정하는 문장을 내가 바라는 행동을 요청하는 문장으로 바꾸는 것**이다.

| 바꾸는 방향 | 단정하는 말 | 요청하는 말 |
| --- | --- | --- |
| 지적 → 요청 | 「너 정말 무례하다」 | 「서로 예의를 지켜서 이야기하면 좋겠어」 |
| 단정 → 질문 | 「넌 못 할 거야」 | 「이거 할 수 있겠어? 걸리는 게 있으면 말해 줘」 |
| 금지 → 제안 | 「그렇게 하지 마」 | 「이렇게 해 보면 어때?」 |
| 네 오해 → 내 설명 | 「네가 잘못 알아들었잖아」 | 「내 설명이 분명하지 않았던 것 같아. 다시 말할게」 |
| 추궁 → 안부 | 「왜 화났는데?」 | 「지금 기분이 어때?」 |
| 터뜨리기 → 설명 | (목소리를 높인다) | 「나는 ~해서 화가 났어」 |
| 말투 지적 | 「말투가 왜 그래」 | 「방금 말이 좀 아프게 들렸어. 다시 말해 줄래?」 |

화는 표현하되 터뜨리지 않는다. **화가 났다는 사실과 이유를 문장으로 설명**하면 상대는 방어 대신 이해를 시작할 수 있다. 감정을 숨기거나 떠보는 것, 바라는 것을 말하지 않고 알아주기를 기다리는 것은 실망을 예약하는 일이다. 상처가 되는 말을 들었을 때도 되받아치기 전에 「무슨 뜻으로 한 말이야?」로 의도를 먼저 확인한다.

### 말하기 전 점검: THINK

말이 나가기 전에 다섯 가지를 묻는 약어다.

| 글자 | 질문 |
| --- | --- |
| **T**rue | 사실인가 |
| **H**elpful | 도움이 되는가 |
| **I**nspiring | 힘이 되는가 |
| **N**ecessary | 꼭 필요한가 |
| **K**ind | 친절한가 |

### 일터에서: 방어하는 말을 다음 행동이 보이는 말로

직장에서는 짧은 대답이 방어나 거절로 들리기 쉽다. **다음에 무엇을 할지**를 붙이면 같은 뜻이 협조로 들린다.

| 방어로 들리는 말 | 행동이 보이는 말 |
| --- | --- |
| 「왜요?」 | 「이유를 여쭤봐도 될까요?」 |
| 「안 됩니다」 | 「이 조건에서는 어렵습니다. 가능한 방법을 찾아보겠습니다」 |
| 「바쁩니다」 | 「지금은 어렵고, 일정을 조율해 보겠습니다」 |
| 「잘 몰라요」 | 「확인하고 오늘 안에 다시 말씀드리겠습니다」 |
| 「제 일이 아닌데요」 | 「담당 부서와 협의해 보겠습니다」 |
| 「죄송합니다」(만) | 「죄송합니다. 다음부터는 ~하게 고치겠습니다」 |

정직하게 말하면서도 상대를 돌보는 피드백 방식은 [[kind-engineering|친절한 엔지니어링]]에서 다룬다.

## 다툼을 멈추는 신호어와 휴식

감정이 범람한 상태에서는 논리가 작동하지 않는다. 그때 필요한 것은 더 좋은 논거가 아니라 **멈춤**이다.

- **신호어(코드 단어)를 미리 정한다.** 다툼이 격해지기 전에 꺼내기로 약속한 짧은 문구다. 목적은 옳고 그름을 가리는 것이 아니라 「이 문제보다 우리 관계가 더 중요하다」는 것을 서로에게 상기시키는 것이다.
- **무거운 문구보다 둘만 아는 짧고 우스운 표현**이 잘 듣는다. 웃음이 긴장을 푼다.
- **평온할 때 정한다.** 약속 없이 싸우는 도중에 갑자기 「그만하자」를 꺼내면 회피나 무시로 받아들여진다.
- **쉴 때는 돌아올 시간을 말한다.** 몸이 가라앉는 데 시간이 걸리므로 최소 20분은 쉰다. 쉬는 동안 억울함을 되새기지 말고 음악, 독서, 산책처럼 주의를 돌리는 일을 한다.
- 쉬는 것은 끝내는 것이 아니다. 가라앉은 뒤 반드시 다시 이야기한다.

## 사과

### 좋은 사과의 여섯 요소

Lewicki·Polin·Lount(2016)는 사과문을 요소별로 나눠 755명(333명, 422명 두 실험)에게 평가하게 했다. **요소가 많을수록 사과는 효과적으로 평가됐고**, 요소마다 무게가 달랐다.

| 요소 | 내용 | 무게 |
| --- | --- | --- |
| 유감 표현 | 미안하다고 말한다 | |
| 경위 설명 | 무엇이 잘못됐는지 설명한다 | |
| **책임 인정** | 내 잘못임을 분명히 한다 | 가장 중요하다 |
| 뉘우침 선언 | 다시 하지 않겠다고 밝힌다 | |
| 보상 제안 | 피해를 바로잡을 방법을 내놓는다 | |
| 용서 요청 | 용서해 달라고 한다 | 가장 덜 중요하다 |

같은 실험에서 실수(역량 문제)에 대한 사과는 고의(정직성 문제)에 대한 사과보다 잘 받아들여졌다.

### 사과를 망치는 것

- **뭉뚱그린 사과**: 「기분 나빴다면 미안」은 잘못이 아니라 상대의 기분을 문제 삼는다. 무엇을 잘못했는지 구체적으로 짚는다.
- **자기합리화**: 「미안해, 그런데」 뒤에 오는 말이 사과를 지운다. 경위 설명과 변명은 다르다. 설명은 책임을 인정한 뒤에, 책임을 줄이려는 목적 없이 한다.
- **말뿐인 사과**: 말한 대로 행동이 바뀌지 않으면 다음 사과는 믿기지 않는다.
- 마음에 없는 말을 했다면 본심이 아니었다는 것을 설명한다. 본심이었지만 표현이 지나쳤다면 **생각이 아니라 말하고 행동한 방식**이 잘못됐음을 인정한다.

## 사과, 용서, 화해는 서로 다른 일이다

| | 누가 하나 | 무엇인가 | 혼자서 되나 |
| --- | --- | --- | --- |
| 사과 | 잘못한 쪽 | 책임을 인정하고 바로잡겠다는 표현 | 된다 |
| 용서 | 상처받은 쪽 | 원망과 복수심을 내려놓겠다는 의식적 결정 | 된다 |
| 화해 | 양쪽 | 신뢰를 다시 쌓아 관계를 회복하는 과정 | 안 된다 |

- **사과했다고 곧바로 용서받는 것은 아니다.** 사과는 잘못한 쪽의 선택이고 용서는 상처받은 쪽의 선택이다. 용서를 재촉하는 것은 두 번째 잘못이다.
- **용서는 묵인이나 망각이 아니다.** 잘못의 무게를 줄이지도, 잊으라고 요구하지도, 법적 책임을 면해 주지도 않는다.
- **용서가 화해의 의무를 낳지 않는다.** 용서하고도 관계를 되돌리지 않을 수 있다. 모든 관계를 복원할 필요는 없고, 건강한 거리가 나은 때도 있다.
- 신뢰는 한 번의 사과가 아니라 반복되는 배려와 달라진 행동으로 돌아온다.

## 평소에 쌓는 신뢰: 감정은행 계좌

**감정은행 계좌(Emotional Bank Account)**는 스티븐 코비가 『성공하는 사람들의 7가지 습관』에서 관계 속 신뢰의 양을 은행 잔고에 빗댄 개념이다. 친절과 약속 이행은 입금, 약속 어기기와 무신경한 말은 인출이다. 잔고가 넉넉하면 실수 한 번은 이해받지만, 잔고가 바닥이면 사소한 말 한마디도 오해를 산다.

| 여섯 가지 입금 | 뜻 |
| --- | --- |
| 상대를 이해하기 | 내 기준이 아니라 상대에게 중요한 것을 중요하게 대한다 |
| 사소한 일에 마음 쓰기 | 작은 친절과 예의가 큰 입금이고, 작은 무례가 큰 인출이다 |
| 약속 지키기 | 지킨 약속은 큰 입금이고 어긴 약속은 큰 인출이다 |
| 기대를 분명히 하기 | 말하지 않은 기대는 실망과 다툼을 부른다. 바라는 것은 처음에 직접 밝힌다 |
| 언행일치 | 없는 자리에 있는 사람에게도 한결같다 |
| 인출했을 때 진심으로 사과하기 | 같은 잘못을 되풀이하는 사과는 입금이 되지 않는다 |

가트맨의 「고마움과 존중의 문화」와 같은 이야기다. **갈등을 다루는 기술보다 갈등 이전의 잔고가 결과를 더 크게 좌우한다.**

### 칭찬이 입금이 되려면

| 조건 | 설명 |
| --- | --- |
| 구체적이다 | 「수고했어」보다 그 일이 왜 어려웠고 어떻게 해냈는지 짚는다. 관찰한 사람만 할 수 있는 칭찬이 진심으로 전해진다 |
| 요구를 싣지 않는다 | 「매번」, 「항상」은 앞으로도 그래야 한다는 기대로 들려 부담이 된다. 그때 받은 도움이 얼마나 알맞았는지만 말한다 |
| 없는 자리에서도 한다 | 당사자가 없는 곳에서 한 칭찬은 이익을 바란 말로 보이지 않아 더 진실하게 전해진다 |
| 때와 자리에 맞다 | 사람마다 반기는 방식이 다르다. 여럿 앞의 칭찬을 불편해하는 사람도 있으니 상대를 먼저 파악한다 |

## 정리

- 갈등을 키우는 것은 비난, 경멸, 방어, 담쌓기다. 그중 경멸이 가장 해롭다.
- 단정은 요청으로, 「너」는 「나」로, 추궁은 질문으로 바꾼다.
- 범람했으면 미리 정한 신호어로 멈추고 20분 이상 쉰 뒤 돌아온다.
- 사과는 요소를 갖출수록 통하고, 그중 가장 중요한 것은 책임 인정이다. 용서해 달라는 말은 가장 덜 중요하다.
- 사과·용서는 각자의 선택이고 화해는 둘의 과정이다. 용서가 화해를 의무로 만들지 않는다.
- 평소의 입금(이해, 작은 배려, 약속, 분명한 기대, 언행일치, 사과)이 갈등의 결과를 정한다.
