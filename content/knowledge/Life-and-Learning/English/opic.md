OPIc(Oral Proficiency Interview - computer)은 미국외국어교육협회(ACTFL)의 말하기 인터뷰를 컴퓨터로 옮긴 말하기 시험이다. 아바타 질문자와 대화하듯 답하고, 국내에서는 멀티캠퍼스가 운영한다. 등급(Novice Low ~ Advanced Low)은 문법의 완벽함보다 **얼마나 자연스럽고 다양하게, 감정을 담아 이야기하는가**로 갈린다.

## 시험 흐름

1. 백그라운드 서베이: 직업, 거주 형태, 여가·취미 등을 고른다. 고른 항목으로 출제 주제가 정해진다.
2. 자가 평가(Self-assessment): 내 말하기 수준을 고른다. 이 선택으로 시작 난이도가 정해진다.
3. 장비 세팅과 샘플 문항
4. 본 시험: 40분 안에 모든 문항에 답한다.

- 자가 평가 난이도에 따라 12문항(난이도 1~2) 또는 15문항(3~6)이 나온다. 1번은 자기소개다.
- 문항은 선택 주제 세트, 공통(돌발) 주제 세트, 롤플레이(11~13번), 고난도 세트(14~15번)로 짜인다.
- 질문은 미리 볼 수 없으니, 처음 몇 초 안에 못 알아들었으면 바로 다시 듣기(replay)를 누른다.
- 세부 구성과 접수 일정은 OPIc 공식 사이트(opic.or.kr)에서 확인한다.

## 모든 답변의 기본 원칙

- **Main Point(MP)를 먼저, 짧고 분명하게.** 그 뒤 MP를 뒷받침하는 이야기 전개가 그만큼 중요하다.
  - MP를 잡기 어려우면 질문을 하나로 좁혀 본다. "주말에 뭐 해?" → "주말에 넷플릭스로 뭘 볼 거야?"
- **MP 직후 감정을 말한다.** 감정 표현이 무엇보다 중요하다.
- **다른 사람을 등장시킨다.** AL을 받으려면 이야기에 '나' 외의 인물과 관계가 드러나야 한다.
- **같은 말을 반복하지 않는다.** IH에서 AL로 못 올라가는 가장 흔한 이유다.
- 질문자에게 말을 거는 듯 **you**를 쓰며 대화체로 말한다.
- 문법 실수는 핀셋처럼 고치려 하지 말고, filler를 넣고 새 문장으로 다시 말한다.
- 자기소개에서 나에 대한 구체적 정보를 주고, 이후 답변에서 한두 번씩 끌어다 쓴다.

### 쓰기 좋은 연결 표현

- `Here's the thing.` / `Let me tell you about ~` / `I gotta tell you ~`
- `I don't know if you've heard about ~`
- `Anyway, ~`: 짧은 배경 설명 뒤 본론(MP)으로 넘어갈 때
- 의인화로 재치 더하기: `Now my bed is calling my name.`
- 일반론에서 나로 전환: `For me, ~` / `As for me, ~`

## 유형별 답변 구조

| 유형 | 구조 |
| --- | --- |
| 선호 | `I love ~!` → `There are several reasons for my preference. To start with ~ / What's more ~` |
| 묘사 | MP → 감정(좋다/싫다) → 이유. 같은 감정을 유지하다 아주 일부만 다른 감정을 섞으면 깊이 있어 보인다 |
| 비교 | 주제 제시 → 지금은 A, 이런 점이 좋다 → 예전엔 B, 이런 점이 아쉬웠다 → 지금의 감정. (반대로 과거가 더 좋았던 경우도 가능: 예) 미세먼지) |
| 경험 | MP(클라이맥스) 먼저 → 직접 인용("그때 난 이렇게 생각했어: …"를 현재 시제로) → 결론. 처음부터 다른 인물을 등장시키면 좋다 |
| 습관 | 유일하게 MP 없이 자유롭게. 자기소개와 연결하고, "past → but over time → present"로 빠르게 비교 |
| 뉴스·이슈 | 사회 이야기 → `For me, ~`로 나와 연결 |

- **콤보 세트**: 세 문항을 각각 다른 질문이 아니라 하나의 큰 질문으로 보고, 매 문항 새로운 내용을 보여 준다. 첫 문항(묘사·습관)은 길게 할 필요 없다.
- 자주 재활용되는 토픽: 나의 습관(가장 빈출), 다른 사람의 습관, 과거 경험

## 롤플레이 (11~13번)

상대(아는 사람/모르는 사람)와 방식(대면/전화/드물게 자동응답기)이 바뀐다.

**11번: 질문하기**

용건 → 질문 → (상대 답변 가정) 리액션 → 반복 → 감정 → 질문 두 개 더 → 감사 인사. 내내 긍정적인 반응을 유지한다.

**12번: 문제 해결**

"~할 수 있을까요?" → "왜 안 되죠?" → "아, X 때문이군요" → "That's too bad." → "그럼 대신 ~는 가능할까요?" → "다행이네요, 고마워요"

**13번: 관련 경험**

롤플레이에서 빠져나와 12번과 비슷한 실제 경험을 말한다. MP(어떤 문제, 느낀 점과 이유) → 간접 화법으로 상황 설명 → 해결 과정으로 마무리.

## 고난도 세트 (14~15번)

- 14번: 비교 문제
- 15번: 뉴스·사회 이슈, 사람들에 관한 질문 → 일반론에서 자연스럽게 나의 이야기로 전환한다.
