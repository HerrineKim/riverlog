> English Grammar Here의 이미지 자료 「Speaking Phrases」를 바탕으로 재구성한 노트다. 격식 정도와 쓰임을 덧붙이고, 틀리거나 맥락이 다른 표현은 고쳐 넣었다.

같은 뜻이어도 표현마다 **격식(register)**이 다르다. 친구에게 쓰는 말을 업무 메일에 쓰면 가볍고, 반대면 딱딱하다. 아래 표의 「격식」은 세 단계로 표시한다.

- **캐주얼**: 친구·동료와 말할 때
- **중립**: 대부분의 상황에서 무난
- **격식**: 업무 문서, 처음 만난 사람, 공식 자리

## 의견 말하기 (I think)

`I think`만 반복하지 않고 확신의 정도에 따라 고른다.

| 표현 | 뉘앙스 | 격식 |
| --- | --- | --- |
| If you ask me, … | 내 생각을 말하자면 (묻지 않았어도 의견을 낼 때) | 캐주얼 |
| The way I see it, … | 내가 보기엔 | 중립 |
| As far as I can tell, … | 내가 아는 한 (정보가 제한적임을 인정) | 중립 |
| As far as I'm concerned, … | 나로서는 (다른 사람 생각과 상관없이) | 중립 |
| To my way of thinking, … | 내 사고방식으로는 | 중립 |
| In my view, … / In my opinion, … | 제 견해로는 | 격식 |
| It's my belief that … / I honestly believe that … | 확신을 담아 | 격식 |

`In my point of view`는 흔한 오용이다. `From my point of view` 또는 `In my view`가 맞다.

## 이유 대기 (Because)

전치사구 뒤에는 명사가, `in that`·`for the reason that` 뒤에는 절이 온다.

| 표현 | 쓰임 | 예 |
| --- | --- | --- |
| due to + 명사 | ~ 때문에 (원인) | The event was canceled **due to** the rain. |
| considering + 명사/절 | ~를 고려하면 | **Considering** the deadline, we should start now. |
| in that + 절 | ~라는 점에서 | The plan is risky **in that** it has no fallback. |
| inasmuch as + 절 | ~이므로 (문어체) | **Inasmuch as** you agreed, we'll proceed. |
| for the reason that + 절 | ~라는 이유로 (장황해서 `because`가 대개 낫다) | |

목적을 나타내는 표현은 이유와 구별한다. `for the sake of`(~를 위해), `in the interest of`(~를 위해, ~의 이익을 위해), `on behalf of`(~를 대신해, ~를 대표해)는 「왜냐하면」이 아니다. `in behalf of`는 옛 미국식 표현이고 지금은 `on behalf of`를 쓴다.

## 인사 (Hello)

| 표현 | 쓰임 | 격식 |
| --- | --- | --- |
| Hey / Hey there | 아는 사이 | 캐주얼 |
| How are ya? / Howdy? | 아주 가볍게. Howdy는 미국 남부 느낌 | 캐주얼 |
| Long time no see | 오랜만이야 | 캐주얼 |
| Good to see you | 반가워 (아는 사람을 다시 만났을 때) | 중립 |
| How are you feeling today? | 몸 상태를 물을 때 (아팠던 사람에게). 일반 인사로는 `How are you doing?` | 중립 |

처음 만난 사람에게는 `Nice to meet you`, 다시 만난 사람에게는 `Good to see you`를 쓴다.

## 감사 (Thank you)

| 표현 | 뉘앙스 | 격식 |
| --- | --- | --- |
| Cheers. | 고마워 (영국·호주에서 흔함) | 캐주얼 |
| Thanks a ton for helping out. | 도와줘서 정말 고마워 | 캐주얼 |
| Many thanks. | 대단히 감사 (메일 맺음말로도 씀) | 중립 |
| That's so kind of you. | 친절에 대한 감사 | 중립 |
| I can't thank you enough. | 아무리 감사해도 모자라다 | 중립 |
| Words can't describe how thankful I am. | 말로 다 못 할 만큼 | 감정적 |

## 감사에 답하기 (You're welcome)

| 표현 | 뉘앙스 | 격식 |
| --- | --- | --- |
| You got it. / Cool. | 응, 별거 아냐 | 캐주얼 |
| It's all gravy. | 다 괜찮아 (속어, 드묾) | 캐주얼 |
| No problem / No worries | 문제없어 | 캐주얼 |
| Don't mention it. / Not at all. | 별말씀을 | 중립 |
| My pleasure. | 기꺼이 한 일 | 격식 |
| Glad to be of any assistance. | 도움이 되어 기쁘다 (서비스 응대) | 격식 |

업무 메일에서 `No problem`은 부정어라 가볍게 들릴 수 있다. 대안은 [[business-expressions|비즈니스 미팅 쿠션 표현]]의 「지나치게 낮추지 않기」에 있다.

## 칭찬 (Well done)

| 표현 | 쓰임 |
| --- | --- |
| Way to go! / Good for you! | 잘했다, 잘됐다 (캐주얼) |
| Well, look at you go! | 와, 대단한데 (진척을 보며) |
| You did it this time. | 이번엔 해냈네 (원 이미지의 `that time`은 어색하다) |
| You're really improving. | 점점 나아지고 있다 (과정 칭찬) |
| I'm impressed. | 인상적이다 (중립·업무에서도 무난) |
| Marvelous! / Tremendous! | 훌륭하다 (다소 과장된 느낌) |

## 거절 (No)

거절은 **감사·아쉬움 + 이유 + (대안)** 순서로 하면 부드럽다.

| 표현 | 뉘앙스 |
| --- | --- |
| I'd love to, but I can't. | 하고 싶지만 못 한다 |
| I wish I could make it work. | 어떻게든 해 보고 싶은데 안 된다 |
| Maybe another time. | 다음에 (대안 제시) |
| I'm already booked. | 선약이 있다 |
| No thanks, I have another … | 고맙지만 다른 게 있다 |
| That's not going to work for me. | 나한테는 안 맞는다 (단호함) |
| I'm sorry, I'm busy. | 바쁘다 (짧아서 차갑게 들릴 수 있다) |

## 애정 표현 (I love you)

연인 사이 표현이라 업무·친구 사이에는 쓰지 않는다.

| 표현 | 뉘앙스 |
| --- | --- |
| I adore you. | 너무 좋아 (가볍게도 씀) |
| You mean the world to me. / You are precious. | 소중한 사람 |
| I'm better because of you. | 너 덕분에 더 나은 사람이 된다 |
| You complete me. | 너로 완전해진다 (영화 대사로 유명) |
| I'm infatuated with you. | 푹 빠졌다 (일시적 열병 뉘앙스) |
| You set my heart on fire. | 마음에 불을 지핀다 (시적, 과장) |

## 정리

- 같은 의미라도 격식이 다르다. 상대와의 관계를 먼저 보고 표현을 고른다.
- 의견은 확신의 정도로, 이유는 뒤에 오는 품사(명사·절)로 고른다. 목적 표현(`for the sake of`)을 이유로 쓰지 않는다.
- 거절과 감사 응답은 업무 상황에서 특히 말투가 드러난다. 업무용은 [[business-expressions|비즈니스 미팅 쿠션 표현]]을 따른다.
