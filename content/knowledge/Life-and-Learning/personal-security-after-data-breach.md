> 금융위원회·금융감독원 「[오픈뱅킹 안심차단서비스 시행](https://fsc.go.kr/no010101/85644)」(2025.11)과 「비대면 계좌개설 안심차단 시행」(2025.03) 보도자료, 한국정보통신진흥협회 [엠세이퍼](https://www.msafer.or.kr/index.do), 통신사 유심보호서비스 안내, USENIX Security 2025 논문 「[ChoiceJacking](https://www.usenix.org/conference/usenixsecurity25/presentation/draschbacher)」을 바탕으로 종합한 노트다.

## 유출 뒤에 벌어지는 일

유출된 이름, 연락처, 주소, 주문 내역은 그대로 쓰이기보다 **다음 공격의 재료**가 된다.

| 2차 피해 | 모습 |
| --- | --- |
| 맞춤형 피싱 | 유출 기업이나 카드사를 사칭해 「카드가 발급됐다」, 「피해를 보상한다」, 「유심이 도착했다」는 전화·문자를 보내고 가짜 고객센터나 악성 앱 설치로 유도한다. 배송지와 주문 정보까지 알고 있어 진짜처럼 들린다 |
| 명의도용 | 탈취한 신분 정보와 인증 수단으로 휴대전화를 개통하고 비대면 계좌와 대출을 연다 |
| 계정 연쇄 탈취 | 한 서비스에서 유출된 아이디와 비밀번호를 다른 서비스에 그대로 넣어 본다(크리덴셜 스터핑). 비밀번호를 여러 곳에 같이 쓰면 한 번의 유출이 전체로 번진다 |
| 무단 결제 | 쇼핑몰에 등록해 둔 카드와 간편결제로 결제한다 |

## 유출 통지를 받았을 때

1. 통지에 적힌 유출 항목을 확인한다. 비밀번호가 포함됐으면 그 서비스와 **같은 비밀번호를 쓰던 모든 서비스**의 비밀번호를 바꾼다.
2. 그 서비스에 등록한 결제 수단의 결제 내역을 확인한다. 카드번호와 인증 정보(유효기간, CVC)까지 유출됐으면 카드를 재발급하고, 쓰지 않는 해외 결제는 차단한다.
3. 보상·환불·재발급을 안내하는 문자의 링크는 누르지 않는다. 공식 앱이나 대표 번호로 직접 확인한다.
4. 아래 사전 차단 서비스를 걸어 둔다.
5. 신분증을 잃어버렸거나 사본이 넘어갔으면 재발급하고, 금융감독원의 개인정보노출자 사고예방시스템에 노출 사실을 등록한다.

피싱 전화와 문자의 유형, 송금한 뒤의 대응은 [[voice-phishing-response|보이스피싱과 스미싱]]에 있다.

## 사전 차단 서비스

### 금융거래 안심차단 3종

본인이 신청해 두면 금융권 전체에서 해당 거래가 실시간으로 막힌다. 세 가지는 따로 신청한다.

| 서비스 | 시행 | 막는 것 |
| --- | --- | --- |
| 여신거래 안심차단 | 2024년 8월 23일 | 신용대출, 카드론, 신용카드 신규 발급, 할부금융, 예·적금 담보대출 같은 신규 여신거래 |
| 비대면 계좌개설 안심차단 | 2025년 3월 12일 | 앱이나 인터넷으로 수시입출식 계좌를 새로 여는 것 |
| 오픈뱅킹 안심차단 | 2025년 11월 14일 | 내가 고른 금융회사의 계좌를 오픈뱅킹에 새로 등록하는 것, 이미 등록된 계좌의 오픈뱅킹 조회·출금 |

| 항목 | 내용 |
| --- | --- |
| 신청 | 거래 중인 은행, 저축은행, 농협·수협·신협·새마을금고·산림조합, 우체국의 영업점. 비대면으로는 은행 모바일뱅킹이나 금융결제원 「어카운트인포」 앱 |
| 해제 | **영업점을 방문해 대면으로 본인 확인을 한 뒤에만** 가능하다. 사기범이 비대면으로 풀지 못하게 한 설계다. 해제하면 바로 거래할 수 있다 |
| 확인 | 여신거래와 비대면 계좌개설 차단은 한국신용정보원 「크레딧포유」, 오픈뱅킹 차단은 어카운트인포에서 조회한다. 금융회사가 가입 사실을 주기적으로 문자나 이메일로 알려 준다 |

- 대출이나 새 계좌가 필요해지면 영업점에 가야 하는 불편이 생긴다. 당장 계획이 없다면 걸어 두는 쪽이 낫다.
- 오픈뱅킹을 막으면 **오픈뱅킹 출금에 기대는 간편결제 충전과 지역사랑상품권 구매가 멈출 수 있다.** 신청 전에 쓰고 있는 서비스를 확인하고 금융회사별로 고른다.

### 휴대전화 개통 차단: 엠세이퍼

한국정보통신진흥협회(KAIT)가 운영하는 무료 명의도용 방지 서비스다.

| 서비스 | 내용 |
| --- | --- |
| 가입사실현황조회 | 내 명의로 개통된 이동전화, 인터넷 같은 통신 회선을 한꺼번에 본다 |
| 가입제한 | 내 명의의 이동전화 신규 개통을 미리 막는다 |
| 이메일 안내 | 내 명의로 개통되면 신청한 이메일로 알려 준다 |

엠세이퍼 홈페이지나 통신 3사의 PASS 앱에서 본인 인증 뒤 이용한다. 모르는 회선이 조회되면 해당 통신사에 명의도용을 신고한다. 상담은 부정가입·명의도용 방지 상담센터(1670-1382)가 받는다.

## 심 스와핑과 유심 보호

### 심 스와핑

유심에 들어 있는 가입자 식별 정보를 빼내거나 통신사를 속여, 피해자의 번호를 공격자의 유심과 단말로 옮기는 공격이다. 번호가 넘어가면 그 번호로 오는 **문자·전화 인증을 공격자가 받는다.** 휴대전화 본인 인증만으로 비밀번호를 재설정할 수 있는 금융·가상자산·이메일 계정이 차례로 넘어간다.

| 대응 | 내용 |
| --- | --- |
| 유심보호서비스 | 통신 3사가 무료로 제공한다. 내 유심이 등록된 단말이 아닌 다른 기기에 꽂히면 통신을 막아, 복제 유심이나 무단 기기 변경으로 번호를 쓰지 못하게 한다. 2025년 5월부터 3사 모두 해외 로밍 중에도 함께 쓸 수 있다 |
| 문자 인증 줄이기 | 중요한 계정의 2단계 인증을 문자 대신 인증 앱(TOTP)이나 패스키로 바꾼다 |
| 이상 징후 | 갑자기 통화와 데이터가 끊기고 「서비스 없음」이 되거나, 요청하지 않은 인증 문자가 연달아 온다 |
| 의심될 때 | 다른 전화로 통신사에 연락해 회선을 확인·정지하고, 금융회사에 지급정지를 요청한다 |

대규모 유심 정보 유출이 알려진 직후에는 유심 교체·배송 안내를 사칭한 스미싱이 돈다. 교체 예약은 통신사 공식 앱이나 매장에서만 한다.

### 가짜 기지국

휴대전화는 신호가 센 기지국에 자동으로 붙는다. 이 성질을 이용해 통신사 기지국인 척하는 장비(가짜 기지국, 불법 초소형 기지국)를 가까이 두면 주변 단말의 접속을 끌어와 가입자 식별번호(IMSI) 같은 정보를 모으고 통신을 가로챌 수 있다. 국내에서도 2025년에 불법 초소형 기지국(펨토셀)에 접속된 가입자의 식별번호와 문자·ARS 인증 정보가 새어 나가 무단 휴대전화 소액결제 피해로 이어졌다. 이용자가 전파 단계에서 막을 방법은 없으므로 피해가 나는 지점을 줄인다.

- 쓰지 않는 **휴대전화 소액결제는 통신사 앱이나 고객센터에서 차단**하거나 한도를 낮춘다.
- 통신 요금 청구서와 결제 내역을 주기적으로 확인한다.
- 통신사가 유심 교체나 재설정을 안내하면 공식 경로로 따른다.

## 계정 보안

| 수칙 | 이유 |
| --- | --- |
| 서비스마다 다른 비밀번호 | 한 곳의 유출이 다른 계정으로 번지는 것을 끊는다. 비밀번호 관리자를 쓰면 유지하기 쉽다 |
| 다중 인증과 패스키 | 비밀번호가 새도 로그인이 되지 않는다. 방식별 차이는 [[two-factor-totp-passkey\|2단계 인증: TOTP와 패스키]]에 있다 |
| 기기 보안을 함께 | 계정 정보는 서비스 서버가 아니라 **악성코드에 감염된 개인 기기에서 빠져나가기도 한다.** 브라우저에 저장한 비밀번호와 로그인 세션이 통째로 넘어간다. 공식 스토어 밖의 앱을 설치하지 않고 OS와 앱을 최신으로 유지한다 |
| 클라우드 계정을 가장 강하게 | 구글·애플 계정에는 기기 찾기와 원격 초기화가 묶여 있다. 이 계정이 넘어가면 공격자가 휴대전화를 초기화하고 메신저로 지인에게 악성 파일을 뿌릴 수 있다 |
| 로그인 기기 점검 | 계정 설정의 로그인된 기기 목록에서 모르는 기기를 로그아웃한다 |
| 거래 알림 | 카드·계좌의 결제와 이체 알림을 켜 두면 이상 거래를 바로 안다 |
| 아는 사람이 보낸 파일도 확인 | 계정이 탈취된 지인의 메신저로 악성 파일이 온다. 예상하지 못한 파일은 다른 경로로 물어본 뒤 연다 |
| 기기 처분 | 팔거나 버리기 전에 계정을 로그아웃하고 공장 초기화한다 |

## 기기와 주변 환경

### 공용 USB 충전

공항, 역, 카페의 공용 USB 포트나 남이 건넨 케이블은 전력만이 아니라 데이터도 주고받을 수 있다. 충전기로 위장한 장치가 데이터를 빼 가는 공격을 주스 재킹(juice jacking)이라고 한다. 스마트폰은 USB 데이터 연결을 맺기 전에 화면에서 사용자 승인을 받도록 막아 왔다.

**초이스 재킹(ChoiceJacking)**은 그 승인 절차를 우회한다. 그라츠 공과대학 연구진이 2025년 USENIX Security에서 발표한 공격으로, 악성 충전기가 입력 장치인 척하며 스스로 승인 입력을 넣어 데이터 연결을 연다. 안드로이드와 iOS 양쪽, 8개 제조사 기기에서 사진·문서·앱 데이터 접근이 확인됐고, 구글·삼성·샤오미·애플이 문제를 인정하고 완화책을 넣기로 했다.

- 개인 어댑터를 전원 콘센트에 직접 꽂아 충전한다. 보조 배터리도 같은 효과가 있다.
- 공용 포트를 써야 하면 데이터 선이 없는 충전 전용 케이블이나 데이터 차단 어댑터를 쓴다.
- 충전 중 화면에 뜨는 「이 컴퓨터를 신뢰」, 「파일 전송」 같은 창은 승인하지 않고 충전 전용을 고른다. OS를 최신으로 유지한다.

### 카메라가 달린 가전

가정용 IP 카메라, 로봇청소기처럼 카메라와 마이크가 달린 기기는 출고 때의 기본 비밀번호나 단순한 비밀번호를 쓰던 기기가 집중적으로 뚫린다. 설치 직후 비밀번호를 바꾸고, 제조사 앱의 2단계 인증을 켜고, 펌웨어와 앱을 최신으로 유지한다. 살 때는 계정 보호 방식과 보안 인증 여부를 확인한다.

### 공용 와이파이

암호가 없거나 출처를 알 수 없는 와이파이에서는 금융 거래와 로그인을 피하고 이동통신 데이터를 쓴다.

## 정리

- 유출은 끝이 아니라 시작이다. 뒤따르는 사칭 연락은 공식 앱과 대표 번호로만 확인한다.
- 안심차단 3종과 엠세이퍼 가입제한은 내 명의의 대출·계좌·개통을 미리 막는다. 해제는 영업점에서만 된다.
- 유심보호서비스를 켜고, 중요한 계정의 인증을 문자에서 인증 앱이나 패스키로 옮긴다.
- 비밀번호는 서비스마다 다르게, 클라우드 계정은 가장 강하게 지킨다.
- 충전은 내 어댑터로, 승인 창은 누르지 않는다.
