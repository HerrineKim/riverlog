> CJ 칠버스(CJ Chilvers)의 글 「[35 Lessons from 35 Years of Newsletter Publishing](https://www.cjchilvers.com/blog/35-lessons-from-35-years-of-newsletter-publishing/)」(2022.01)를 요약·재구성한 노트다.

## 뉴스레터란

뉴스레터는 구독을 신청한 독자에게 정기적으로 보내는 이메일 출판물이다. 개인 발행부터 기업 마케팅까지 쓰임이 넓지만, 오래 가는 뉴스레터의 원칙은 다섯 가지 주제로 모인다. 독자와의 관계, 쓰는 법, 지표, 습관, 성장과 수익이다.

**뉴스레터는 구독자 수를 늘리는 채널이 아니라 관계를 쌓는 채널이다.**

## 1. 독자와의 관계

| 교훈 | 뜻 |
| --- | --- |
| 관계가 목적이다 | 독자 한 명과의 인연이 경력이나 삶을 바꿀 수 있다 |
| 한 사람에게 쓴다 | 메일은 결국 한 명이 열어 읽는다. 군중이 아니라 개인에게 말하듯 쓴다 |
| 정직이 통한다 | 독자는 스팸과 영업 문구를 금방 알아챈다. 솔직함과 약한 모습에는 반응한다 |
| 진심으로 신경 쓴다 | 독자를 아끼는 발행자는 생각보다 드물다. 그것만으로 차별점이 된다 |
| 직접 만난다 | 독자를 실제로 만나 보면 무엇을, 어떻게 쓸지가 달라진다 |
| 모두를 만족시킬 수 없다 | 솔직하면 적대적인 반응도 생긴다. 그래도 무관심보다 낫다 |

## 2. 무엇을, 어떻게 쓰나

- **내 목소리**가 가장 큰 경쟁력이다. 개인의 말투는 누구도 흉내 낼 수 없다.
- **짧게 쓴다.** 간결함은 독자의 시간을 아끼는 배려다. 대부분의 글은 지금보다 짧아야 한다.
- 분량이 아니라 **독자의 문제를 풀어 주는 것**이 가치다.
- **큐레이션도 가치다.** 만드는 사람은 넘치고 골라 주는 편집자는 적다.
- 가장 중요한 링크를 **맨 앞에** 둔다. 첫 링크의 클릭이 가장 많다.
- 다른 뉴스레터에서 **나를 즐겁게 한 요소**를 눈여겨본다. 즐거움이 다음 호를 기다리게 만든다.
- 예전 글을 다시 읽으면 주제 사이의 **새로운 연결**이 보인다.
- **완벽주의는 버린다.** 매력도 없고 속도만 늦춘다.

## 3. 지표와 운영

| 항목 | 원칙 |
| --- | --- |
| 성과 지표 | **답장 수**가 가장 좋은 척도다 |
| 클릭 추적 | 집착하지 않는다 |
| 구독 해지 | 쉽게 만든다. 붙잡아 두는 독자는 의미가 없다 |
| 열람률 | 제목보다 **보낸 사람 이름(From)**이 더 중요하다. 이름의 힘은 신뢰에서 나온다 |
| 이메일이라는 매체 | 다른 형식을 좋아하더라도, 이메일은 여전히 가장 보편적인 온라인 매체다 |
| 정리 | 먼저 과감히 지우고, 그다음 정리하고 자동화한다. 자동화가 독자와의 관계를 해치면 안 된다 |

## 4. 습관과 과정

- **꾸준함**이 독자의 일상에 자리를 만든다. 꾸준함의 바탕은 시간을 확보하는 것이다.
- 발행 주기는 통계상 좋다는 요일이 아니라 **내 생활 습관에 맞춰** 정한다.
- 뉴스레터는 **작업 과정의 부산물**이다. 결과물보다 과정을 개선해야 지치지 않는다.
- 영감은 기다리는 것이 아니라 **정해 둔 작업 시간**에서 나온다.
- 매일 발행하지 않더라도 **매일 만든다.** 만드는 행위가 습관을 만든다.
- 쉬는 시간도 일정에 넣는다. 창작자는 넓게 보면 즐거움을 주는 일을 한다.
- 막히면 **제약을 하나 더** 건다.
- 새 아이디어는 지금 시작하고 가면서 고친다. 실패도 다음 글의 소재가 된다.
- 계획을 발표하면 뇌는 이미 출시한 것처럼 느낀다. 그래서 사전 판매처럼 **실제 책임이 따르는 장치**를 더한다.

## 5. 성장과 수익

| 교훈 | 뜻 |
| --- | --- |
| 관심은 조금씩 얻는다 | 독자는 기본적으로 관심이 없다. 작은 신뢰를 여러 번 쌓아야 한다 |
| 구독 창구를 어디에나 | 관계가 시작되는 곳이 구독 신청란이다. 모든 채널에서 알린다 |
| 추천사를 받는다 | 기존 독자의 말이 새 독자에게 구독할 이유가 된다 |
| 무료로 더 준다 | 개별 프로젝트는 끝나도 독자는 남는다 |
| 수익은 따라온다 | 독자에게 쓸모 있으면 수익화는 자연히 생긴다. 그것을 쫓지 않는다 |
| 남의 성공을 축하한다 | 내 주제의 응원단이 된다 |
| 빨리 버린다 | 모든 것이 바뀐다. 익힌 방식을 빨리 버리는 능력이 필요하다 |

## 정리

- 뉴스레터의 중심은 구독자 수가 아니라 **독자 한 사람과의 관계**다. 그래서 답장이 가장 정직한 지표다.
- 쓰는 법의 원칙은 짧게, 내 목소리로, 독자의 문제를 풀어 주는 것이다.
- 지속하는 힘은 영감이 아니라 정해 둔 시간과 과정에서 나온다.
- 블로그나 기술 글에도 그대로 옮겨 쓸 수 있다. 「한 사람에게 쓴다」와 「과정을 개선한다」가 특히 그렇다.
