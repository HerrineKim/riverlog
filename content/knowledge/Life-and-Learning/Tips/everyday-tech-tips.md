> 「Gmail에서 다른 주소로 메일 보내기」는 팔만코딩경(42Seoul 커뮤니티 위키)의 「42메일로 이메일 보내기」를 바탕으로 보강한 노트다.

자주 찾아보게 되는 소소한 IT 문제 해결법 모음. 서비스 화면과 메뉴 이름은 업데이트로 바뀔 수 있다.

## 구글 드라이브 "다운로드 한도 초과" 우회

공유 파일은 다운로드가 몰리면 한도에 걸린다. **내 드라이브에 사본을 만들면** 사본은 별도 파일이라 받을 수 있다.

1. 공유 링크를 열고 구글 계정으로 로그인한다.
2. drive.google.com → **공유 문서함**에서 해당 파일을 찾는다. (링크 화면의 '내 드라이브에 추가'는 **바로가기**만 만들기 때문에 그대로는 한도에 계속 걸린다. 반드시 다음 단계의 사본을 만든다)
3. 파일 우클릭 → **사본 만들기**
4. 내 드라이브에 생긴 사본을 우클릭 → 다운로드
5. 파일명 앞의 "~의 사본"을 지운다.

## Gmail에서 다른 주소로 메일 보내기

학교·회사 주소처럼 다른 이메일 주소를 **보낸사람**으로 쓰고 싶을 때 Gmail의 "다른 주소에서 메일 보내기"를 쓴다.

1. Gmail **설정 → 모든 설정 보기 → 계정 및 가져오기 → 다른 주소에서 메일 보내기 → 다른 이메일 주소 추가**
2. 이름과 보낼 주소를 입력한다.
3. SMTP 서버 정보를 넣는다. 그 주소가 Google 계정(Google Workspace 학교·회사 계정 포함)에 연결되어 있으면 `smtp.gmail.com`, 포트 587(TLS)을 쓴다.
4. 사용자 이름에는 그 SMTP 서버에 로그인하는 Google 계정 주소를, 비밀번호에는 **계정 비밀번호가 아니라 앱 비밀번호**를 넣는다.
5. 해당 주소로 온 확인 메일의 링크를 누르면 끝이다.

`535-5.7.8 Username and Password not accepted` 오류는 거의 항상 4번 문제다. 앱 비밀번호는 Google 계정에 **2단계 인증을 켠 뒤** 계정 설정의 "앱 비밀번호"에서 만든다. 학교·회사 계정은 관리자가 앱 비밀번호를 막아 두었을 수 있다.

## 공용 와이파이 접속

공공 와이파이는 개방형과 보안형 두 가지 네트워크가 함께 뜬다. **보안형(Secure)** 에 접속해야 오가는 데이터가 암호화된다.

| 네트워크 | 이름(SSID) | 아이디 / 비밀번호 |
| --- | --- | --- |
| 서울시 공공 와이파이 | `SEOUL_Secure`, 더 강한 WPA3 방식은 `SEOUL_Secure_(3)` | seoul / seoul |
| 전국 공공 와이파이 (지자체·버스 등) | `Public WiFi Secure` | 대부분 wifi / wifi. 지자체마다 다를 수 있다 |
| 서울 시내버스 | `PublicWiFi@Bus_Secure_노선번호` | 위 공공 와이파이와 같다 |

- 보안형에 한 번 접속해 두면 다음부터 자동으로 붙는다. 안드로이드는 EAP 방식을 PEAP로 고르고, 아이폰은 인증서 신뢰를 한 번 승인한다.
- 지하철과 통신사 와이파이는 유심(USIM) 인증으로 비밀번호 없이 붙는 경우가 많다. 카페·편의점 와이파이 비밀번호는 매장 안내나 영수증을 본다.
- 공용 와이파이에서는 금융 거래와 중요한 로그인을 피하고, 필요하면 모바일 데이터나 VPN을 쓴다.

## Windows에서 OneDrive 완전히 제거

관리자 권한 명령 프롬프트에서 실행한다. 설치 파일 위치는 Windows 버전에 따라 다르다.

```bat
taskkill /f /im OneDrive.exe
%SystemRoot%\SysWOW64\OneDriveSetup.exe /uninstall
```

32비트 Windows이거나 위 경로에 파일이 없다면 `%SystemRoot%\System32\OneDriveSetup.exe /uninstall`을 쓴다. Windows 11에서는 **설정 → 앱 → 설치된 앱**(Windows 10은 **앱 및 기능**)에서 Microsoft OneDrive를 제거하는 방법이 가장 간단하다.

## 휴대폰으로 별 사진 찍기

1. 기본 카메라의 **프로(수동) 모드**로 들어간다.
2. 셔터 속도(노출 시간)를 10초 이상으로 길게, 초점은 **무한대(∞)**, ISO는 높게 설정한다. ISO를 최대로 올리면 노이즈가 심해지니 적당히 조절한다.
3. 바닥이나 삼각대에 고정하고 타이머로 촬영해 흔들림을 없앤다.
4. 촬영이 끝날 때까지 기다리면 완성.

## 3D 게임 멀미 줄이기

1. 시야각(FOV)을 넓힌다.
2. 모션 블러를 끈다.
3. 카메라 흔들림(head bob) 효과를 끈다.
4. 그래픽 품질보다 **프레임 우선** 설정으로 프레임을 높고 안정적으로 유지한다.
5. 그래도 힘들면 멀미약.
