> 「전자상거래 등에서의 소비자보호에 관한 법률」, 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」, 「개인정보 보호법」, 「표시·광고의 공정화에 관한 법률」, 「식품 등의 표시·광고에 관한 법률」의 조문을 바탕으로, 쇼핑몰·구독 서비스·마케팅 화면을 만들 때 걸리는 규제를 정리한 노트다.

## 어떤 법이 무엇을 다루나

| 영역 | 법 |
| --- | --- |
| 구매·해지 화면 설계 (다크패턴) | 전자상거래법 |
| 광고 문구의 진실성 | 표시광고법 |
| 문자·이메일·푸시 광고 전송 | 정보통신망법 |
| 동의 화면, 개인정보 수집·제공 | 개인정보 보호법 |
| 식품 광고 | 식품표시광고법 |

## 다크패턴

다크패턴(dark pattern)은 소비자의 착각이나 부주의를 이용해 원하지 않는 지출이나 동의를 끌어내는 화면 설계다. 전자상거래법은 2025년 2월 14일부터 여섯 가지 유형을 금지한다. 위반하면 유형마다 **1천만 원 이하의 과태료** 대상이다(제45조).

| 유형 | 금지되는 설계 | 지키는 설계 |
| --- | --- | --- |
| 숨은 갱신 (제13조 제6항) | 정기결제 금액을 올리거나 무료 체험을 유료 정기결제로 바꾸면서 동의를 받지 않는 것 | 바뀌는 날짜, 바뀌기 전과 후의 가격, 결제 방법을 미리 알리고 동의를 받는다. 취소·해지 조건과 방법도 알린다 |
| 순차 공개 가격 책정 (제21조의2 제1호) | 가격을 처음 보여 주는 화면에 필수로 내야 하는 총액의 일부만 표시하는 것 | 배송비, 수수료처럼 반드시 붙는 금액을 포함한 총액을 첫 화면에 표시한다 |
| 특정 옵션 사전 선택 (제2호) | 구매 과정에서 다른 상품·서비스 추가 여부를 묻는 항목을 미리 체크해 두는 것 | 추가 구매 항목은 선택되지 않은 상태로 둔다 |
| 잘못된 계층 구조 (제3호) | 구매·가입·해지·탈퇴의 선택지를 크기·모양·색으로 크게 다르게 만들어 한쪽만 고를 수 있거나 반드시 골라야 하는 것처럼 보이게 하는 것 | 「해지하기」와 「유지하기」를 비슷한 눈에 띄는 정도로 둔다 |
| 취소·탈퇴 방해 (제4호) | 해지 절차를 가입 절차보다 복잡하게 만들거나, 가입과 다른 방법(예: 전화)으로만 해지하게 하는 것 | 가입한 경로에서, 가입보다 복잡하지 않은 절차로 해지할 수 있게 한다 |
| 반복 간섭 (제5호) | 이미 정한 선택을 바꾸라고 팝업으로 계속 요구하는 것 | 「일정 기간 다시 보지 않기」를 제공한다 |

화면 문구에서 다크패턴을 피하는 방법은 [[ux-writing|UX 라이팅]]에 있다.

## 광고성 정보 전송

### 수신 동의

문자, 이메일, 앱 푸시, 메신저처럼 전자적 매체로 **영리 목적의 광고성 정보**를 보내려면 받는 사람의 명시적인 사전 동의가 필요하다(정보통신망법 제50조).

| 규칙 | 내용 |
| --- | --- |
| 사전 동의 | 보내기 전에 받는다. 거래 관계에서 직접 연락처를 받은 사업자가 같은 종류의 상품을 광고하는 경우 등은 예외다 |
| 야간 전송 | **오후 9시부터 다음 날 오전 8시까지**는 별도의 사전 동의가 있어야 한다 |
| 표시 사항 | 보내는 사람의 명칭과 연락처, 수신 거부나 동의 철회를 쉽게 할 수 있는 방법을 밝힌다 |
| 수신 거부 | 거부하거나 동의를 철회한 사람에게는 보낼 수 없다. 거부에 드는 통화료 같은 비용을 수신자가 부담하게 하면 안 된다 |
| 처리 결과 통지 | 수신 동의, 수신 거부, 동의 철회를 처리한 결과를 수신자에게 알린다 |
| 정기 확인 | 동의를 받은 뒤에도 정기적으로 수신 동의 여부를 확인한다 |
| 금지 행위 | 수신 거부를 피하거나 방해하는 조치, 전송자 신원이나 광고 출처를 숨기는 조치, 수신자를 속여 회신을 유도하는 것 |

사전 동의, 야간 전송, 표시 사항, 정기 확인 규칙을 어기면 **3천만 원 이하의 과태료**, 처리 결과를 알리지 않으면 1천만 원 이하의 과태료 대상이다(제76조). 전송을 **하도록 시킨 자**도 같은 과태료 대상이어서, 발송을 대행사에 맡겨도 광고주의 책임이 남는다.

### 동의 화면

| 원칙 | 근거 |
| --- | --- |
| 동의 항목 이름에 「광고성 정보 수신 동의」라는 점을 그대로 적는다. 「혜택 알림」, 「정보 제공」 같은 이름은 무엇에 동의하는지 드러나지 않는다 | 정보통신망법 제50조 (명시적인 사전 동의) |
| 홍보·판매 권유를 위한 개인정보 처리 동의는 다른 동의와 **구분해서** 받는다 | 개인정보 보호법 제22조 |
| 수집·이용 동의, 제3자 제공 동의도 각각 구분해서 받는다. 마케팅 동의 한 번으로 제3자 제공까지 묶을 수 없다 | 개인정보 보호법 제22조 |
| 선택 동의나 마케팅 동의를 하지 않았다는 이유로 서비스 제공을 거부할 수 없다 | 개인정보 보호법 제22조 |

방문 기록이나 구매 이력 같은 행태 정보를 리타기팅 태그나 광고 SDK로 모아 맞춤형 광고에 쓰는 것도 홍보·판매 권유를 위한 처리다. 개인을 알아볼 수 있는 정보와 결합되는 경우에는 광고에 쓴다는 목적을 밝히고 다른 목적과 구분한 동의로 받는다.

가입하는 쪽에서는 필수와 선택을 한꺼번에 누르는 「전체 동의」 대신 항목을 펼쳐 **제3자 제공**과 마케팅 수신을 따로 확인하고, 선택 항목이면 동의하지 않아도 가입할 수 있다는 점을 기억한다.

### 발송 전 점검

- 수신 동의를 받은 날짜, 경로, 문구를 기록으로 남겼는가
- 야간 발송 대상에 야간 동의가 따로 있는가
- 메시지에 전송자 이름, 연락처, 무료 수신 거부 방법이 있는가
- 수신 거부자가 발송 목록에서 빠지는가
- 대행사가 보내는 메시지도 같은 기준으로 검수하는가

## 부당한 표시·광고

표시광고법은 소비자를 속이거나 잘못 알게 할 우려가 있는 광고를 네 가지로 나눠 금지한다.

| 유형 | 예 |
| --- | --- |
| 거짓·과장 | 근거 자료 없이 쓰는 「국내 1위」, 「업계 최다」, 「유일」, 「무독성」 |
| 기만 | 불리한 사실을 숨기거나 줄여 보여 주는 것. 한 번만 쓸 수 있는 쿠폰을 적용한 가격을 늘 받는 가격처럼 표시하는 것, 대가를 받은 후기를 개인 후기처럼 올리는 것 |
| 부당한 비교 | 기준을 밝히지 않거나 유리한 항목만 골라 경쟁사와 비교하는 것 |
| 비방 | 근거 없이 경쟁사나 경쟁 제품을 깎아내리는 것 |

- 「1위」, 「최대」, 「최초」 같은 최상급·배타적 표현은 사실임을 뒷받침하는 자료(조사 기관, 기간, 범위)를 갖춘 뒤에 쓰고 그 기준을 함께 적는다. 홈페이지, 블로그, SNS, 옥외 광고처럼 노출되는 모든 채널에 적용된다.
- 위반하면 시정명령, 시정명령을 받은 사실의 공표, 정정광고, 과징금 대상이 되고 형사처벌도 가능하다.
- 후기 형태의 광고에서 대가 관계를 밝히는 방법은 [[sponsored-review-rules|협찬 후기와 원고료]]에 있다.

### 가짜 할인

| 수법 | 왜 문제인가 |
| --- | --- |
| 정가를 올린 뒤 할인율을 붙이는 것 | 실제로 팔린 적 없는 가격을 기준으로 삼아 할인 폭을 부풀린다 |
| 늘 같은 가격인데 「기간 한정」, 「오늘만」, 「마감 임박」으로 표시하는 것 | 서둘러야 한다는 거짓 정보로 결정을 재촉한다 |
| 일회성 쿠폰이나 특정 조건의 할인을 적용한 가격을 기본 가격처럼 보여 주는 것 | 조건을 숨긴 기만 광고다 |

판매자는 혜택의 **적용 조건**(일회성인지, 대상이 누구인지, 언제까지인지)을 가격 표시 바로 옆에 적고, 문구를 내보내기 전에 검수한다. 소비자는 할인율과 마감 표시를 그대로 믿지 않고 가격 비교 서비스의 가격 이력을 확인한다.

## 식품 광고에서 금지되는 표현

일반 식품은 약이 아니므로 병을 고치거나 막는다고 광고할 수 없다(식품표시광고법 제8조).

| 금지 | 예 |
| --- | --- |
| 질병의 예방·치료에 효능이 있는 것으로 보일 우려가 있는 광고 | 「불면증 개선」, 「당뇨에 좋은」 |
| 의약품으로 보일 우려가 있는 광고 | 「먹는 비만 치료제」, 「식욕 억제제」 |
| 건강기능식품이 아닌 것을 건강기능식품처럼 보이게 하는 광고 | 일반 식품에 기능성 인정을 받은 것처럼 표시 |
| 거짓·과장, 소비자를 속이는 광고 | 원재료나 제조 방법을 사실과 다르게 표시 |
| 다른 업체나 제품을 비방하거나 근거 없이 비교하는 광고 | - |

2026년 5월 개정 법률은 **인공지능으로 만든 가상의 의사·약사·교수 같은 전문가**가 식품을 보증하거나 추천하는 것처럼 보이게 하는 광고도 금지 목록에 넣었다. 이 조항은 2026년 11월 27일부터 시행된다.

숏폼 영상에서만 효능을 내세우고 판매 페이지에서는 그 표현을 빼는 수법도 있다. 영상도 광고이므로 같은 금지가 적용된다. 소비자는 효능을 말하는 식품 광고를 보면 제품에 **건강기능식품** 표시가 있는지부터 확인한다.

## 정리

- 구매 화면은 총액을 처음부터 보여 주고, 추가 옵션은 비워 두고, 해지는 가입만큼 쉽게 만든다.
- 광고 메시지는 사전 동의, 야간 별도 동의, 무료 수신 거부, 정기 확인이 한 묶음이다. 대행사에 맡겨도 책임은 광고주에게 남는다.
- 마케팅 동의와 제3자 제공 동의는 다른 동의와 구분해 받는다.
- 최상급 표현과 할인 표시는 근거 자료와 조건을 함께 적는다.
- 식품은 질병과 약을 연상시키는 표현을 쓸 수 없다.
