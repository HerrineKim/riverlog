> 에누리 쇼핑지식의 구매 가이드 「[체형별 맞춤의자 선택 방법!](https://enuri.com/knowcom/detail.jsp?kbno=252512)」(2016.07)을 바탕으로 재구성한 노트다.

## 바른 자세가 기준이다

의자는 디자인보다 **몸에 맞는지**로 고른다. 기준은 앉았을 때의 자세다.

- 허리가 자연스러운 **S자 곡선**을 유지한다.
- 등과 허리가 등받이에 **빈틈 없이 밀착**된다.
- 발바닥이 바닥에 완전히 닿고, 무릎 안쪽이 눌리지 않는다.

의자를 고를 때는 이 자세가 나오도록 **등판, 목받침, 좌판, 팔걸이**의 형태와 조절 범위를 확인한다. 사람마다 체형이 달라서, 조절 가능한 부위가 많을수록 맞추기 쉽다.

## 부위별 확인 항목

| 부위 | 확인할 것 | 이유 |
| --- | --- | --- |
| 등판 굴곡 | 척추 곡선을 따라 휘어 있는가. 앉았을 때 허리 뒤에 빈틈이 없는가 | 빈틈이 있으면 허리가 펴지지 않는다. 빈틈은 허리받침으로 보완할 수 있다 |
| 등판 형태 | 일반형인가 듀얼형인가 | 아래 표 참고 |
| 등판 각도 | 뒤로 약 10도 기울어졌는가. 각도 조절이 되는가 | 작업할 때 100~105도, 쉴 때 110도 안팎이 적당하다 |
| 등판 높이·폭 | 높이 조절이 되는가. 폭 조절은 듀얼 등판에서만 가능하다 | 체형의 굴곡에 맞춰야 밀착된다 |
| 목받침 | 높이와 각도가 조절되는가 | 뒤로 기댈 때 목의 부담을 줄인다. 각도 조절형은 기대는 힘에 따라 상하로 움직인다 |
| 좌판 높이 | 신발을 벗고 등을 기댔을 때 발바닥이 바닥에 닿는가 | 발이 뜨면 허벅지와 허리에 부담이 간다 |
| 좌판 깊이 | 무릎 안쪽에 압박감이 없는가 | 너무 깊으면 등을 기대지 못하고, 얕으면 허벅지를 받치지 못한다 |
| 팔걸이 | 있는가. 높이와 폭 조절이 되는가 | 어깨와 척추의 부담을 덜어 피로가 줄어든다 |
| 높낮이 조절 | 가스 방식인가 | 나사 방식도 있지만 거의 나오지 않는다. 가스 방식이 편하다 |
| 시트 소재 | 적당히 단단한가. 스펀지라면 복원력이 좋은가 | 너무 푹신하면 몸이 가라앉아 자세가 무너진다 |
| 마감 | 조절 부위와 팔걸이가 철재라면 모서리 마감이 안전한가 | 사용 중 다칠 수 있다 |

### 등판 형태: 일반형과 듀얼형

| 구분 | 모양 | 특징 | 맞는 사람 |
| --- | --- | --- | --- |
| 일반형 | 등판이 하나로 이어짐 | 튼튼하고 안정감이 있다 | 안정감을 중시할 때 |
| 듀얼형 | 등판이 좌우 두 쪽으로 나뉨 | 몸의 움직임에 따라 각 쪽이 따로 움직여 부드럽게 받친다. 폭 조절이 가능하다 | 허리가 불편할 때 |

## 앉은 자세 점검 순서

```text
좌판 높이 ─ 발바닥이 바닥에 닿게
   │
좌판 깊이 ─ 무릎 안쪽에 틈이 남게
   │
등판 밀착 ─ 허리 뒤 빈틈 확인 (있으면 허리받침)
   │
등판 각도 ─ 작업 100~105도 / 휴식 110도
   │
팔걸이 ─ 어깨가 올라가거나 처지지 않는 높이
   │
목받침 ─ 뒤로 기댔을 때 목이 자연스럽게 받쳐지는 높이
```

아래에서 위로 맞춘다. 좌판이 먼저 정해져야 등판과 팔걸이의 기준이 생긴다.

## 아동 의자는 따로 본다

성장기 아이는 몸이 계속 바뀌므로 **모든 부위가 조절되는 제품**이 실용적이다. 어른 의자와 다른 확인 항목이 있다.

| 항목 | 내용 |
| --- | --- |
| 등판 깊이 조절 | 좌판 앞뒤로 등판을 당겨 작은 체형에도 밀착시킨다 |
| 발받침 높이 조절 | 발이 바닥에 닿지 않는 아이의 자세를 잡아 준다 |
| 무회전 | 의자가 돌아가지 않아야 집중이 흐트러지지 않는다 |
| 색상 | 밝은 톤이 정서에 좋다고 안내한다 |

## 의자만으로는 부족하다

- 각도와 높이 수치는 출발점이다. 체형과 작업에 따라 몸이 편한 쪽으로 미세 조정한다.
- 의자는 **책상과 모니터 높이와 함께** 맞춘다. 팔꿈치가 책상 높이와 비슷하고, 모니터 윗단이 눈높이 근처에 오면 목과 어깨가 덜 긴장한다. 노트북을 오래 쓴다면 거치대와 외장 키보드를 쓴다.
- 좋은 의자도 오래 앉아 있으면 몸이 굳는다. 30~60분마다 일어나 자세를 바꾸는 것이 의자 사양보다 효과가 크다.
- 허리 통증이 계속되면 의자를 바꾸기 전에 전문의 진료를 받는다.

## 정리

- 의자 선택의 기준은 **앉았을 때 허리가 S자를 유지하고 등받이에 밀착되는가**다.
- 조절되는 부위가 많을수록 체형에 맞추기 쉽다. 등판 높이·각도, 좌판 높이, 팔걸이, 목받침 순으로 확인한다.
- 등판 각도는 작업 100~105도, 휴식 110도가 기준이다.
- 허리가 불편하면 듀얼 등판, 아이에게는 등판 깊이와 발받침이 조절되는 무회전 의자를 본다.
- 결국 사양표보다 **직접 앉아서 발, 무릎, 허리, 목 순으로 점검**하는 것이 확실하다.
