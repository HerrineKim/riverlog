> Ideopunk의 글 「[100 Tips for a Better Life](https://www.lesswrong.com/posts/7hFeMWC6Y5eaSixbD/100-tips-for-a-better-life)」(LessWrong, 2020.12)를 요약·재구성한 노트입니다. 건강 관련 팁은 의학 조언이 아닙니다.

## 개요

커뮤니티에서 모은 생활 조언 100가지를 물건과 돈, 생활과 몸, 일, 생각, 나 자신, 관계, 즐거움의 일곱 주제로 묶었다. 미국에만 해당하는 팁은 뺐다.

## 1. 물건과 돈

| 팁 | 이유 |
| --- | --- |
| 제품 후기는 「제품명 reddit」으로 찾는다 | 검색 최적화된 리뷰보다 실제 사용자 의견이 나온다 |
| 오래 쓰는 물건에 돈을 쓴다 | 침대·의자처럼 인생의 큰 비중을 함께하는 물건이 효과가 크다 |
| 질 낮은 물건은 버린다 | 좋은 물건이 바로 눈에 띈다 |
| 버리는 기준을 미리 정한다 | 「혹시 몰라서」보다 어떤 규칙이든 정해 두는 편이 낫다 |
| 돈과 시간은 맞바꾼다 | 돈이 부족하면 시간을 들여 싸게 사고, 시간이 부족하면 빨리 산다 |
| 모니터를 하나 더 둔다 | 창 전환이 줄어 생각할 여유가 생긴다 |

## 2. 생활과 몸

- 하루 몇 시간 **한꺼번에 요리**해 두면 한 주 식사가 싸고 건강해진다.
- 요리가 끝나면 창문을 잠깐 연다. 조리 중에 생긴 오염 물질이 빠진다.
- 레시피는 「best」를 붙여 검색한다. 값싼 향신료만 갖춰도 음식이 훨씬 다양해진다.
- **20-20-20 규칙**: 화면을 20분 보면 20피트(약 6m) 밖을 20초 본다.
- 운동은 효과가 가장 큰 생활 습관이다. 일주일에 15분이라도 **작게 시작**한다. 근력 운동은 근육과 뼈 모두에 좋다.
- 휴대폰은 생각보다 무거워 손목에 부담을 준다. 가능하면 컴퓨터를 쓰거나 폰을 받쳐 둔다.

## 3. 일하는 법

| 원칙 | 내용 |
| --- | --- |
| 완벽보다 완성 | 먼저 내놓는 쪽이 표준이 되는 경우가 많다 |
| 시작을 쉽게 | 사람들은 일을 필요 이상으로 어렵게 만든다. 첫걸음의 문턱을 낮춘다 |
| 동기보다 규율 | 동기는 금방 사라지지만 규율은 훈련된다 |
| 믿을 만함 | 꾸준함은 드물고 귀하다. 고객은 완벽보다 일관성을 원한다 |
| 의사소통 | 지능보다 연습으로 늘리기 쉽고, 잘하면 확실한 우위가 된다 |
| 도구 숙련 | 고급 검색 연산자, 단축키, 반복 작업 자동화(AutoHotkey, AppleScript)를 익힌다. 검색 연산자는 [[google-search-operators|구글 검색 연산자]] 참고 |
| 빈 책상 | 책상 위 물건은 모두 주의를 뺏는다. 책상은 일하는 곳이지 보관함이 아니다 |
| 작은 보상 | 어설프게 끝냈더라도 해낸 일에는 스스로 보상한다 |

**하루를 보내는 방식이 곧 삶을 보내는 방식이다.**

## 4. 생각하는 법

- 남의 편향보다 **내 편향**을 찾는 것이 훨씬 어렵고, 그만큼 값지다.
- 문제를 소리 내어 설명하면 답이 보인다. 고무 오리 디버깅(rubber duck debugging)과 같은 원리다.
- **사전 부검(premortem)**: 계획이 실패했다고 가정하고, 가장 유력한 원인을 미리 고친다.
- 같은 일에 계속 놀란다면 내 **세계 모형이 틀린 것**이다. 모형을 고친다.
- 증상을 검색해 겁먹기 전에 **기저율**부터 본다. 흔한 원인이 대부분이다.
- 성공한 사람의 조언에는 **생존자 편향**이 있다. 같은 방법으로 실패한 사례는 알려지지 않는다.
- 받은 조언의 **반대도 생각**해 본다. 정말 필요한 조언을 걸러 내고 있을 수 있다.
- 가장 좋은 조언은 나를 잘 아는 친구에게서 나온다.
- 삶은 실수를 알려 주지 않는다. **스스로 경보 장치**를 만들어야 한다.
- 어리석어 보이는 사람의 말도 맞을 때가 많다. 말한 사람 때문에 의견을 버리지 않는다.

## 5. 나 자신

| 팁 | 뜻 |
| --- | --- |
| 정체성은 작게 | 「난 그런 걸 하는 사람이 아니야」라는 말이 스스로를 가둔다 |
| 좋아서 하나, 보이려고 하나 | 둘을 구분한다. 이미지 때문에 새로운 경험을 막지 않는다 |
| 일단 해 본다 | 아흔 살이 안 됐다면 시도할 시간이 있다 |
| 내 잘못이 아니어도 | 내 책임일 수는 있다 |
| 고통으로 나를 정의하지 않는다 | 그렇게 하면 고통이 오래간다 |
| 깨달음은 바로 계획으로 | 깨달음은 금방 흐려진다. 그 자리에서 구체적인 행동으로 바꾼다 |
| 나쁜 습관을 미룬다 | 미루는 버릇을 나쁜 습관에 쓴다 |
| 「다 괜찮아」라고 말해 본다 | 마음속에서 반박이 떠오르는 지점이 진짜 문제다 |
| 기본기부터 | 실존적 고민은 친구를 자주 보고 잘 자는 것만으로 줄어드는 경우가 많다 |

## 6. 사람과 관계

**피할 사람**

- 늘 억울해하는 사람과 늘 화가 나 있는 사람. 위험한 사람 대부분에게 보이는 두 신호다.
- 습관적으로 갈등을 만드는 사람.
- 불안을 먼저 심고 해결책을 파는 사람. 정치인, 마케터, 자칭 구루가 흔한 예다.
- 말과 행동이 다르면 **행동을 믿는다.** 가까운 사람의 잔인함을 눈감아 주면 언젠가 나에게 돌아온다.

**관계를 가꾸는 법**

- 연인은 **그냥 같이 있어도 즐거운 사람**을 고른다. 긴 관계의 대부분은 평범한 시간이다.
- 오래됐다는 사실이 좋은 관계·직업·신념의 증거는 아니다.
- 연인 험담을 동료나 온라인에 하면 얻는 것보다 잃는 것이 크다.
- 관계에는 새로움이 필요하다. 새로운 경험을 일부러 계획한다.
- 잘 안 맞는다고 나쁜 사람은 아니다. 사람은 복잡하다.
- 「제일 좋아하는 것」보다 「요즘 즐기는 것」을 물으면 대화가 잘 풀린다.
- 지루해하는 사람이 지루한 사람이다. 밴드나 모임처럼 무리에 들어가 본다.
- 화면 없이 함께 저녁을 먹는다.

**너그러움**

- 부모님이 생각나면 전화하고, 친구에게 아낀다고 말한다. 칭찬을 아끼지 않는다.
- 여럿이 한 사람을 비난할 때 거들지 않는다.
- 서류·사기·복잡한 절차에 서툰 사람, 말이 서툰 사람에게 인내심을 갖는다.
- **시도한 사람, 실수를 인정한 사람을 벌하지 않는다.** 벌하면 다음부터 시도하지도, 인정하지도 않는다.
- 보이지 않는 고통이 많다. 특히 수치심은 말로 꺼내기 어렵다.
- 친절하지 않을 핑계는 늘 있다. 그 핑계를 이긴다.

## 7. 즐거움

- 운동, 잠, 햇빛, 자연은 기분에 큰 영향을 주고 실험 비용도 싸다.
- 모든 것의 90%는 별로다. 어떤 장르가 싫다면 최악의 작품만 봤을 수 있다.
- 일을 사랑하지 않아도 된다. 일은 아끼는 것들을 위한 수단일 수 있다.
- 지나친 감식안은 즐거움을 줄인다.
- 좋아하는 것과 원하는 것은 다르다. 독서처럼 하면 즐겁지만 당기지 않는 일은 일부러 시작한다.
- 긴 통근은 삶의 질을 깎는다. 멀고 좋은 집이 항상 이득은 아니다.
- 남이 더 힘들거나 더 운이 좋다고 내 감정이 무효가 되지는 않는다.
- 나쁜 소식은 극적이라 눈에 띄고, 꾸준한 개선은 눈에 안 띈다. **좋은 소식을 따로 챙겨** 균형을 잡는다.

## 정리

- 일과 습관에서는 **완벽보다 시작과 꾸준함**이 반복해서 나온다.
- 생각에서는 **내 편향과 틀린 모형을 찾아 고치는 태도**가 핵심이다.
- 사람에게는 행동으로 판단하되, 시도와 실수에는 너그럽다.
- 목록 전체가 「작게 실험해 보고 맞으면 유지하라」는 한 가지 태도로 모인다.
