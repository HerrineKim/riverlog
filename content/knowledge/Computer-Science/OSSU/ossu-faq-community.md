> OSSU의 공개 컴퓨터과학 커리큘럼과 관련 자료를 주제별로 재구성한 노트다.

## 자주 묻는 질문

| 질문 | 핵심 답변 |
| --- | --- |
| Does OSSU offer a degree? | OSSU는 학위를 수여하지 않는다. CS 전공 학습을 위한 공개 자료와 순서를 안내한다. |
| How can I review the math prerequisites? | 고교 수학이 부족하면 Pre-College Math 과정으로 대수·기하·미적분 준비 과정을 보충한다. |
| What is a good course to learn a particular language? | OSSU는 특정 언어보다는 CS 핵심 개념을 중심으로 구성되어 있다. 언어별 자료는 해당 생태계 문서와 커뮤니티를 병행한다. |
| Why is the Firebase OSSU app different or broken? | 오래된 Firebase 앱과 제3자 보드는 유지보수가 중단됐을 수 있다. GitHub와 공식 사이트를 기준으로 삼는다. |
| In what order should I take the courses? | 전체를 위에서 아래로 진행하거나 영역별로 병렬 학습할 수 있다. 단, 개별 과목 선수 지식은 지킨다. |
| Does every resource in the main curriculum have to be free? | 학습 자료의 무료 접근을 목표로 하지만 인증서와 일부 평가·상호작용 기능은 유료일 수 있다. |
| Are Coursera courses free to access? | OSSU FAQ는 Coursera의 2025년 7월 무료 청강 정책 변경을 알린다. README에 남은 Coursera 강좌는 무료 접근을 보장하지 않으므로 대체 자료를 확인한다. |
| Is it necessary to purchase the Verified Upgrade for edX courses? | 영상 시청만 할 경우 유료 인증은 보통 필요하지 않지만, 일부 무료 청강 기간에 제한이 있어 시작 전에 기간을 확인한다. |
| What are the alt links? | 대체 강의 또는 동일 내용을 다른 경로로 볼 수 있는 링크다. 본 강좌가 중단되거나 유료화된 경우 활용한다. |
| Why doesn't the curriculum cover/ignore topic X? | 대학 CS 전공의 교육 기준과 과정 품질·가용성을 바탕으로 선정한다. 빠진 영역이 있다면 기여 절차를 통해 제안한다. |
| Why is the curriculum missing some pre-requisites? | 상위 과목에 필요한 배경 지식이 충분한지 직접 점검하고, 모자란 영역을 보충한다. |
| Why require experience with a sizable project before the Software Engineering courses? | 규모 있는 프로젝트를 다뤄 봐야 설계·테스트·협업의 필요성이 추상적 이론에 머물지 않는다. |
| How can I find a course on a particular subject? | 정규 목록뿐 아니라 extras/courses와 extras/readings를 검색한다. |

## 확인해야 할 접근 조건

- [공식 FAQ](https://github.com/ossu/computer-science/blob/8f8272b1d378d31494240aa1d667aa6b045c6552/FAQ.md)는 **2025년 7월 Coursera 무료 청강 정책 변경**을 안내한다. README 강좌 목록에 링크가 있다고 해서 현재 무료 수강이 보장되는 것은 아니다.
- 공식 [CS 교육과정 기준](https://github.com/ossu/computer-science/blob/8f8272b1d378d31494240aa1d667aa6b045c6552/CURRICULAR_GUIDELINES.md)은 CS2013 기반이며, CS2023은 2024년에 출판되었다는 사실도 명시한다.
- 강의 사이트의 실제 수강 가능 여부, 평가 비용, 기간 제한은 강의 페이지에서 확인한다.

## 도움 요청과 기여

- 공식 [Discord](https://discord.gg/wuytwK5s9h)에서는 강좌별 질문과 공부 모임에 참여할 수 있다.
- 개별 과제에서 막힐 때는 해당 강의 포럼을 먼저 확인하고, 문제·이미 시도한 과정·오류를 정리해 질문한다.
- 커리큘럼 개선은 [CONTRIBUTING](https://github.com/ossu/computer-science/blob/8f8272b1d378d31494240aa1d667aa6b045c6552/CONTRIBUTING.md)과 GitHub 이슈를 따른다.
