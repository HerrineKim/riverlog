C는 메모리를 직접 다루는 언어라서, 주소와 포인터를 이해하면 컴퓨터가 데이터를 실제로 어떻게 저장하는지가 보인다. 하버드 CS50 강의(부스트코스)를 바탕으로 정리했다.

- **c-basics** — 정보의 표현, 4단계 컴파일 과정, 자료형 크기, 배열과 널 종단 문자열, 명령행 인자
- **pointers-and-memory** — 16진수와 주소, 포인터, 문자열의 정체, malloc/free, 메모리 영역(스택·힙)
- **file-io** — scanf로 입력받기, fopen/fprintf/fread로 파일 읽고 쓰기
- **data-structures** — 배열, 연결 리스트, 이진 탐색 트리, 해시 테이블, 트라이, 얕은·깊은 복사
