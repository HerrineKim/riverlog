> 고려사이버대학교 「정보통신개론」(2023 겨울계절학기) 강의 내용을 바탕으로 정리했다.

[[network-basics|네트워크 기초]]의 1계층 부분이 「어떤 매체로 보내나」를 다룬다면, 이 노트는 「그 매체에 비트를 어떤 모양으로 싣고, 한 선로를 어떻게 나눠 쓰나」를 다룬다.

## 비트를 보내는 방식

### 직렬과 병렬

| 구분 | 직렬 전송 | 병렬 전송 |
| --- | --- | --- |
| 방식 | 선 하나로 비트를 차례로 | n비트를 n개 선으로 동시에 |
| 비용 | 선이 적어 싸다 | 선이 많아 비싸다 |
| 거리 | 장거리에 맞다 | 단거리용 |
| 예 | USB, SATA, 이더넷 | 옛 프린터 포트(25핀), 옛 IDE 디스크 |

컴퓨터 내부는 병렬로 다루므로 밖으로 보낼 때 병렬 → 직렬, 받을 때 직렬 → 병렬로 바꾼다. 같은 클럭이면 병렬이 빨라 보이지만, 클럭이 높아지면 선마다 신호 도착 시각이 조금씩 어긋나는 문제(skew)와 선 사이 간섭이 커진다. 그래서 고속 인터페이스는 오히려 직렬로 옮겨 갔다. IDE가 SATA로, 병렬 포트가 USB로 바뀐 이유다.

### 비동기와 동기

직렬 전송에서는 수신 측이 「어디서 한 글자가 시작하고 끝나는지」를 알아야 한다.

| 구분 | 비동기식 | 동기식 |
| --- | --- | --- |
| 단위 | 문자 하나 | 여러 바이트를 묶은 블록(프레임) |
| 경계 표시 | 문자마다 시작 비트·정지 비트 | 미리 약속한 비트 패턴(동기 문자, 플래그)으로 블록 시작을 알림 |
| 오버헤드 | 크다(8비트에 2비트 이상 추가) | 작다 |
| 어울리는 데이터 | 띄엄띄엄 생기는 입력(키보드, 시리얼 콘솔) | 연속된 대량 데이터(파일 전송) |

비동기식은 8비트 데이터에 시작·정지 비트를 붙여 10비트를 보내므로 선로 효율이 80%에 그친다. 동기식은 수신 측이 블록을 모아 두었다가 쪼개야 해서 버퍼가 필요하지만 효율이 높다. 이더넷 프레임의 프리앰블이 동기식의 「블록 시작 신호」에 해당한다.

전송 방향(단방향·반이중·전이중)은 [[network-basics|네트워크 기초]]의 「전송 방향과 충돌」에 있다.

## 아날로그 전송과 디지털 전송

정보(데이터)와 신호를 나눠 보면 조합이 네 가지다.

| 정보 → 신호 | 변환 | 예 |
| --- | --- | --- |
| 아날로그 → 아날로그 | 그대로, 또는 반송파에 실어(AM·FM) | 옛 전화, 라디오 |
| 디지털 → 아날로그 | **변조**(모뎀) | 전화선 모뎀, Wi-Fi, LTE |
| 아날로그 → 디지털 | **PCM**(표본화 → 양자화 → 부호화) | 디지털 전화, VoIP |
| 디지털 → 디지털 | **선로 부호화**(전압 패턴으로) | 이더넷 NIC |

아날로그 신호는 먼 거리를 가며 잡음이 섞이면 원래 모양을 되돌릴 방법이 없다. 증폭기는 잡음까지 키운다. 디지털 신호는 중간에서 0과 1만 판정해 깨끗하게 다시 만들 수 있어(재생 중계) 오류가 쌓이지 않는다. 지금 통신망이 거의 다 디지털로 바뀐 이유다. PCM의 8kHz·64kbps 계산은 [[voip-sip-rtp|VoIP 노트]]에 있다.

### bps와 보오

- **bps**: 초당 보내는 비트 수.
- **보오(baud)**: 초당 신호가 바뀌는 횟수.

신호 한 번에 1비트를 실으면 둘이 같다. 신호 하나가 4가지 상태를 가지면 한 번에 2비트, 8가지면 3비트를 실으므로 같은 보오에서 bps가 2배, 3배가 된다. 즉 `bps = 보오 × log₂(신호 상태 수)`다.

### 디지털 변조

반송파(일정한 사인파)의 어느 성질을 바꿔서 비트를 나타내느냐로 나뉜다.

| 방식 | 바꾸는 것 | 특징 |
| --- | --- | --- |
| ASK (진폭 편이) | 진폭(세기) | 단순하지만 잡음에 약하다 |
| FSK (주파수 편이) | 주파수 | ASK보다 잡음에 강하고 회로가 간단하다. 옛 저속 모뎀 |
| PSK (위상 편이) | 위상(파형의 시작 시점) | 잡음에 강하다. 위상을 4개로 나누면 신호당 2비트(QPSK) |
| QAM (직교 진폭) | 진폭 + 위상 | 한 신호에 많은 비트. 16-QAM은 4비트, 64-QAM은 6비트, 256-QAM은 8비트 |

QAM 단계를 올리면 같은 대역폭에서 속도가 오르지만, 점들이 촘촘해져 잡음이 조금만 있어도 틀린다. 그래서 Wi-Fi와 LTE는 신호 품질을 보고 변조 단계를 그때그때 바꾼다. 공유기 가까이에서 속도가 잘 나오는 이유 중 하나다.

### 대역폭이 정하는 한계

얼마나 빨리 보낼 수 있는지는 선로의 **주파수 대역폭**(B, Hz)과 **잡음**이 정한다.

| 정리 | 식 | 뜻 |
| --- | --- | --- |
| 나이퀴스트 | 최대 bps = 2B × log₂L (L은 신호 상태 수) | 잡음이 없다면 상태 수를 늘릴수록 빨라진다 |
| 섀넌 | 용량 C = B × log₂(1 + S/N) | 잡음이 있으면 상태를 아무리 늘려도 이 값을 넘지 못한다 |

예를 들어 대역 3kHz짜리 전화선에서 신호 대 잡음비가 30dB(S/N = 1000)면 섀넌 용량은 약 3000 × log₂1001 ≈ 30kbps다. 다이얼업 모뎀이 수십 kbps에서 멈춘 이유가 이것이고, ADSL이 전화선의 4kHz 필터를 걷어내고 1MHz 대역을 쓰면서 Mbps급이 된 이유이기도 하다([[access-network-and-wan|가입자망과 광역 회선]]).

## 다중화: 선로 하나를 나눠 쓰기

통신 장치마다 전용선을 까는 것은 비싸다. **다중화(multiplexing)** 는 여러 신호를 한 선로에 모아 보내고, 받는 쪽에서 다시 나누는(역다중화) 기술이다. [[transport-layer|전송 계층]]이 포트 번호로 여러 프로세스의 데이터를 한 연결에 섞는 것과 발상이 같고, 여기서는 물리 신호 수준에서 한다.

### FDM: 주파수로 나누기

**주파수 분할 다중화**는 각 신호를 서로 다른 주파수 대역으로 옮겨 합친다. 대역끼리 겹치지 않게 사이에 보호 대역을 둔다. 받는 쪽은 대역 통과 필터로 원하는 대역만 걸러 복조한다. 라디오·TV 채널이 대표적이고, 아날로그 신호에 맞는 방식이다. 각 신호의 대역폭 합이 선로 대역폭보다 작아야 한다.

### TDM: 시간으로 나누기

**시분할 다중화**는 시간을 슬롯으로 잘라 채널마다 돌아가며 준다. 디지털 신호에 맞는 방식이다.

| 구분 | 동기식 TDM | 비동기식(통계적) TDM |
| --- | --- | --- |
| 슬롯 배정 | 채널마다 고정 | 보낼 데이터가 있는 채널에만 |
| 빈 채널 | 빈 슬롯이 그대로 전송돼 낭비 | 낭비 없음. 대신 슬롯에 주소를 붙여야 한다 |

동기식 TDM의 대표 예가 북미 전화망의 **T1** 회선이다. 64kbps 음성 채널 24개를 한 프레임에 1바이트씩 담고, 프레임 구분용 1비트를 더한다.

```text
프레임 = 24채널 × 8비트 + 1비트 = 193비트
초당 8,000프레임(음성 표본화 주기) → 193 × 8,000 = 1.544Mbps
```

통계적 TDM의 발상을 끝까지 밀고 가면 슬롯 대신 주소가 붙은 패킷을 필요할 때만 보내는 **패킷 교환**이 된다([[network-layer|데이터 교환 방식]]).

### WDM: 빛의 파장으로 나누기

광섬유에서는 서로 다른 **파장(색)** 의 빛을 한 가닥에 함께 실어 보낸다. 원리는 FDM과 같고 대상이 빛일 뿐이다. 새 광케이블을 깔지 않고 파장만 늘려 용량을 키울 수 있어 백본망의 기본 기술이다.

| 방식 | 파장 간격 | 특징 |
| --- | --- | --- |
| CWDM (저밀도) | 넓다(20nm). 1270~1610nm 구간에 십여 개 | 장비가 싸고 전력이 적다. 도시 내 구간 |
| DWDM (고밀도) | 매우 좁다. 수십~백 개 가까운 파장 | 광섬유 한 가닥 용량을 극대화. 장거리 백본 |

### 다중화와 다중 접속

다중화는 보통 한 장비가 여러 신호를 모아 한 선로로 보내는 것이다. 여러 사용자가 **각자** 공유 매체(무선 주파수)에 접근하는 경우는 **다중 접속**이라 부르고 FDMA·TDMA·CDMA·OFDMA로 나뉜다. 이동통신 세대를 가르는 기준이 되므로 [[mobile-communication|이동통신]]에서 따로 다룬다.

## 핵심 정리

- 고속 인터페이스는 skew 때문에 병렬에서 직렬로 옮겨 갔다.
- 비동기식은 문자마다 시작·정지 비트, 동기식은 블록 단위로 약속한 패턴을 쓴다.
- 디지털 신호는 중간에서 재생할 수 있어 잡음이 쌓이지 않는다.
- bps = 보오 × 신호당 비트 수. QAM은 진폭과 위상을 함께 바꿔 신호당 비트를 늘린다.
- 속도의 상한은 대역폭과 신호 대 잡음비가 정한다(섀넌).
- 다중화는 주파수(FDM), 시간(TDM), 빛의 파장(WDM)으로 선로를 나눈다. T1은 64kbps × 24채널 + 프레이밍 = 1.544Mbps.
