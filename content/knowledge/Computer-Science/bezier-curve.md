## 베지어 곡선이란

베지어 곡선(Bézier curve)은 **시작점·끝점과 그 사이의 제어점(control point)으로 곡선 모양을 정하는** 매개변수 곡선이다. 르노 자동차의 엔지니어 피에르 베지에(Pierre Bézier)가 차체 설계에 쓰며 알려졌다. 곡선은 시작점과 끝점을 지나고, 제어점은 곡선을 자기 쪽으로 끌어당길 뿐 곡선 위에 있지 않다.

점이 2개면 직선, 3개 이상이면 곡선이 된다. 점이 n+1개면 n차 곡선이다.

| 차수 | 점 | 제어점 | 쓰이는 곳 |
| --- | --- | --- | --- |
| 1차 | P₀, P₁ | 없음 | 직선 |
| 2차 | P₀, P₁, P₂ | 1개 | TrueType 폰트, SVG `Q` |
| 3차 | P₀, P₁, P₂, P₃ | 2개 | 포토샵·일러스트레이터·피그마 펜 툴, SVG `C`, CSS `cubic-bezier()`, PostScript·OpenType(CFF) 폰트 |

## 출발점: 선형 보간

두 점 P₀, P₁을 잇는 선분 위의 점은 매개변수 t(0 ≤ t ≤ 1)로 쓴다.

```text
B(t) = P₀ + t·(P₁ − P₀) = (1 − t)·P₀ + t·P₁
t = 0 → P₀,  t = 0.5 → 중점,  t = 1 → P₁
```

이것이 선형 보간(linear interpolation, lerp)이다. 베지어 곡선은 **이 lerp를 단계마다 한 번씩 겹쳐 적용한 것**이 전부다.

## 2차 곡선: lerp를 두 번

```text
P₀ ────K₁──── P₁ ────K₂──── P₂
          \            /
           ──── K ────          K가 그리는 자취 = 2차 베지어 곡선

K₁ = lerp(P₀, P₁, t)
K₂ = lerp(P₁, P₂, t)
K  = lerp(K₁, K₂, t)
```

대입해서 정리하면 다음과 같다.

```text
B(t) = (1 − t)²·P₀ + 2(1 − t)t·P₁ + t²·P₂
```

## 3차 곡선과 행렬 표현

점 4개에도 같은 과정을 한 단계 더 반복한다.

```text
B(t) = (1 − t)³·P₀ + 3(1 − t)²t·P₁ + 3(1 − t)t²·P₂ + t³·P₃
```

계수 `1, 3, 3, 1`은 이항계수이고, 각 항의 가중치를 **번스타인 다항식(Bernstein polynomial)** 이라 한다. t의 거듭제곱과 상수 행렬로 나누면 다음과 같다.

```text
                     ┌ -1  3 -3  1 ┐ ┌ P₀ ┐
B(t) = [t³ t² t 1] · │  3 -6  3  0 │ │ P₁ │
                     │ -3  3  0  0 │ │ P₂ │
                     └  1  0  0  0 ┘ └ P₃ ┘
```

가운데 4×4 행렬은 상수라서, 곡선 여러 개를 그릴 때도 제어점만 바꿔 같은 계산을 반복하면 된다. GPU가 곡선을 빠르게 그리는 데 유리한 형태다.

## 드 카스텔조 알고리즘

식을 외우지 않아도 lerp를 재귀로 적용하면 몇 차 곡선이든 계산할 수 있다. 이것이 **드 카스텔조 알고리즘(De Casteljau's algorithm)** 이다. 다항식을 바로 계산하는 것보다 수치적으로 안정적이다.

```python
def lerp(a, b, t):
    return (a[0] + (b[0] - a[0]) * t, a[1] + (b[1] - a[1]) * t)

def bezier(points, t):
    if len(points) == 1:
        return points[0]
    next_level = [lerp(points[i], points[i + 1], t) for i in range(len(points) - 1)]
    return bezier(next_level, t)

# t를 0→1로 움직이며 점을 찍으면 곡선이 된다
curve = [bezier([(0, 0), (30, 100), (70, 100), (100, 0)], i / 50) for i in range(51)]
```

## 성질

| 성질 | 뜻 |
| --- | --- |
| 양 끝점 통과 | t=0이면 P₀, t=1이면 마지막 점 |
| 접선 방향 | 시작점의 접선은 P₀→P₁, 끝점의 접선은 P₂→P₃ 방향. 펜 툴의 핸들이 바로 이 접선이다 |
| 볼록 껍질 | 곡선은 제어점들이 만드는 볼록 다각형 안에 있다. 충돌 검사·화면 밖 판정에 쓴다 |
| 아핀 불변 | 곡선을 이동·회전·확대하려면 제어점만 변환하면 된다 |
| 전역 영향 | 제어점 하나를 움직이면 곡선 전체가 바뀐다. 그래서 긴 경로는 3차 곡선 여러 조각을 이어 붙이고(path), 이음매에서 핸들을 일직선으로 맞춰 매끄럽게 한다 |

## 웹에서 만나는 베지어 곡선

```css
/* 애니메이션 진행률 곡선: P₀=(0,0), P₃=(1,1) 고정, 두 제어점만 지정 */
.box { transition: transform 300ms cubic-bezier(0.25, 0.1, 0.25, 1); } /* = ease */
```

```html
<!-- SVG 경로: M 시작점, C 제어점1 제어점2 끝점 -->
<path d="M 0 100 C 30 0, 70 0, 100 100" />
```

## 정리

- 베지어 곡선은 제어점으로 모양을 정하는 매개변수 곡선이고, 양 끝점만 지난다.
- 원리는 선형 보간의 반복이며, 이를 재귀로 구현한 것이 드 카스텔조 알고리즘이다.
- 3차 곡선은 번스타인 다항식, 또는 상수 4×4 행렬과 제어점의 곱으로 표현된다.
- 펜 툴의 핸들, SVG `C`·`Q`, CSS `cubic-bezier()`, 폰트 외곽선이 모두 같은 수학이다.
- **복잡한 곡선은 고차 곡선 하나가 아니라 3차 곡선 조각을 이어서 만든다.**
