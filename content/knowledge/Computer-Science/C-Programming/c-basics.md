> 하버드 CS50(부스트코스 「모두를 위한 컴퓨터 과학」) 1~3강과 고무오리 CS 스터디의 CS50 정리 노트를 바탕으로 재구성한 노트다.

컴퓨터가 정보를 0과 1로 표현하는 방법, C 코드가 실행 파일이 되는 과정, 배열과 문자열이 메모리에 놓이는 방식을 다룬다. 이어지는 메모리 이야기는 [[pointers-and-memory|포인터와 메모리]]에 있다.

## 컴퓨팅 사고: 정보의 표현

- **비트**는 0 또는 1, **바이트**는 비트 8개다. 1바이트로 2⁸ = 256가지 값을 표현할 수 있다.
- 문자는 ASCII, Unicode 같은 **표준**에 따라 숫자로 바꿔 표현한다(진법·보수·부동 소수점은 [[data-representation|데이터의 표현]]).
- 그림은 픽셀마다 RGB 값을 숫자로 저장한다.
- 어떤 정보든 결국 0과 1의 조합이다.

### 알고리즘과 의사 코드

**알고리즘**은 입력을 원하는 출력으로 바꾸는 처리 과정, 즉 규칙의 순서적 나열이다. 정확성과 효율성을 함께 따져야 한다. 전화번호부에서 이름을 찾는 의사 코드에는 프로그래밍의 기본 요소가 모두 들어 있다.

| 요소 | 역할 |
| --- | --- |
| 함수 | 무엇을 할지 알려 주는 동사 (예: "책을 펼친다") |
| 조건 | 여러 갈래 중 하나를 고름 |
| 불리언 표현 | 참/거짓으로 답이 나오는 질문 (예: "찾는 이름이 이 페이지에 있는가?") |
| 루프 | 같은 일을 반복 |

## 컴파일 과정

`make`나 `clang`으로 "컴파일한다"고 하지만, 실제로는 네 단계를 거친다.

| 단계 | 하는 일 | 결과 |
| --- | --- | --- |
| 1. 전처리 (Preprocessing) | `#`으로 시작하는 지시문을 처리. 예: `#include <stdio.h>`는 헤더 파일 내용을 그 자리에 붙여 넣음 | 전처리된 C 코드 |
| 2. 컴파일 (Compiling) | C 코드를 **어셈블리 코드**로 변환 | 어셈블리 코드 |
| 3. 어셈블 (Assembling) | 어셈블러가 어셈블리 코드를 CPU가 실행할 수 있는 0과 1의 **오브젝트 코드**(기계어)로 변환 | 오브젝트 파일 |
| 4. 링크 (Linking) | 링커가 여러 오브젝트 파일(직접 짠 코드, `stdio` 같은 라이브러리)을 하나의 실행 파일로 합침 | 실행 파일 |

소스 파일이 하나뿐이어도 프로그램 시작 코드와 `printf` 같은 C 표준 라이브러리를 붙여야 하므로, 실행 파일을 만들려면 링크 단계를 반드시 거친다. 정적·동적 링킹의 차이는 [[gcc-compile-and-link|GCC 컴파일과 링크]]에 정리했다. 어셈블리 언어가 기계어로 바뀌는 과정은 [[basic-computer-programming|기본 컴퓨터 프로그래밍]]에서 볼 수 있다.

## 디버깅과 코드 디자인

- `printf`로 중간값을 출력해 보는 것이 가장 기본적인 디버깅이다. 한 줄씩 실행하며 변수를 보려면 디버거(gdb·lldb, IDE 디버거, CS50 환경의 `debug50`)를 쓴다.
- 여러 사람이 함께 작업할수록 자동 검사 도구가 도움이 된다. 포매터·린터(`clang-format`, CS50의 `style50`)는 코드가 일관된 스타일로 작성되었는지 검사한다.
- **고무 오리 디버깅**: 앞에 놓인 고무 오리(아무 물체)에게 코드를 한 줄씩 말로 설명하다 보면 문제를 스스로 발견하게 된다.

## 자료형과 크기

C의 자료형은 차지하는 메모리 크기가 정해져 있다. (64비트 리눅스·macOS 기준. C 표준은 최소 크기만 정하므로 환경마다 다를 수 있고, 예를 들어 64비트 Windows에서는 `long`이 4바이트다. `bool`은 C99~C17에서는 `<stdbool.h>`를 포함해야 쓸 수 있고, C23부터는 `bool`·`true`·`false`가 키워드라 헤더 없이 쓴다.)

| 자료형 | 의미 | 크기 |
| --- | --- | --- |
| `bool` | 불리언 | 1바이트 |
| `char` | 문자 | 1바이트 |
| `int` | 정수 | 4바이트 |
| `float` | 실수 | 4바이트 |
| `long` | 더 큰 정수 | 8바이트 |
| `double` | 더 정밀한 실수 | 8바이트 |
| `string` | 문자열 (CS50 라이브러리) | 길이에 따라 다름 |

## 배열

같은 자료형의 값들을 메모리에 **연속으로** 저장하고, 하나의 이름과 인덱스로 다루는 구조다.

```c
int scores[5];   // int 5개짜리 배열 — 20바이트가 연속으로 잡힌다
```

크기를 코드에 고정하면 점수 개수가 바뀔 때마다 코드를 고쳐야 한다. 크기를 사용자에게 입력받아 그만큼 배열을 만들면 더 유연하다.

```c
#include <cs50.h>
#include <stdio.h>

int main(void)
{
    int n = get_int("Number of scores: ");
    int scores[n];                       // 입력받은 크기의 배열 (가변 길이 배열, VLA)

    for (int i = 0; i < n; i++)
    {
        scores[i] = get_int("Score %i: ", i + 1);
    }

    int sum = 0;
    for (int i = 0; i < n; i++)
    {
        sum += scores[i];
    }
    printf("Average: %f\n", sum / (float) n);
}
```

가변 길이 배열(VLA)은 스택에 잡히므로 n이 크면 스택 오버플로우가 난다. C11부터는 컴파일러가 지원하지 않아도 되는 선택 기능이라 MSVC에서는 쓸 수 없다. 크기가 실행 중에 정해지고 클 수 있다면 `malloc`으로 힙에 잡는 것이 안전하다([[pointers-and-memory|포인터와 메모리]]).

## 문자열은 char의 배열

문자열 `"CS50"`은 메모리에 다음처럼 저장된다.

| 인덱스 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 값 | `'C'` | `'S'` | `'5'` | `'0'` | `'\0'` |

- 맨 끝의 **널 종단 문자 `\0`**(모든 비트가 0인 바이트)이 문자열의 끝을 표시한다. 그래서 4글자 문자열이 5바이트를 차지한다.
- 문자열의 길이는 `\0`을 만날 때까지 세어서 알아낸다. `\0`은 문자열 중간에 올 수 없고 끝 표시로만 쓰인다.

### 문자열 다루기

| 작업 | C | Python | JavaScript |
| --- | --- | --- | --- |
| 길이 | `strlen(s)` (`string.h`) | `len(s)` | `s.length` |
| 대문자로 | `toupper(c)` (`ctype.h`) 또는 ASCII 값에서 32를 뺌 | `s.upper()` | `s.toUpperCase()` |

ASCII에서 소문자는 대문자보다 32 크다(`'a'` = 97, `'A'` = 65). 그래서 문자를 숫자처럼 계산해 대소문자를 바꿀 수 있다.

## 명령행 인자

프로그램을 실행할 때 명령과 함께 넘기는 추가 정보다.

```c
#include <cs50.h>
#include <stdio.h>

int main(int argc, string argv[])
{
    if (argc != 2)
    {
        printf("missing command-line argument\n");
        return 1;                 // 0이 아닌 종료 코드 = 오류
    }
    printf("hello, %s\n", argv[1]);
    return 0;
}
```

- `argc`: 인자의 개수(프로그램 이름 포함), `argv`: 인자 문자열 배열
- `argv[0]`은 프로그램 이름이다. `./hello David`라면 `argv[1]`이 `"David"`.
- `main`의 반환값은 **종료 상태(exit status)** 다. 0은 성공, 그 외는 오류를 뜻한다.
- Python에서는 `sys.argv`로 같은 정보를 얻는다.

## 핵심 정리

- 컴파일 = 전처리 → 컴파일(어셈블리) → 어셈블(기계어) → 링크(실행 파일).
- 배열은 같은 자료형을 메모리에 연속으로 저장한다.
- C 문자열은 `\0`으로 끝나는 `char` 배열이라, n글자 문자열은 n + 1바이트를 쓴다.
- `main(int argc, string argv[])`로 명령행 인자를 받고, 반환값은 종료 상태다.
