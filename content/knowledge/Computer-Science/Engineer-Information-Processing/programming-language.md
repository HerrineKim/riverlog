실기 시험의 코드 문제는 언어 지식 자체보다 **자주 틀리는 함정**을 정확히 아는지를 본다. 회차마다 반복되는 개념을 언어별로 묶고, 짧은 예시로 확인한다.

## C

### 포인터와 배열

- 배열 이름은 첫 원소의 주소처럼 쓰인다. `a[i]`는 `*(a + i)`와 같다.
- `*p + 2`와 `*(p + 2)`는 다르다. 앞은 "가리키는 값 + 2", 뒤는 "두 칸 뒤의 값".

```c
char *p = "KOREA";
printf("%s\n", p + 3);    // EA   (4번째 문자부터 문자열)
printf("%c\n", *(p + 3)); // E
printf("%c\n", *p + 2);   // M    ('K' + 2)
```

- 포인터 배열: `int *arr[3]`은 int 포인터 3개짜리 배열. `**arr`는 `*arr[0]`과 같다.

```c
int a = 12, b = 24, c = 36;
int *arr[3] = {&a, &b, &c};
printf("%d", *arr[1] + **arr + 1); // 24 + 12 + 1 = 37
```

### 구조체와 구조체 포인터

- 구조체 포인터의 멤버는 `p->member` (= `(*p).member`)로 접근한다.
- 포인터에 1을 더하면 **구조체 하나 크기만큼** 다음 원소로 이동한다.

```c
struct insa { char name[10]; int age; } a[] = {{"Kim", 28}, {"Lee", 38}};
struct insa *p = a;
p++;
printf("%s %d", p->name, p->age); // Lee 38
```

### 자주 나오는 함정

- 곱셈 누적 변수를 0으로 초기화하면 결과는 항상 0이다 (`c = 0; c *= i;`).
- 함수 호출이 중첩되면 가장 안쪽부터 계산한다.

## Java

### 상속과 오버라이딩

- 부모 타입 참조로 자식 객체를 가리켜도(`Parent p = new Child();`), **오버라이딩된 메서드는 실제 객체(자식)의 것**이 호출된다 (동적 바인딩).
- 자식 메서드 안에서 재귀 호출을 하면 그 재귀도 자식의 메서드를 탄다.
- 부모에만 있는 메서드를 호출하면 부모의 것이 실행된다. 이름이 같아도 매개변수가 다르면 오버라이딩이 아니라 **오버로딩**이다.
- `super(...)`는 부모 생성자 호출, `super.method()`는 부모의 메서드 호출.
- **생성자 실행 순서**: 자식 객체를 만들면 **부모 생성자가 먼저** 실행된다. 자식 생성자에 `super()`를 쓰지 않아도 컴파일러가 첫 줄에 넣어 준다. 예: 부모 생성자가 `"Super"`, 자식 생성자가 `"Sub"`을 출력하면 `new SubClass()`의 결과는 `SuperSub`.

```java
class Parent { void show() { System.out.println("Parent"); } }
class Child extends Parent { void show() { System.out.println("Child"); } }

Parent p = new Child();
p.show(); // Child
```

### static, 객체 생성, 배열

- `static` 메서드는 객체를 만들지 않고 클래스 이름으로 호출할 수 있다. `main`에서 바로 부르려면 `static`이어야 한다.
- 객체 생성은 `new`.
- 2차원 배열은 행마다 길이가 다를 수 있다: `int a[][] = {{45, 50, 75}, {89}};`에서 `a[0].length`는 3, `a[1].length`는 1.

### switch의 fall-through

`break`가 없으면 일치한 `case`부터 **switch 끝까지 모든 문장이 실행**된다.

```java
int i = 3, k = 1;
switch (i) {
    case 3: k = 0;
    case 4: k += 3;   // 3
    case 5: k -= 10;  // -7
    default: k--;     // -8
}
```

### 비트·논리 연산자

- `&`, `|`는 boolean에도 쓸 수 있으며 **단락 평가를 하지 않는다** (양쪽 모두 계산).
- `^`(XOR)는 두 값이 다를 때 true.
- 연산자 우선순위: 비교(`==`, `!=`) > `&` > `^` > `|` > `&&` > `||`.

### 싱글톤

`getInstance()`가 항상 같은 인스턴스를 돌려주므로, 여러 변수로 받아 각각 `count()`를 호출해도 **하나의 카운터**가 증가한다.

## Python

- **set**: 순서와 중복이 없다. `add`(하나 추가), `update`(여러 개 추가), `remove`(삭제). 이미 있는 값을 추가해도 변화 없음.
- **리스트 인덱싱**: 중첩 리스트 `lol[2][1]`은 세 번째 리스트의 두 번째 값.
- **문자열 인덱싱**: `s[0]`은 첫 글자.
- **비트 시프트**: `a >> i`는 a를 2^i로 나눈 몫. `100 >> 2`는 25.
- `print(x == y)`처럼 비교식 결과는 `True`/`False`.

```python
a = {'일본', '중국', '한국'}
a.add('베트남')
a.add('중국')        # 이미 있으므로 변화 없음
a.remove('일본')
a.update({'홍콩', '한국', '태국'})
print(a)             # {'중국', '한국', '베트남', '홍콩', '태국'} (순서는 실행마다 다를 수 있음)
```

## 진법 변환 패턴

10진수를 2진수로 바꿀 때는 `n % 2`를 저장하고 `n /= 2`를 `n > 0`인 동안 반복한 뒤, **거꾸로** 출력한다.

```java
int[] bits = new int[8];
int i = 0, n = 10;
while (n > 0) {
    bits[i++] = n % 2;
    n /= 2;
}
for (i = 7; i >= 0; i--) System.out.print(bits[i]); // 00001010
```
