## EAI (Enterprise Application Integration)

기업 안의 서로 다른 플랫폼·애플리케이션을 연계·통합하는 솔루션이다.

| 유형 | 특징 |
| --- | --- |
| Point to Point | 애플리케이션끼리 1:1 직접 연결. 단순하지만 변경·재사용이 어렵다 |
| Hub & Spoke | 중앙 허브를 거쳐 연결. 확장·유지보수가 쉽지만 허브 장애가 전체로 번진다 |
| Message Bus (ESB) | 애플리케이션 사이에 미들웨어(버스)를 둔다. 확장성이 좋아 대용량 처리에 맞다 |
| Hybrid | 그룹 안은 Hub & Spoke, 그룹 사이는 Message Bus. 병목을 줄인다 |

## 신기술 용어

| 분류 | 용어 | 의미 |
| --- | --- | --- |
| 데이터 | 데이터 마이닝 | 대량 데이터에서 규칙·패턴을 찾는 기법. **분류**(모형으로 예측), **연관**(함께 나타나는 항목, 장바구니 분석), **연속**(연관 + 시간 순서), **군집화**(사전 정보 없이 묶기) |
| 데이터 | 빅데이터 / 브로드 데이터 | 기존 방식으로 처리하기 어려운 대량의 정형·비정형 데이터 / 여러 채널의 소비자 상호작용에서 생기는 마케팅용 데이터 |
| 데이터 | 메타데이터 | 데이터를 설명하는 데이터(데이터 사전, 스키마) |
| 데이터 | Linked Open Data | 웹의 공개 데이터를 서로 연결해 공유하는 방식 |
| 데이터 | 하둡(Hadoop) | 범용 서버 여러 대로 대용량 데이터를 분산 저장·병렬 처리하는 Java 기반 오픈소스 프레임워크 |
| 데이터 | 블록체인 | 거래 정보를 블록으로 연결해 P2P 참여자가 분산 저장·공동 관리하는 기술 |
| 네트워크 | IoT / M2M | 모든 사물을 인터넷으로 연결 / 기계와 기계 사이의 통신 |
| 네트워크 | 애드혹 / 메시 네트워크 | 기지국 없이 이동 단말만으로 구성, 토폴로지가 동적(재난·군사) / 많은 노드가 그물처럼 연결된 특수 목적망 |
| 네트워크 | SDN / 네트워크 슬라이싱 | 소프트웨어로 네트워크를 제어·관리 / 물리망 하나를 여러 가상망으로 분리(5G 핵심) |
| 네트워크 | NDN / NGN | 주소 대신 콘텐츠 이름으로 전달 / ITU-T가 정의한 차세대 통합 통신망 |
| 네트워크 | Wi-SUN / BLE | 스마트 그리드용 저전력 장거리 무선 / 대기 중 절전하는 저전력 블루투스 |
