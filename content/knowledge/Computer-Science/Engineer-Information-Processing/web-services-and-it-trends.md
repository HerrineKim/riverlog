## 데이터 표현과 웹 서비스

### XML과 JSON

- **XML(eXtensible Markup Language)**: HTML의 브라우저 간 호환 문제와 SGML의 복잡함을 해결하려고 만든 다목적 마크업 언어.
  - 사용자가 태그와 속성을 정의할 수 있고, 다른 마크업 언어를 만드는 데 쓰인다.
  - 유니코드 기반 다국어 지원, 대소문자 구분, 속성값은 반드시 따옴표로 감싼다.
- **JSON**: 키-값 쌍을 중괄호로 표현하는 경량 데이터 교환 형식. AJAX에서 XML을 대신해 널리 쓰인다.
- **AJAX**: 페이지 전체를 새로 고치지 않고 JavaScript로 서버와 비동기 통신하는 기법.

### SOAP, WSDL, UDDI

| 기술 | 역할 |
| --- | --- |
| SOAP | HTTP·HTTPS·SMTP 위에서 **XML 메시지**를 주고받는 통신 규약. Envelope(전체 정의), Header(선택), Body(실제 메시지)로 구성 |
| WSDL | 웹 서비스의 이름, 위치, 메시지 형식, 프로토콜을 **XML로 기술**한 문서. 클라이언트가 이를 읽고 사용할 수 있는 기능을 파악 |
| UDDI | WSDL로 기술된 웹 서비스를 등록·검색하는 저장소 |

SOAP은 무겁기 때문에 최근에는 REST로 대체하는 경우가 많다.

### REST

웹 같은 분산 하이퍼미디어 환경에서 자원을 **URI**로 표현하고, **HTTP 메서드**로 조작하는 아키텍처 스타일.

| 메서드 | 동작 |
| --- | --- |
| POST | 생성 |
| GET | 조회 |
| PUT | 갱신 |
| DELETE | 삭제 |

구성 요소: 자원(URI), 행위(메서드), 표현(메시지).

## EAI (Enterprise Application Integration)

기업 내 서로 다른 플랫폼·애플리케이션을 연계·통합하는 솔루션.

| 유형 | 특징 |
| --- | --- |
| Point to Point | 애플리케이션끼리 1:1 직접 연결. 단순하지만 재사용 어려움 |
| Hub & Spoke | 중앙 허브를 거쳐 연결. 관리 쉽지만 허브 장애 시 전체 영향 |
| Message Bus | 미들웨어(버스)를 두고 연결. 확장성 높음 |
| Hybrid | Hub & Spoke + Message Bus |

## 데이터 관련 용어

### 데이터 마이닝

대량의 데이터에서 통계적 규칙이나 패턴을 자동으로 찾아 의사결정에 활용하는 기법.

- 절차: 목적 설정 → 데이터 준비 → 가공 → 마이닝 기법 적용 → 검증
- 기법
  - **분류**: 과거 데이터로 분류 모형을 만들어 새 데이터의 결과 예측
  - **연관**: 항목 간 함께 나타나는 관계 발견 (장바구니 분석)
  - **연속**: 연관 규칙에 시간 순서를 더한 것
  - **군집화**: 사전 정보 없이 비슷한 데이터끼리 묶음

### 기타

- **빅데이터**: 기존 방식으로 처리하기 어려운 대량의 정형·비정형 데이터
- **브로드 데이터**: 다양한 채널에서 소비자와의 상호작용으로 생기는, 마케팅에 유용한 다양한 데이터
- **메타데이터**: 데이터를 설명하는 데이터 (데이터 사전, 스키마 등)
- **디지털 아카이빙**: 디지털 정보 자원을 장기 보존하는 작업
- **Linked Open Data**: 웹상의 공개 데이터를 서로 연결해 공유하는 방식
- **하둡(Hadoop)**: 일반 PC급 서버들로 대용량 데이터를 분산 저장·병렬 처리하는 자바 기반 오픈소스 프레임워크
- **블록체인**: 거래 정보를 블록으로 연결해 P2P 참여자들이 분산 저장·공동 관리하는 기술

## 네트워크 관련 신기술

| 용어 | 의미 |
| --- | --- |
| IoT | 모든 사물을 인터넷으로 연결 |
| M2M | 기계와 기계 사이의 통신 |
| 애드혹 네트워크 | 기지국·고정 장비 없이 이동 단말만으로 구성, 토폴로지가 동적으로 바뀜 (재난·군사 현장) |
| 메시 네트워크 | 많은 노드가 그물처럼 연결된 특수 목적 네트워크 |
| SDN | 소프트웨어로 네트워크를 가상화해 제어·관리 |
| 네트워크 슬라이싱 | 하나의 물리 네트워크를 여러 가상 네트워크로 분리 (5G 핵심 기술) |
| NDN | 주소 대신 콘텐츠 이름으로 데이터를 찾아 전달 |
| NGN | ITU-T가 정의한 차세대 통합 통신망 |
| Wi-SUN | 스마트 그리드 등을 위한 저전력 장거리 무선 통신 |
| BLE | 대기 상태에서 절전 모드를 유지하는 저전력 블루투스 |

그 밖에 그리드·클라우드·모바일 클라우드 컴퓨팅, NFC, UWB, 피코넷, WBAN, USN 같은 용어도 자주 등장한다.

## 운영체제·플랫폼 용어

- **UNIX**: 1960년대 말 AT&T 벨 연구소에서 개발, 대부분 C로 작성, 트리 구조 파일 시스템
- **Android**: 리눅스 커널 기반 모바일 운영체제·소프트웨어 스택 (Java, Kotlin으로 앱 개발)
- **GUI**: 마우스·키보드로 그래픽 요소를 조작하는 인터페이스 (Windows, macOS)
