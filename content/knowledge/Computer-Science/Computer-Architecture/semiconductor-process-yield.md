> IEEE Spectrum의 「[A Better Way to Measure Progress in Semiconductors](https://spectrum.ieee.org/a-better-way-to-measure-progress-in-semiconductors)」(2020.07), SK hynix 뉴스룸의 반도체 테스트 공정 해설, 단위와 공정에 관한 공개 자료를 바탕으로 종합한 노트다.

## 공정 노드 이름은 치수가 아니다

「7나노」, 「2나노」의 숫자는 예전에는 트랜지스터 게이트 길이와 대략 맞았지만, 지금은 **칩 위의 어떤 치수와도 일치하지 않는 세대 이름**이다. 7나노 공정 트랜지스터의 주요 치수는 7 nm보다 훨씬 크다. 숫자가 작을수록 더 새로운 세대이고, 세대가 바뀌면 같은 면적에 넣는 트랜지스터 수(집적도), 성능, 전력 효율이 함께 좋아진다는 뜻으로 읽는다.

| 이름 | 회사 | 읽는 법 |
| --- | --- | --- |
| N2 | TSMC | 2나노급. 2025년 4분기에 양산을 시작했다 |
| SF2 | 삼성전자 | 2나노급 |
| 18A | 인텔 | 18옹스트롬, 곧 1.8나노급이라는 이름 |
| A16 | TSMC | 16옹스트롬, 곧 1.6나노급이라는 이름 |

- 회사마다 기준이 달라서 **이름의 숫자가 같아도 집적도와 성능은 같지 않다.** 비교하려면 트랜지스터 밀도, 게이트 피치, 금속 배선 피치 같은 실제 수치를 본다.
- 2나노 아래로는 이름의 단위가 나노미터에서 옹스트롬으로 바뀌었다. 18A, A16의 A가 옹스트롬이다.

### 로직과 메모리는 경쟁하는 자리가 다르다

2나노 경쟁은 **로직 반도체**를 위탁 생산하는 파운드리의 이야기다. AI 가속기, 서버 CPU, 모바일 AP가 이 공정으로 만들어진다. D램 같은 **메모리 반도체**는 세대 이름을 따로 쓴다(10나노급을 1x, 1y, 1z, 1a, 1b, 1c 순으로 부른다). 메모리 회사는 2나노 경쟁의 직접 당사자가 아니고, [[memory-hierarchy|HBM 같은 고대역폭 메모리]]로 첨단 로직 칩 옆에서 성능을 뒷받침한다. 가속기의 종류는 [[ai-accelerators|AI 반도체]]에 있다.

## 옹스트롬

**옹스트롬(Å)** 은 길이 단위다. 1 Å = 10⁻¹⁰ m = 0.1 nm다. 국제단위계(SI)에 속하지 않고, 2019년판 SI 문서에서는 함께 쓰는 단위 목록에서도 빠졌다. 그래도 원자 크기와 자릿수가 맞아서 원자 간 거리, 결합 길이, 격자 상수, 박막 두께를 말할 때 널리 쓴다.

| 대상 | 길이 |
| --- | --- |
| 수소 원자의 보어 반지름 | 약 0.53 Å |
| 탄소-탄소 단일 결합 | 약 1.54 Å |
| X선 회절(XRD)에 흔히 쓰는 구리 Kα선의 파장 | 약 1.54 Å |
| 가시광선의 파장 | 약 4,000~7,000 Å (400~700 nm) |

반도체 공정에서 옹스트롬이 나오는 곳은 다음과 같다.

| 기술 | 내용 |
| --- | --- |
| ALD (원자층 증착, Atomic Layer Deposition) | 원료 기체를 번갈아 넣어 한 사이클에 원자층 하나 수준으로 막을 쌓는다. 대표적인 산화알루미늄 공정은 사이클당 약 1.1 Å 자란다 |
| ALE (원자층 식각, Atomic Layer Etching) | ALD의 반대로, 원자층 단위로 깎아 낸다 |
| XRD (X선 회절) | 원자 간격과 비슷한 파장의 X선을 쏘아 결정 구조와 격자 상수를 잰다 |
| 공정 이름 | 18A, A16처럼 세대 이름의 단위로 쓴다. 실제 선폭은 아니다 |

## 수율

**수율(yield)** 은 투입량 대비 양품의 비율이다. 반도체에서는 웨이퍼 한 장에 만든 칩(다이) 가운데 정상 동작하는 칩의 비율을 가리킨다. 일반 제조업에서도 투입한 원재료 대비 완성품의 비율로 같은 말을 쓴다.

칩은 여러 단계를 거치고, 단계마다 불량이 걸러진다. 회사와 교재마다 단계를 나누는 방식은 조금씩 다르지만 흔히 아래 네 단계로 본다.

| 단계 | 수율이 뜻하는 것 |
| --- | --- |
| 팹(Fab) 수율 | 투입한 웨이퍼 가운데 전공정을 끝까지 마친 웨이퍼의 비율 |
| 웨이퍼 테스트 수율 (EDS, 프로브 테스트) | 웨이퍼 위의 칩 가운데 전기적 검사를 통과한 칩의 비율 |
| 조립(패키징) 수율 | 패키징한 칩 가운데 조립 불량이 없는 것의 비율 |
| 최종 검사 수율 | 패키지 상태의 최종 검사를 통과한 비율 |

**전체(누적) 수율은 단계별 수율의 곱이다.**

```text
누적 수율 = 팹 수율 × 웨이퍼 테스트 수율 × 조립 수율 × 최종 검사 수율
예: 0.90 × 0.95 × 0.98 × 0.97 ≈ 0.813 (81.3%)
```

- 곱이기 때문에 단계가 늘수록 전체 수율은 빠르게 떨어진다. 모든 단계가 95%여도 네 단계를 거치면 약 81%다.
- 수율은 곧 원가다. 웨이퍼 한 장의 가공비는 정해져 있으므로, 양품이 절반이면 칩 하나의 원가는 두 배가 된다.
- HBM처럼 미세 공정으로 만든 D램을 여러 장 쌓아 붙이는 제품은 **팹 수율과 조립 수율이 함께** 수익성을 좌우한다. 쌓은 뒤에는 한 층만 불량이어도 적층 전체가 불량이 되기 때문이다.
- 테스트 단계에서 여분 셀로 불량 셀을 바꾸는 리페어를 거치면 메모리 수율이 올라간다.

## 공급 계약 용어

반도체는 증설에 몇 년이 걸려서 수요가 몰리면 공급이 바로 늘지 않는다. 공급이 부족한 시기에는 가격보다 **물량을 받을 수 있느냐**가 문제가 되고, 계약 조건도 달라진다.

| 용어 | 뜻 |
| --- | --- |
| 할당 (allocation) | 주문량을 모두 채울 수 없을 때 공급사가 고객별로 물량을 나눠 배정하는 것. 과거 구매 실적, 전략 고객 여부, 장기 계약 체결 여부가 기준이 된다 |
| LTA (Long-Term Agreement) | 장기 공급 계약. 여러 분기나 여러 해에 걸친 물량과 가격 조건을 미리 정한다 |
| NCNR (Non-Cancelable, Non-Returnable) | 주문을 취소할 수도, 받은 물건을 반품할 수도 없는 조건. 구속력이 강하다 |
| 테이크 오어 페이 (take-or-pay) | 약정한 물량을 가져가거나, 가져가지 않으면 대금 또는 위약금을 내는 조건. 최소 구매 약정을 가리키는 일반적인 말이다 |
| 베스트 에포트 (best effort) | 공급사가 최선을 다해 공급하되 물량을 보장하지는 않는 조건 |

- 구속 조건은 양쪽에 위험을 나눈다. 구매자는 물량을 확보하는 대신 **수요가 꺾였을 때의 재고와 현금흐름 위험**을 지고, 공급사는 증설 투자를 회수할 근거를 얻는다.
- 공급자 우위 시장에서는 NCNR과 장기 약정이 늘고, 수요자 우위로 바뀌면 조건이 완화되거나 물량 이월·조정 협의가 가능해진다.

## 정리

- 공정 노드 이름은 세대 이름이다. 회사 사이의 비교는 이름이 아니라 실제 밀도와 피치로 한다.
- 1 Å = 0.1 nm. 원자 크기의 길이를 재는 단위이고, 2나노 아래 공정 이름의 단위로도 쓴다.
- 전체 수율은 단계별 수율의 곱이며, 수율이 곧 원가다.
- 공급 부족기에는 할당, LTA, NCNR처럼 물량을 묶는 조건이 늘고, 그 대가로 구매자가 재고 위험을 진다.
