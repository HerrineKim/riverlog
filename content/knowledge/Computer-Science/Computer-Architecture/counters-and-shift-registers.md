> 고려사이버대학교 「디지털논리설계」(2024-2학기) 강의 내용을 바탕으로 정리했다.

카운터는 클럭이 들어올 때마다 정해진 순서로 상태가 바뀌는 순차 회로이고, 시프트 레지스터는 저장한 비트를 클럭마다 옆으로 한 칸씩 옮기는 회로다. 둘 다 플립플롭을 사슬처럼 이어 만든다. 플립플롭 자체는 [[digital-logic-circuits|디지털 논리 회로와 부품]]에, 상태도에서 회로를 끌어내는 설계 절차는 [[sequential-circuit-design|순차 회로 설계]]에 있다.

## 비동기 카운터 (리플 카운터)

JK 플립플롭의 J = K = 1(또는 T = 1)로 두면 클럭마다 출력이 반전된다. 첫 단에만 외부 클럭을 넣고, **각 단의 출력을 다음 단의 클럭**으로 쓰면 2진 카운터가 된다. 하강 에지 플립플롭이라면 앞 단이 1 → 0으로 떨어질 때 다음 단이 반전하므로, 아랫자리에서 자리올림이 나는 순간과 정확히 맞는다.

```text
클럭  ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓
Q_A   0  1  0  1  0  1  0  1  0    (클럭마다 반전)
Q_B   0  0  1  1  0  0  1  1  0    (Q_A가 떨어질 때 반전)
Q_C   0  0  0  0  1  1  1  1  0    (Q_B가 떨어질 때 반전)
상태  0  1  2  3  4  5  6  7  0
```

다음 단의 클럭으로 Q 대신 Q'를 쓰면(또는 상승 에지 플립플롭을 쓰면) 거꾸로 세는 하향 카운터가 된다. 단마다 MUX를 두어 Q와 Q'를 고르게 하면 상향/하향 겸용이 된다.

**약점은 지연이 쌓이는 것이다.** 자리올림이 물결처럼 한 단씩 전달되므로, 맨 윗단은 모든 단의 지연을 더한 뒤에야 바뀐다. 클럭 주기가 이보다 짧으면 안 된다.

```text
f_max ≤ 1 / (n × t_pd)        n: 플립플롭 수, t_pd: 한 단의 전파 지연

예) 8비트, 단마다 15ns → 120ns → f_max ≈ 8.3MHz
```

또 바뀌는 도중에 잘못된 값이 잠깐 보인다. 0111 → 1000으로 갈 때 아랫자리부터 차례로 바뀌어 0110, 0100, 0000을 거친다. 이 출력을 디코더에 바로 물리면 짧은 가짜 펄스가 생긴다.

## mod-N 카운터

플립플롭 M개는 2ᴹ개 상태를 갖지만, 그보다 적은 N개 상태만 쓰게 만들 수 있다(절단 시퀀스). 이때 N을 **모듈러스**라 한다.

비동기 카운터에서는 **N이 되는 순간 모든 플립플롭을 클리어**한다. N을 2진으로 적었을 때 1인 비트들만 AND로 감시하면 된다(부분 디코딩). 0~N−1 사이에는 그 비트들이 동시에 1인 값이 없기 때문이다.

| 카운터 | 클리어 조건 | 플립플롭 |
| --- | --- | --- |
| mod-6 (0~5) | 110 → Q_C · Q_B | 3개 |
| mod-10, 10진(BCD) 카운터 (0~9) | 1010 → Q_D · Q_B | 4개 |

카운터는 N에 아주 잠깐 도달했다가 0으로 돌아가므로, 출력에 폭이 좁은 **글리치**가 생긴다. 다른 회로가 이 순간을 읽으면 오동작할 수 있다. 동기 카운터나 아래의 동기식 클리어·로드로 피한다.

## 동기 카운터

모든 플립플롭에 **같은 클럭**을 넣어 동시에 바뀌게 한다. 어느 플립플롭을 반전할지는 조합 회로가 정한다. 2진 상향 카운터에서는 "아랫자리가 모두 1일 때만 이 자리가 반전한다"는 규칙이 그대로 입력식이 된다.

```text
T_A = 1
T_B = Q_A
T_C = Q_A · Q_B
T_D = Q_A · Q_B · Q_C        (JK라면 J = K = 같은 식)
```

상태도에서 출발해 여기표 → 카르노 맵으로 설계하므로, 2진 순서가 아닌 임의의 순서(그레이 코드 순서, 0·3·5·6만 도는 순서)도 만들 수 있다. 입력 x로 상향과 하향을 고르게 하거나, 0~9만 돌고 9에서 자리올림 출력 C = 1을 내는 BCD 카운터도 같은 방법으로 만든다.

| 비교 | 비동기(리플) | 동기 |
| --- | --- | --- |
| 클럭 | 첫 단만 외부 클럭, 나머지는 앞 단 출력 | 모든 단이 공통 클럭 |
| 지연 | 단 수만큼 쌓인다 | 플립플롭 한 단 + 조합 회로 |
| 과도 상태 | 중간값이 잠깐 보인다 | 동시에 바뀐다 |
| 회로 | 단순 | 단마다 AND 등 조합 회로 필요 |
| 임의 순서 | 어렵다 | 상태도로 자유롭게 |

## 카운터 활용

### 프리셋(로드) 카운터

LOAD 신호를 주면 미리 정한 값을 병렬로 넣는다. 0이 아닌 값부터 셀 수 있고, "끝까지 세면 시작값을 다시 로드"하면 mod-N이 된다. 예를 들어 4비트 카운터가 15에서 자리올림을 낼 때 5를 로드하면 5~15를 도는 mod-11 카운터다.

상용 4비트 동기 카운터 칩도 클리어 방식이 갈린다. 74161은 클리어가 비동기(즉시)라 글리치 문제가 남고, 74163은 클리어가 동기(다음 클럭에)라 "N−1일 때 클리어"를 걸면 글리치 없이 mod-N이 된다.

### 종속 연결 (cascading)

더 큰 모듈러스가 필요하면 카운터를 이어 붙인다. 아랫자리 카운터가 끝까지 셌다는 신호(자리올림, RCO)를 윗자리 카운터의 클럭에 넣으면 비동기 종속, 윗자리 카운터의 Enable에 넣고 클럭은 공통으로 주면 동기 종속이다. 10진 카운터 4개를 이으면 0000~9999를 센다.

### 분주기

T 플립플롭 하나는 클럭 두 번에 출력이 한 주기 돌므로 **주파수를 절반**으로 만든다(듀티비 50%). n단을 이으면 1/2ⁿ, mod-N 카운터의 최상위 출력은 1/N이다. 시계 IC는 32.768kHz 수정 발진기를 15단 나눠 정확히 1Hz를 얻는다(32768 = 2¹⁵).

## 시프트 레지스터

플립플롭 출력을 다음 플립플롭의 D 입력에 이어, 클럭마다 저장된 비트가 한 칸씩 이동한다. 카운터와 달리 정해진 상태 순서가 없고, 들어온 데이터를 저장하고 옮기는 것이 목적이다.

| 종류 | 입력 → 출력 | 쓰임 |
| --- | --- | --- |
| SISO (직렬 입력·직렬 출력) | 한 비트씩 넣고 n클럭 뒤 한 비트씩 나온다 | 디지털 지연선 |
| SIPO (직렬 입력·병렬 출력) | 한 비트씩 넣고 n비트를 한꺼번에 읽는다 | 직렬 → 병렬 변환. 74HC595로 마이크로컨트롤러 핀 3개로 출력 8개를 제어 |
| PISO (병렬 입력·직렬 출력) | n비트를 한꺼번에 넣고 한 비트씩 내보낸다 | 병렬 → 직렬 변환. 74HC165로 버튼 여러 개를 핀 몇 개로 읽기 |
| PIPO (병렬 입력·병렬 출력) | 한꺼번에 넣고 한꺼번에 읽는다 | 일반 저장 레지스터 |

PISO는 단마다 MUX를 두고 SH/LD 신호로 "병렬 입력을 받을지, 옆 칸 값을 받을지"를 고른다. 이 원리를 넓혀 유지·왼쪽 시프트·오른쪽 시프트·병렬 로드를 모두 고르는 것이 **범용 시프트 레지스터**(74194 등)다.

- 2진수를 왼쪽으로 한 칸 옮기면 ×2, 오른쪽으로 옮기면 ÷2다(부호 있는 수는 산술 시프트, [[register-transfer|레지스터 전송과 마이크로 연산]]).
- UART 같은 직렬 통신은 보내는 쪽 PISO와 받는 쪽 SIPO의 짝이다([[io-organization|입출력 구조]]).

### 3상태 버퍼

출력이 0과 1 말고 **하이 임피던스(Hi-Z)**, 즉 선에서 떨어진 상태를 하나 더 갖는 버퍼다. Enable이 꺼지면 출력이 끊긴다. 레지스터 여러 개의 출력을 같은 버스 선에 물려 두고, 한순간에 하나만 Enable하면 서로 충돌하지 않는다. 버스를 MUX 없이 공유하는 방법이다([[system-bus-and-arbitration|시스템 버스와 버스 중재]]).

## 시프트 레지스터 카운터

시프트 레지스터의 출력을 입력으로 되돌리면 카운터가 된다.

| 카운터 | 되먹임 | n비트로 만드는 상태 수 | 특징 |
| --- | --- | --- | --- |
| 링 카운터 | 마지막 Q를 첫 D로 | n | 1 하나가 돈다(원-핫). 디코더 없이 출력이 바로 타이밍 신호. 시작할 때 1 하나를 넣어야 한다 |
| 존슨 카운터 | 마지막 **Q'** 를 첫 D로 | 2n | 상태마다 한 비트만 바뀐다. 2입력 AND 하나로 각 상태를 디코딩 |

```text
3비트 존슨 카운터 (오른쪽 시프트, 첫 입력 = Q_C')
000 → 100 → 110 → 111 → 011 → 001 → 000
```

되먹임을 단순 연결 대신 몇 개 출력의 XOR로 만든 것이 LFSR(선형 되먹임 시프트 레지스터)이다. 의사 난수 생성과 CRC 계산에 쓰인다.

## 핵심 정리

- 비동기 카운터는 앞 단 출력을 다음 단 클럭으로 써서 단순하지만, 지연이 단 수만큼 쌓여 f_max ≤ 1/(n·t_pd)이고 중간값이 잠깐 보인다.
- mod-N 비동기 카운터는 N이 되는 순간 클리어해서 만들고, 이때 글리치가 생긴다.
- 동기 카운터는 공통 클럭으로 동시에 바뀌고, 상태도로 임의 순서를 설계할 수 있다.
- 프리셋 로드와 종속 연결로 원하는 모듈러스를 만들고, 카운터는 곧 주파수 분주기다.
- 시프트 레지스터는 입출력 방식으로 SISO·SIPO·PISO·PIPO로 나뉘며 직렬·병렬 변환의 핵심이다.
- 출력을 되먹이면 링 카운터(n상태)와 존슨 카운터(2n상태)가 된다.
