정보처리기사 실기는 소프트웨어 공학, 데이터베이스, 프로그래밍 언어, 네트워크·운영체제, 보안, 신기술 용어를 폭넓게 묻는다. 2020~2021년 기출과 시험 직전 요약 노트를 바탕으로, 문제 원문 대신 **반복 출제되는 개념**을 주제별로 정리했다.

- **software-engineering** — 모듈 결합도·응집도, 디자인 패턴, UML, 객체지향, 비용 산정, 형상 관리, UI 설계
- **software-testing** — 테스트 원리, V-모델, 블랙박스·화이트박스 기법, 테스트 오라클, 통합 테스트와 결함 관리
- **programming-language** — C 포인터·구조체, Java 상속·오버라이딩, Python 자료형 등 코드 해석 문제의 핵심 개념
- **security** — 보안 3요소, 공격 기법, 암호 알고리즘, 접근 통제
- **web-services-and-it-trends** — XML·SOAP·WSDL·REST, EAI, 데이터 마이닝과 각종 신기술 용어

데이터베이스(트랜잭션, 정규화, SQL), 운영체제(프로세스 스케줄링), 네트워크(OSI 7계층, IP·ARP·ICMP, 라우팅) 관련 출제 개념은 각각 Database, Operating-System, Network 주제의 노트에 통합했다.
