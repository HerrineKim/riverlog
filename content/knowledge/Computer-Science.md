프레임워크와 언어는 바뀌어도, 프로그램이 하드웨어 위에서 어떻게 실행되고 데이터가 어떻게 오가는지에 대한 이해는 오래 쓰인다. 이 분야에는 하드웨어(컴퓨터 구조)에서 시작해 운영체제, 네트워크, 데이터베이스로 올라가는 CS 기초를 모았다. 강의와 책으로 공부한 내용, 그리고 정보처리기사를 준비하며 정리한 개념이 함께 들어 있다. 어디서부터 볼지 정하려면 학습 로드맵 노트를 먼저 보면 된다.

- [CS 학습 로드맵](Computer-Science/cs-roadmap.md) — CS50 → 컴퓨터 구조 → 운영체제 → 네트워크 순서의 학습 로드맵과 자료
- [Computer-Architecture](Computer-Science/Computer-Architecture.md) — 논리 회로와 디지털 부품, 데이터 표현과 컴퓨터 산술, 레지스터 전송, 기본 컴퓨터의 설계와 어셈블리 프로그래밍, CPU 명령어, 파이프라인, 입출력, 메모리 계층과 캐시
- [Operating-System](Computer-Science/Operating-System.md) — 운영체제 개요, 커널, 인터럽트와 시스템 콜, 프로세스와 스레드, CPU 스케줄링, 동기화와 교착 상태, 메모리 관리와 가상 메모리, 파일 시스템, 디스크 스케줄링
- [Network](Computer-Science/Network.md) — 네트워크 기초와 OSI 7계층, IP, 전송 계층과 포트, TCP, HTTP, WebRTC
- [Database](Computer-Science/Database.md) — 데이터 모델, 트랜잭션, 정규화, SQL
- [C-Programming](Computer-Science/C-Programming.md) — C 기초와 컴파일 과정, 포인터와 메모리, 파일 입출력 (CS50)
- [Engineer-Information-Processing](Computer-Science/Engineer-Information-Processing.md) — 정보처리기사 실기의 반복 출제 개념 정리
