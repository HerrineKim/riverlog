Markdown은 `#`, `-`, `*` 같은 간단한 기호로 문서 구조를 표현하는 **경량 마크업 언어**입니다. README, TIL, 블로그, 기술 문서 대부분이 Markdown으로 쓰이고, 결국 HTML로 변환되어 보입니다.

## 제목 (Heading)

`#`의 개수로 h1~h6를 표현합니다. `#` 뒤에는 공백이 필요합니다.

```markdown
# 제목 1
## 제목 2
### 제목 3
###### 제목 6
```

## 목록

```markdown
- 딸기            <!-- 순서 없는 목록: *, -, + 모두 가능 -->
- 사과
  - 아오리 사과   <!-- 들여쓰기(Tab)로 하위 목록 -->

1. 세수          <!-- 순서 있는 목록 -->
2. 아침
3. 출근
```

## 코드

인라인 코드는 백틱 하나(`` `code` ``), 여러 줄 코드는 백틱 세 개로 감싸고 **언어 이름**을 적으면 문법 강조가 적용됩니다.

````markdown
```python
for i in range(5):
    print(i)
```
````

## 링크와 이미지

```markdown
[구글](https://google.com)
![대체 텍스트](images/photo.png)
```

이미지 크기를 조절하려면 HTML 태그를 직접 씁니다.

```html
<img src="images/photo.png" width="450" alt="설명">
```

> 로컬 에디터(Typora 등)에서 이미지를 붙여 넣을 때는 **상대 경로**로 저장되도록 설정하고, 이미지 폴더(`*.assets`)를 문서와 함께 올려야 다른 곳에서도 깨지지 않습니다. `C:\Users\...` 같은 절대 경로는 내 컴퓨터에서만 보입니다.

## 인용문

```markdown
> Life is short, you need Python!
>
> > 중첩 인용
> >
> > > 3단계 인용
```

## 표

```markdown
| 이름 | 나이 | 비고 |
| ---- | :--: | ---: |
| 포터 | 3    | 왼쪽/가운데/오른쪽 정렬 |
```

두 번째 줄의 `:` 위치로 정렬을 지정합니다. (Typora에서는 `Ctrl + T`로 표를 삽입할 수 있습니다.)

## 텍스트 강조와 기타

| 문법 | 결과 |
| --- | --- |
| `*기울임*` 또는 `_기울임_` | *기울임* |
| `**굵게**` | **굵게** |
| `***굵은 기울임***` | ***굵은 기울임*** |
| `~~취소선~~` | ~~취소선~~ |
| `---` 또는 `***` (한 줄 단독) | 수평선 |
