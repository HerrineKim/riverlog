기본 조작을 익히기 좋은 첫 모델은 **아이소메트릭(isometric) 방**입니다. 아이소메트릭은 세 축이 같은 각도로 보이는 등각 투영 시점으로, 방 하나를 잘라 비스듬히 위에서 내려다본 듯한 귀여운 3D 일러스트를 만들 때 많이 씁니다. 큐브 몇 개로 벽·바닥·가구를 만들면서 기본 조작을 모두 익힐 수 있습니다.

## 화면 조작

| 조작 | 기능 |
| --- | --- |
| 휠 드래그 | 시점 회전 |
| `Shift` + 휠 드래그 | 시점 이동(Pan) |
| `Ctrl` + 휠 드래그 / 휠 스크롤 | 확대·축소 |
| 숫자 패드 | 정면·측면·위 등 고정 시점 |
| 숫자 패드 `/` | 선택한 개체만 보기(Local View) |
| `Alt + Z` | 엑스레이 모드 (가려진 점·면도 선택 가능) |
| `N` | 우측 사이드바(Item, Tool, View) |
| `T` | 좌측 툴바 열기/닫기 |
| 영역 경계 우클릭 → Vertical/Horizontal Split | 화면 분할 |

## 변형 단축키

Blender는 마우스 드래그보다 **"단축키 + 축 + 수치"** 조합으로 정확하게 다룹니다.

| 단축키 | 기능 | 예 |
| --- | --- | --- |
| `G` | 이동(Grab) | `G` `Z` `1` → Z축으로 1m 이동 |
| `S` | 크기(Scale) | `S` `Z` `0` → Z 방향으로 납작하게(평평하게 정렬) |
| `R` | 회전(Rotate) | `R` `Z` `90` → Z축으로 90° 회전 |
| `E` | 돌출(Extrude) | 선택한 면을 수직 방향으로 뽑아냄 |
| `F` | 면 채우기 | 선택한 점·선 사이를 면으로 메움 |
| `Tab` | Object 모드 ↔ Edit 모드 | |

축 키(`X`/`Y`/`Z`)를 생략하면 자유 변형이 됩니다.

## Edit 모드

- `1` / `2` / `3`: **점(Vertex) / 선(Edge) / 면(Face)** 선택 모드
- `Shift` + 클릭: 다중 선택, `A`: 전체 선택
- 면을 선택하고 `E`로 뽑아내면 벽이나 처마의 뼈대를 쉽게 만들 수 있다.
- 일부 면을 드래그로 선택 → 우클릭 → **Separate**: 선택 부분을 별도 개체로 분리 (예: 처마만 따로 다루기)

## 모디파이어 (Modifier)

모디파이어는 원본 메시(Mesh)를 직접 고치지 않고 **비파괴적으로** 형태를 바꿔 주는 기능입니다. 켜고 끄며 결과를 비교할 수 있습니다.

### Bevel: 모서리 둥글리기

1. Object 모드에서 `Ctrl + A` → **All Transforms** (크기·회전 값을 적용해 Bevel이 고르게 들어가도록)
2. Edit 모드에서 `A`로 전체 선택 → `Ctrl + B` → 드래그로 폭 조절
3. 휠로 **Segments**를 3 정도로 늘려 부드럽게

모디파이어 패널의 Bevel을 써도 같은 효과를 비파괴적으로 얻을 수 있습니다.

### Subdivision Surface

면을 잘게 나눠 표면을 **부드럽게** 만듭니다. 모서리가 너무 뭉개지면 Bevel이나 Loop Cut으로 모서리 근처에 선을 추가해 형태를 잡습니다.

### Array

같은 개체를 일정 간격으로 반복 배치합니다. 마루 조각 하나(얇은 큐브)를 만들고 Array를 적용하면 마룻바닥이 완성됩니다.

## 방 소품 만들기 요약

- **마룻바닥**: Add → Mesh → Cube → 판자 하나 크기로 줄이고 Array. 크기 조정은 엑스레이 모드에서 한쪽 면의 점들을 드래그로 잡고 `G`로 이동
- **침대**: 큐브를 3D 커서 위치 기준으로 `S` + 축으로 늘려 형태 잡기
- **책상**: All Transforms → Edit 모드에서 앞면 선택 → **Inset Face**(`I`)로 안쪽 면 생성 → `E`로 밀어 넣어 서랍 홈 만들기, Cylinder로 다리 추가
- **원기둥 윗면 정리**: Cylinder 생성 시 Cap Fill Type을 Triangle Fan으로 하면 윗면에 중심선이 생긴다.
