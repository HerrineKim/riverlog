기본 변형(G/S/R/E)에 익숙해졌다면, 메시에 **선을 추가하고 자르고 복제하는** 도구로 좀 더 복잡한 형태를 만들 수 있습니다. 아래 도구들은 책장·서랍·의자처럼 가구를 만들 때 자주 쓰입니다.

## 핵심 도구

| 단축키 | 도구 | 용도 |
| --- | --- | --- |
| `Ctrl + R` | Loop Cut | 면을 가로지르는 고리 모양 선 추가. 휠/숫자로 분할 수 지정 → 클릭 후 위치 조정(우클릭 시 가운데) |
| `I` | Inset Faces | 선택한 면 안쪽에 테두리 면 생성. 한 번 더 `I`를 누르면 면마다 개별 Inset |
| `K` | Knife | 원하는 경로로 면을 자름. 실행 중 `C`로 보이지 않는 뒷면까지 관통해서 자르기 |
| `Alt` + 선 클릭 | Loop Select | 이어진 선 고리 전체 선택 |
| `Ctrl + X` | Dissolve | 형태는 유지하면서 선·점 제거 (`X` → Delete는 구멍이 생김) |
| `M` → By Distance | Merge by Distance | 겹쳐 있는 점들을 하나로 합침 |
| `Shift + D` | Duplicate | 복제 후 바로 이동/회전 |
| `M` (Object 모드) | Move to Collection | 개체를 컬렉션으로 정리 |

## 책장

1. 큐브를 책장 크기로 만든 뒤 `Ctrl + R`로 선반 높이만큼 Loop Cut
2. 앞쪽 칸의 면들을 선택 → `I` 두 번(개별 Inset) + `0.07` 입력으로 테두리 두께 지정
3. `E` + `Y`로 안쪽으로 밀어 넣어 칸 만들기

## 서랍

- `I`로 앞면 테두리를 만든 뒤, `Alt` + 선 선택으로 수평선을 잡아 세 서랍의 높이 균형 맞추기
- 서랍 앞면 세 개를 우클릭 → **Separate → Selection**으로 분리하고 `G`로 빼내기
- 불필요한 면은 `X` → Faces로 삭제, `E`·`I`를 반복해 서랍 속 상자 만들기

### Bevel이 너무 많은 선을 만들 때

Bevel 후 Subdivision을 넣으면 형태가 이상해질 수 있습니다. Bevel 모디파이어의 **Limit Method를 Angle**로 두면 일정 각도 이상인 모서리에만 Bevel이 들어가 선이 불필요하게 늘어나지 않습니다.

## 발받침(쿠션)

1. 직육면체 두 개를 겹쳐 놓고, `K`로 윗면을 바둑판 모양으로 자르기
2. 가운데 조각의 윗면만 선택하고 **Proportional Editing**(상단 과녁 모양 아이콘)을 켠 뒤 `G` + `Z`로 올려 볼록하게
3. 엑스레이 모드에서 밑면 점을 모두 선택 → `S` `Z` `0`으로 바닥을 평평하게
4. Object 모드에서 All Transforms 적용 → Bevel 모디파이어 추가 (Clamp Overlap 해제, Amount 0.02m, Segments 3)

## 슬리퍼

1. 큐브를 `Ctrl + R`로 세 칸으로 나누고 양옆 선을 살짝 내려 곡면 만들기
2. 가로로도 자른 뒤 앞부분을 `S` `Z`, `G` `Z`로 다듬고 점 단위로 미세 조정
3. `K`로 발 넣을 부분을 자르고, 그 면을 `E`로 안쪽으로 밀어 넣기 (`K` → `C`로 관통 컷)
4. Subdivision을 넣고, 모디파이어를 껐다 켰다 하며 형태 확인

## 카펫과 의자

- **카펫**: Cylinder를 납작하게 만든다. 이때 **Pivot Point**(변형 기준점: 3D 커서, 개별 원점 등)를 바꾸는 법을 익혀 두면 편하다.
- **의자 다리(5개)**:
  1. Cylinder의 위·아래 면을 지우고, `Alt` + 선 클릭으로 아래 테두리만 선택
  2. `E` → `S`, `E` → `Z`를 반복해 파이프 모양 다리 하나 만들기
  3. `Shift + D`로 복제 후 `R` `Z` `72` → 360° / 5 = 72°씩 돌려 다리 5개 완성
  4. 전체 점 선택 → `M` → **By Distance**(0.1m)로 겹친 점 정리
  5. 가운데 오각형 테두리를 선택하고 `F`로 위아래 면 채우기
