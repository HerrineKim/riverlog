## 로우 코드와 Retool

로우 코드(low-code)는 화면을 직접 코딩하는 대신 미리 만들어진 블록을 끌어다 놓고, 필요한 부분만 코드로 채워 소프트웨어를 만드는 방식이다. [Retool](https://retool.com/)은 그중 **사내용 도구**(어드민 페이지, 운영 대시보드, 데이터 수정 화면)를 빠르게 만드는 데 특화된 서비스다. 약간의 JavaScript와 SQL만 알면 데이터를 보여 주는 것은 물론 직접 조작하는 화면까지 만들 수 있다.

## 특징

| 기능 | 내용 |
| --- | --- |
| UI 컴포넌트 | 표, 리스트, 차트, 폼 등 100개가 넘는 블록을 드래그 앤 드롭으로 배치 |
| 데이터 연결 | 대부분의 데이터베이스와 REST·GraphQL·gRPC API에 연결 |
| 쿼리 작성 | 데이터를 읽고 바꾸는 쿼리를 Retool 안에서 바로 작성 |
| 커스텀 로직 | 블록 속성에 `{{ }}`로 감싼 JavaScript를 넣거나, 재사용 가능한 커스텀 컴포넌트를 만든다 |
| 버전 관리 | Git과 연동해 앱 변경 이력을 관리 |
| 인증 | 소셜 로그인, 2단계 인증을 쉽게 붙인다 |

```text
{{ table1.selectedRow.email }}        ← 표에서 선택한 행의 값을 다른 블록에서 참조
{{ query1.data.filter(u => u.active) }}  ← 쿼리 결과를 JS로 가공
```

## 언제 어울리나

- **어울린다**: 운영팀이 쓰는 CRUD 화면, 지표 대시보드, CS 처리 도구처럼 사용자가 사내 인원이고 디자인보다 속도가 중요한 경우.
- **어울리지 않는다**: 고객이 직접 쓰는 서비스 화면, 세밀한 UX·성능 최적화가 필요한 화면. 이런 곳은 직접 개발하는 편이 낫다.
- 운영 데이터베이스에 직접 쓰기 권한을 주는 도구이므로, 연결 계정의 권한과 접근 가능한 사람을 좁게 관리한다.

## 정리

- Retool은 내부 도구용 로우 코드 플랫폼이다. 블록 배치 + 쿼리 + 약간의 JS로 화면을 만든다.
- 어드민·대시보드처럼 "빨리, 사내용으로" 만들 화면에 쓴다.
- 데이터를 직접 바꾸는 도구인 만큼 권한 관리가 중요하다.
