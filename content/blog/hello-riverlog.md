공부한 내용은 GitHub TIL 저장소에, 그때그때의 메모와 정리는 노션에 남겨 왔습니다. 그런데 기록이 쌓일수록 **"내가 이걸 어디에 적어 뒀더라?"** 하는 순간이 늘어났어요. 그래서 흩어진 기록을 한 줄기로 모으는 공간, **riverlog**를 만들었습니다.

## 무엇이 있나요

riverlog는 두 개의 공간으로 나뉩니다.

| 공간 | 내용 | 형식 |
| --- | --- | --- |
| **Blog** | 생각, 회고, 만들면서 배운 이야기 | 시간순 마크다운 글 |
| **Knowledge** | 개념 정리, 강의 노트, 레퍼런스 | 3D 마인드맵 + 계층형 사전 |

### 지식 창고의 두 가지 보기

- **3D 마인드맵** — 분야 → 주제 → 노트로 이어지는 연결을 공간 속에서 탐색합니다. 노드를 클릭하면 카메라가 그쪽으로 날아가요.
- **계층형 사전** — 분야별로 정리된 목차와 가나다순 색인으로 원하는 노트를 빠르게 찾습니다.

기존 노트를 그대로 옮기지 않고, 겹치는 내용은 합치고 틀린 부분은 고쳐서 다시 정리했습니다.

## 어떻게 만들었나요

```ts
// 지식 창고는 content/knowledge 아래의 폴더 구조가 곧 계층이 됩니다.
const tree = getKnowledgeTree();
const { nodes, links } = getGraphData(); // 같은 트리로 3D 그래프도 그립니다
```

- **Next.js App Router** — 모든 페이지는 빌드 시점에 정적으로 생성됩니다.
- **마크다운** — `content/blog`, `content/knowledge`에 `.md` 파일을 추가하면 끝.
- **react-force-graph-3d** — 마인드맵의 3D 렌더링을 담당합니다.

> 기록은 흐르는 강물 같아서, 붙잡아 두지 않으면 금방 흘러가 버린다.
